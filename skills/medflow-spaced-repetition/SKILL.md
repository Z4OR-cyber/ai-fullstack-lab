# MedFlow间隔重复学习

游戏化间隔重复学习系统，FSRS-4.5算法驱动，让记忆不再枯燥。

## 核心特性

### 1. FSRS-4.5间隔重复算法
- 基于遗忘曲线的科学调度，比SM-2(Anki默认)更精准
- 四参数模型：难度(D)、稳定度(S)、可检索性(R)、更新时间
- 自适应调整：根据用户回忆表现动态优化复习间隔

### 2. 游戏化机制
- **打击感反馈**：答题正确时有视觉+数值反馈，模拟"打击感"
- **连击系统**：连续答对积累连击数，激励持续学习
- **进度可视化**：每日学习量、连续打卡、知识掌握度图表

### 3. Dashboard统计
- 学习热力图（GitHub风格日历）
- 知识点掌握度分布
- 复习曲线追踪
- 错题分析

### 4. 数据管理
- localStorage存储，无需后端
- 支持导入/导出JSON
- 卡牌自定义（正面问题+背面答案+标签）

## 适用场景

| 场景 | 示例 |
|------|------|
| 医学知识 | 药理学机制、解剖学结构、诊断标准 |
| 语言学习 | 单词记忆、语法规则、例句 |
| 考试备考 | 考研政治、法考、CPA知识点 |
| 编程学习 | API用法、设计模式、算法复杂度 |
| 自定义 | 任何需要长期记忆的知识点 |

## 使用方式

### 创建卡牌
用户提供知识点列表，系统自动生成卡牌：
```
输入：
- 药物：阿司匹林 | 机制：不可逆抑制COX-1 | 用途：抗血小板
- 药物：氯吡格雷 | 机制：抑制ADP受体P2Y12 | 用途：抗血小板

输出：自动生成正反面卡牌+标签
```

### 学习流程
1. **今日复习**：FSRS调度今日需要复习的卡牌
2. **答题反馈**：翻牌→自评回忆程度（_again / _hard / _good / _easy）
3. **打击感**：答对时数值飞溅+连击+1
4. **数据更新**：FSRS参数自动调整，安排下次复习时间

### 学习统计
- 查看Dashboard：学习热力图、掌握度分布、连续打卡天数
- 导出数据：JSON格式，包含所有卡牌+学习记录

## FSRS-4.5算法参数

```
难度 D = w4 × 评分 + w5 × (1 - R)
稳定度 S = f(D, S, R, 评分)
可检索性 R = exp(-t / S)  // t为距上次复习的天数
```

四档评分影响：
- **Again**（忘记）：重置稳定度，难度+0.2
- **Hard**：稳定度×0.8，难度+0.1
- **Good**：稳定度×1.0，难度不变
- **Easy**：稳定度×1.3，难度-0.1

- 学习界面：卡牌翻转动画+答题按钮+打击感特效
