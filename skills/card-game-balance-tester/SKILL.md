# 卡牌游戏平衡测试

自动化卡牌游戏数值平衡测试工具。通过大规模模拟对战，快速发现流派强度差异和极端对局，为数值调优提供数据支撑。

## 工作流程

### 1. 确认输入

向用户确认以下输入（缺失时用默认值）：

- **卡牌数据**：JSON文件路径或内联数据。每张卡需包含：`id`, `name`, `faction`(流派), `rarity`(稀有度), `cost`(费用), `type`(类型), `attack`(攻击力), `health`(生命值), `effects`(效果列表)
- **战斗配置**（可选）：初始HP、能量上限、手牌上限、场上单位上限、最大回合数、先手抽牌数、后手抽牌数。未提供时使用默认值：HP=20, 能量上限=10, 手牌上限=7, 场上上限=5, 最大回合=8, 先手抽3, 后手抽4
- **模拟局数**（可选）：默认3000局（6流派两两对局30组×100局）
- **流派列表**（可选）：从卡牌数据自动推断

### 2. 运行模拟

执行 `python3 main.py --cards <卡牌数据路径> [--config <配置路径>] [--games <局数>] [--output <报告路径>]`

脚本会：
1. 加载卡牌数据，按流派分组
2. 为每个流派构建合法牌组（遵守同名上限、稀有度上限规则）
3. 运行所有流派两两对局（含同流派镜像对局）
4. 每局模拟完整战斗流程：抽牌→出牌→攻击→效果结算→共鸣检测→回合切换→胜负判定
5. 统计胜率、回合数、极端对局

### 3. 分析报告

脚本输出Markdown格式平衡性报告，包含：
- **流派胜率矩阵**：6×6（或N×N）交叉胜率表
- **综合表现**：每个流派的总胜率、平均回合数、平衡性评估（✅平衡/⚠️偏强偏弱）
- **极端对局**：最高和最低单场胜率
- **调整建议**：基于胜率偏差自动生成削弱/加强建议

### 4. 迭代调优

用户根据报告调整卡牌数值后，重新运行测试验证效果。建议目标：所有流派综合胜率在40%-60%区间，先手胜率不超过55%。

## 支持的卡牌效果类型

damage(伤害), heal(治疗), shield(护盾), freeze(冻结), burn(燃烧), shock(感电), taunt(嘲讽), pierce(穿透), draw_card(抽牌), cost_reduce(减费), buff(增益), debuff(减益)

## 支持的共鸣系统

- 同法则共鸣：2/3/4/5张同流派分级效果
- 跨法则融合技：预设组合触发特殊效果

## 输出格式

报告保存为Markdown文件，同时打印关键指标摘要到控制台。

## 边界情况

- 卡牌数据格式不兼容时，尝试字段映射（hp→health, effect→effects等），映射失败则报错并提示需要的最小字段集
- 某流派卡牌不足构建合法牌组时，跳过该流派并警告
- 模拟局数过少（<100）时提示结果可能不稳定
- 先手胜率>65%时在报告中标注并建议后手补偿机制
