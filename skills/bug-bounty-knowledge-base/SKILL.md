# Bug Bounty 知识库

> 来源：SecurityElites 60天 Bug Bounty 课程（29节）
> 覆盖：29种漏洞类型详解、Recon侦察方法论、漏洞报告写作

## 技能描述
完整的 Bug Bounty 知识库，包含从 Recon 到漏洞报告的全流程方法论。覆盖 OWASP Top 10 及扩展漏洞类型，每种类型含攻击原理、检测方法、修复建议和报告模板。

## 知识库内容
- 29种漏洞类型（XSS/SQLi/SSRF/IDOR/CSRF/RCE/LFI/RFI/XXE等）
- Recon 侦察全流程（子域名枚举/存活探测/目录爆破/漏洞扫描）
- 漏洞报告写作规范和模板
- 工具链使用指南（subfinder/httpx/nuclei/ffuf/dnsx/katana）
