# AI 全栈学习路线图

## 概述
覆盖 Python 基础到 RAG 管道的 AI 全栈学习路径，共 538 道练习题，横跨 12 个阶段，每道题均可独立运行并包含测试。

## 阶段划分

| 阶段 | 主题 | 题数 | 关键内容 |
|------|------|------|---------|
| 1-4 | Python 基础 | ~200 | 数据结构、OOP、Web 开发 |
| 5-8 | ML/LLM/Agent | ~150 | 机器学习、深度学习、LLM 基础、Agent 开发 |
| 9-10 | 协议架构+模型工程 | 28 | 系统设计、模型工程实践 |
| 11 | 生产运维 | 14 | DevOps、监控、部署 |
| 12 | RAG | 10 | 向量嵌入、向量数据库、文档处理、Pipeline |

## RAG 阶段（Phase 12）详情

### 模块1：基础理论（2题）
1. **向量嵌入与语义搜索** — 纯 numpy 实现 embedding 和余弦相似度（736行）
2. **RAG 向量数据库** — Chroma/pgvector/Milvus 三种实现（1483行）

### 模块2：向量数据库（3题）
3-5. 向量数据库对比与选型

### 模块3：文档处理（2题）
6-7. 文档分块策略与混合检索

### 模块4：Pipeline 实战（3题）
8-10. 端到端 RAG Pipeline 与评估

## 技术特点
- 每道题独立可运行，包含完整测试
- 纯 numpy 实现，无外部 API 依赖
- 从基础到高级，循序渐进
