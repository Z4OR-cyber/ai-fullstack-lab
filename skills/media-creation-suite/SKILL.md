# 多媒体内容创作套件

> 整合自：ai-image-studio + video-automation-toolkit + content-atomizer
> 覆盖：图片生成 → 视频制作 → 内容拆分 → 多平台分发

## 模块1：AI图片生成

### 引擎能力矩阵

| 引擎 | 最强场景 | 速度 | 中文支持 |
|------|---------|------|---------|
| GPT Image 2 | 对话式迭代、Prompt理解力、概念设计 | 中 | 中 |
| FLUX 2 Pro | 写实摄影、文字渲染、海报设计 | 快 | 中 |
| Nano Banana | 4K大图、真实人脸、自然光影 | 快 | 弱 |
| Qwen Image 2 | 中文场景、传统文化、多语种 | 快 | 最强 |
| Midjourney | 审美天花板、艺术风格、概念设计 | 慢 | 弱 |

### 引擎选择逻辑
- "中文/国风/传统/水墨/书法" → Qwen Image 2
- "海报/文字/标题/排版" → FLUX 2 Pro
- "4K/高清/大图/壁纸" → Nano Banana
- "帮我改/调整/迭代" → GPT Image 2（对话式）
- "最美/艺术/概念/氛围" → Midjourney
- 未指定 → 默认 FLUX 2 Pro

### 凭证架构
- 4引擎通过Apiframe v2代理调用（sandbox网络限制）
- FLUX保留BFL直连
- 凭证值机制：环境变量为`COZE_CRED_DUMMY_xxx`占位符，由outbound auth proxy自动替换

## 模块2：视频自动化

### 工作流
1. **脚本输入**：用户提供文案/脚本/选题
2. **分镜规划**：自动拆分为镜头列表
3. **画面生成**：调用AI图片引擎生成每帧
4. **配音TTS**：文字转语音
5. **成片合成**：图片+音频+转场→视频
6. **多格式导出**：MP4/GIF/WebM

### 支持的视频类型
- 短视频（15-60秒）：适合抖音/快手/视频号
- 中视频（1-5分钟）：适合B站/YouTube
- 图文轮播：适合小红书/公众号

## 模块3：内容原子化

### 长文拆分策略
1. **语义分段**：按主题/段落自然分割
2. **原子卡片**：每段提取核心信息点
3. **多平台适配**：
   - 小红书：图文笔记（300字+9图）
   - 公众号：长文（1500-3000字）
   - 抖音：短视频脚本（30-60秒口播）
   - 知乎：问答体（500-1000字）
   - B站：中视频脚本（3-5分钟）
4. **标题优化**：每个平台生成3个标题候选
5. **封面设计**：调用图片引擎生成平台适配封面
6. **违禁词检查**：自动检测各平台敏感词

### 跨平台优化
| 平台 | 内容形态 | 字数范围 | 封面规格 |
|------|---------|---------|---------|
| 小红书 | 图文笔记 | 300-500字 | 3:4 (1080×1440) |
| 公众号 | 长文 | 1500-3000字 | 2.35:1 (900×383) |
| 抖音 | 短视频脚本 | 30-60秒口播 | 9:16 (1080×1920) |
| 知乎 | 问答 | 500-1500字 | 自定义 |
| B站 | 中视频脚本 | 3-5分钟 | 16:9 (1920×1080) |
| 微博 | 短文 | 140字+9图 | 1:1 (1080×1080) |

## 统一素材管理
- 所有生成的图片/视频统一存储到项目目录
- 命名规范：`{日期}_{平台}_{类型}_{序号}.{ext}`
- 素材索引文件自动维护
