# RAG 检索增强生成练习集

> 10题4模块 RAG 实战练习，纯 numpy 可运行

## 技能描述
从零实现的 RAG 全栈练习题集，覆盖向量嵌入、向量数据库、文档处理和端到端 Pipeline。所有代码纯 numpy 实现，无需 GPU 或大型框架依赖。

## 模块结构
1. 基础理论（2题）：向量嵌入与语义搜索、RAG架构全貌
2. 向量数据库（3题）：Chroma/pgvector/Milvus + HNSW/IVF索引
3. 文档处理（2题）：分块策略、Hybrid Search（BM25+RRF融合）
4. Pipeline实战（3题）：端到端RAG、RAGAS评估、Agent+RAG融合
