# AI科技简报生成器

自动生成每日AI科技简报，覆盖5大领域，从搜索到输出全链路自动化。

## 简报格式（v1风格）

- **5-8条精选新闻**：自然语言段落（不用表格），每条含来源链接
- **2个新概念**：近期出现的值得关注的AI/技术概念
- **来源验证报告**：信息源质量统计
- **总大小**：6-10KB，30秒可读完

## 覆盖领域（5个）

1. **AI代理**：Agent框架、多Agent协同、Agent监管政策
2. **人工智能/大模型**：新模型发布、能力突破、训练技术
3. **开发者工具**：IDE、CLI、SDK、开发框架
4. **网络安全**：AI安全、漏洞、攻防
5. **科技产品与基础设施**：芯片、云服务、硬件

## 执行流程

### 1. 搜索规划
- 每个领域2条query（1中文+1英文），共10条base query
- 5条动态query（根据近期热点调整）
- 共15条query，每条返回4条候选，共60条候选

### 2. 候选筛选
- **tier排序**：Tier1(官方一手) > Tier2(权威二手) > Tier3(聚合)
- **单域名上限**：同一域名最多3条，保证来源多样性
- **去重**：URL去重 + 标题相似度去重
- 精选12条进入抓取

### 3. 内容抓取
- 每条候选抓取全文（最多12页，每页4000字符）
- 24h缓存：相同query的搜索结果缓存复用

### 4. 事实抽取（batch处理）
- 每3页合并为1次LLM调用（batch_size=3）
- 提取：标题、摘要、关键事实、来源URL、发布时间
- 4次batch调用替代12次单页调用

### 5. 聚合+摘要（合并为1次调用）
- 聚合所有事实单元为结构化新闻
- 同时生成关键要点(takeaways)
- 输出AggregatedBriefing模型（units + takeaways）

### 6. 报告生成
- 1次LLM调用生成最终Markdown报告
- 按重要性排序，去重后保留5-8条

## LLM调用总计
- 事实抽取：4次batch
- 聚合+摘要：1次
- 报告生成：1次
- **共6次**（优化前25次，降76%）

## 状态管理

SQLite数据库，4张表：
- `seen_urls`：URL去重
- `info_units`：信息单元指纹去重
- `daily_units`：每日快照
- `search_cache`：搜索结果24h缓存

## 使用方式

用户说"生成今日AI简报"或"看看今天AI有什么新闻"时触发。

需要环境：
- 网络搜索能力
- 网页抓取能力
- LLM调用能力
- SQLite（用于状态管理）

## 优化历史

| 版本 | 优化项 | LLM调用 | 效果 |
|------|--------|---------|------|
| v1 | 基线 | ~25次 | - |
| v2 | batch extract_facts | ~7次 | 降72% |
| v3 | aggregate+takeaways合并 | ~6次 | 再降14% |
| v3 | 搜索24h缓存 | ~6次 | 重复query零消耗 |
