# AI Tech Briefing Generator — 每日AI科技简报生成器

## 概述

全自动 AI 科技资讯采集与简报生成流水线。每日定时执行，从多源搜索到结构化简报输出，覆盖五个核心领域，支持 Token 优化和质量控制。

## 覆盖领域

1. **AI 代理** — Agent框架、多Agent协同、Agent工具链
2. **人工智能/大模型** — LLM发布、能力突破、训练技术
3. **开发者工具** — IDE、CI/CD、API平台、SDK
4. **网络安全** — 漏洞披露、安全工具、攻防技术
5. **科技产品与基础设施** — 硬件、云服务、边缘计算

## 执行流水线

### Phase 1: 搜索（Search）
- 15条中英文混合 query（9英 + 6中）
- CSDN 清零策略：使用英文 query 规避低质量中文来源
- 24h 时效过滤：只取最近24小时发布的内容

### Phase 2: 筛选（Filter）
- 从搜索结果中筛选 60 个候选
- Tier 分层排序：T1(官方博客/公告) > T2(权威媒体) > T3(聚合/博客)
- 单域名上限 3 条：确保来源多样性

### Phase 3: 精选（Select）
- 从 60 候选中精选 12 条
- 去重：同一事件只保留最权威来源
- 重要性评估：影响范围 × 创新程度 × 时效性

### Phase 4: 抓取（Fetch）
- 对精选文章执行全文抓取
- 使用 fetch_web 获取完整内容
- 抓取失败时降级为搜索摘要

### Phase 5: 事实抽取（Extract）
- LLM 批处理：每批 3-4 篇文章
- 提取：事件描述、关键数据、影响分析、来源链接
- Token 优化：批处理减少 50% LLM 调用

### Phase 6: 聚合生成（Generate）
- 聚合为 5-8 条新闻 + 2 个新概念
- 每条新闻包含：标题、摘要、可信度评级、来源链接
- 新概念：从新闻中提取值得学习的术语/技术

### Phase 7: 验证（Verify）
- 来源验证：每条新闻至少有 2 个独立来源
- 可信度评级：🟢 高可信 / 🟡 中等可信 / 🔴 低可信
- 交叉验证：多源一致的信息才标注为高可信

## 输出格式

```markdown
# AI科技简报 — YYYY年M月D日（星期X）

## 一、重要新闻
### 1. [新闻标题]
[新闻摘要，2-3句]
- **可信度：** 🟢 高可信
- **来源：** [来源1](url)；交叉验证：[来源2](url)

...

## 二、值得学习的新概念
### 1. [概念名称]
**是什么：** ...
**怎么用：** ...
```

## Token 优化策略

1. 中英混合 query 规避 CSDN 等低质量来源
2. 单域名限 3 条确保多样性
3. LLM 批处理（3-4篇/批）降低 50% 调用
4. 搜索摘要优先，仅关键文章全文抓取
5. 结构化输出减少生成长度

## 质量指标

- 文件大小目标：6000-12000 B
- 新闻数量：5-8 条
- 新概念：2 个
- 高可信占比：>60%
- 来源多样性：≥7个不同域名

## 定时任务配置

- 执行时间：每日 08:00
- 弹性窗口：07:50-08:10
- 失败重试：同参数最多1次，失败后降级为纯搜索摘要模式
