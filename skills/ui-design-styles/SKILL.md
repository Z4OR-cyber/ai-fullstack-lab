## 使用原则

1. **精准命名** — 用具体风格名（如"玻璃拟态"）替代模糊描述（如"好看的界面"），AI出图精准度提升10倍
2. **主+辅组合** — 选择1个主风格 + 1-2个辅助风格，避免风格冲突
3. **行业匹配** — 参考场景组合推荐表，按行业/产品类型选择
4. **CSS锚定** — 给AI生成UI时，同时指定风格名+关键CSS特征（如"glassmorphism: backdrop-filter: blur(10px), 半透明背景, 1px边框"）
