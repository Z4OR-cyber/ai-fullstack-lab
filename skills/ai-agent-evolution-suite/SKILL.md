# AI Agent 自进化工程体系

> ai-agent-evolution-suite — 从认知引擎到学习路径的一站式 Agent 自进化工程平台

## 概述

AI Agent 自进化工程体系是一套完整的、纯 Python 实现的智能体工程解决方案，整合了四个独立但互补的子系统，覆盖从底层记忆架构到上层学习路径的全栈能力。整个体系以 **Suyi 自进化 Agent 框架** 为核心引擎，**EvoAgent 记忆系统** 作为认知层已内嵌其中，**RAG 练习集** 提供检索增强生成的实战学习路径，**AI 全栈学习路线图** 则构建了从零到生产的知识图谱。

### 体系规模

| 子系统 | 角色 | 规模 |
|--------|------|------|
| Suyi Agent 框架 | 核心引擎 | 39 模块 / 142 文件 / ~43,000 行 / 3,121 测试 |
| EvoAgent 记忆系统 | 认知层（已内嵌） | 6 文件 / ~2,700 行 / 44 项测试 |
| RAG 练习集 | 实战学习路径 | 10 题 / 4 模块 / 纯 numpy 可运行 |
| AI 全栈路线图 | 知识图谱 | 538 题 / 12 阶段 / 含完整测试 |

## 模块关系

### 层级依赖

```
知识图谱层（AI全栈路线图）
    │
    ├── 提供系统性学习路径（538题/12阶段）
    │   包含 RAG 阶段（Phase 12）的完整知识体系
    │
    ▼
实战练习层（RAG练习集）
    │
    ├── 提供可运行的端到端实战代码
    │   验证学习成果，产出可复用的 RAG 组件
    │
    ▼
核心引擎层（Suyi框架）
    │
    ├── 吸收练习成果到 rag/ 模块
    │   驱动 Agent 的自主决策与工具编排
    │
    ├── 内嵌认知层（EvoAgent记忆系统）
    │   为 Agent 提供记忆、检索与遗忘能力
    │
    ▼
自进化闭环
    │
    └── Evolution引擎基于评估反馈（Evaluation）
        自动变异策略、优化参数，实现持续进化
```

### 数据流向

1. **学习路径 → 实践**：全栈路线图的 RAG 阶段（Phase 12）与 RAG 练习集的 10 题一一对应
2. **实践 → 引擎**：RAG 练习产出的向量检索、文档分块等组件可直接集成到 Suyi 的 `rag/` 模块
3. **引擎 → 认知**：Suyi 的 `memory/` 模块已内嵌 EvoAgent 三层记忆系统，为 Agent 提供上下文管理
4. **认知 → 进化**：记忆系统的置信度评分和遗忘机制为 Evolution 引擎提供适应度信号
5. **进化 → 学习**：自进化引擎的策略变异结果可反馈为新的学习需求，形成闭环

### 二、EvoAgent 三层记忆系统（认知层，已内嵌）

**规模**：6 文件 / ~2,700 行 / 44 项测试

#### 文件清单

| 文件 | 行数 | 功能 |
|------|------|------|
| `utils/token_counter.py` | 137 | 中英文混合 Token 估算 |
| `memory/working.py` | 482 | 工作记忆层，LRU 淘汰，迭代式压缩 |
| `memory/episodic.py` | 542 | 情景记忆层，4 级分级压缩 |
| `memory/semantic.py` | 669 | 语义记忆层，TF-IDF 向量检索 + 关键词倒排索引 |
| `memory/lifecycle.py` | 392 | 记忆生命周期，4 阶段演进 |
| `memory/__init__.py` | 474 | MemoryManager 统一入口 |

#### 三层记忆架构

1. **工作记忆（Working Memory）**：短时上下文缓冲，LRU 淘汰策略，保证不超出 Token 预算
2. **情景记忆（Episodic Memory）**：时间戳标记的经验记录，基于消息年龄的 4 级分级压缩（≤5 轮原文 / ≤15 轮弃工具输出 / ≤30 轮摘要 / >30 轮跳过）
3. **语义记忆（Semantic Memory）**：概念提取与关系映射，TF-IDF 向量检索 + 关键词倒排索引

#### 记忆生命周期

```
新鲜阶段 → 巩固阶段 → 压缩阶段 → 遗忘阶段
(完整保留) (情景→语义) (摘要压缩) (Ebbinghaus指数衰减)
```

#### 置信度计算
```
confidence = base_score × time_decay × (1 + success_count×0.1 − fail_count×0.05)
```
时间衰减采用 half_life = 7 天的指数衰减。

#### 整合状态
EvoAgent 记忆系统已完整整合进 Suyi 框架的 `memory/` 模块，作为 Agent 的认知层运行。可通过 `MemoryManager` 统一入口访问三层记忆。

## 安装与使用

### 环境要求
- Python 3.10+
- numpy（唯一第三方依赖）

### 快速开始

#### 1. 使用 Suyi 框架构建 Agent
```python
from suyi import Agent
from suyi.memory import MemoryManager

# 初始化带三层记忆的 Agent
agent = Agent(
    memory=MemoryManager(token_budget=4096),
    llm_adapter="openai",  # 或 "anthropic"
)

# 注册工具
agent.tools.register(my_tool)

# 运行
result = await agent.run("帮我分析这段代码的性能瓶颈")
```

#### 2. 运行 RAG 练习
```bash
cd rag-exercise-collection
python -m pytest tests/ -v  # 运行全部测试
python exercises/01_vector_embedding.py  # 运行单题
```

#### 3. 按学习路线图学习
```bash
# 从 Phase 1 开始
cd ai-fullstack-learning-path/python_exercises/phase_01/
python -m pytest -v

# 跳转到 RAG 阶段（Phase 12）
cd ../phase_12_rag/
python -m pytest -v
```

## 整合优势

### 1. 认知闭环
EvoAgent 三层记忆系统已内嵌为 Suyi 的认知层，Agent 具备从短期工作记忆到长期语义记忆的完整认知能力，包括基于 Ebbinghaus 遗忘曲线的自适应遗忘机制。

### 2. 自进化能力
Suyi 的 Evolution 引擎结合 Evaluation 框架的 6 项核心指标，可自动评估 Agent 表现、变异策略参数、追踪进化历史，实现无需人工干预的持续优化。

### 3. 学用一体
RAG 练习集与全栈路线图的 Phase 12 精确映射，学习者从路线图获取理论框架，在练习集中动手实践，产出的组件可直接集成到 Suyi 框架的 `rag/` 模块。

### 4. 零依赖架构
整个体系仅依赖 Python 标准库 + numpy，无 PyTorch / TensorFlow / LangChain 等重型框架依赖。所有向量运算、检索逻辑、记忆管理均为纯 Python/numpy 实现，便于理解、调试和部署。

### 5. 工程完备性
- **测试覆盖**：3,121 + 44 + 538 项测试，总计超 3,700 项
- **安全护栏**：输入/输出过滤、敏感信息检测、速率限制
- **人工干预**：HITL 审核循环，关键决策可回退至人工
- **可观测性**：结构化日志、指标收集、分布式追踪
- **多智能体**：Sequential / Parallel / Pipeline 三种协作模式 + Swarm 群体智能

### 6. 生产就绪
MCP 协议支持、AI 网关集成、插件系统、部署模板、多模态支持等增强模块，使体系从学习原型到生产部署的路径畅通无阻。
