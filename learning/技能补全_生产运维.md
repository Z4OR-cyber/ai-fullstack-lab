## 模块一：Observability（可观测性）

### 可观测性三支柱总览

可观测性三支柱是分布式系统监控的基石：

| 支柱 | 核心问题 | 数据特征 | 在 Agent 中的应用 |
|------|---------|---------|------------------|
| Logs 日志 | 「发生了什么？」 | 离散事件记录 | LLM 调用、工具执行、Agent 决策 |
| Metrics 指标 | 「整体怎么样？」 | 聚合数值 | 延迟分布、token 消耗、错误率 |
| Traces 追踪 | 「每步花了多久？」 | 链路时间线 | 请求全链路：用户输入→LLM→工具→输出 |

三者关系：日志是细节、指标是概览、追踪是链路。三者通过 **请求 ID** 关联。

### 第 1 题：结构化 JSON 日志器（支持多级别、上下文注入、请求 ID 追踪）

#### 知识点讲解

Agent 系统的日志与普通 Web 应用不同——一次用户请求可能触发多轮 LLM 调用、多次工具执行，日志必须能按请求 ID 关联起来，形成完整的「执行故事」。

**核心设计：**
1. **JSON 结构化日志**：每条日志是一个 JSON 对象，字段固定（timestamp, level, request_id, message, context），便于机器解析和聚合查询
2. **多级别日志**：DEBUG → INFO → WARNING → ERROR → CRITICAL，支持运行时切换级别过滤
3. **上下文注入**：通过 ContextVar 实现请求级上下文（request_id, user_id, session_id）自动注入，无需手动传递
4. **请求 ID 追踪**：每个请求生成唯一 ID，贯穿整个调用链，便于关联同一请求的所有日志

```
日志关联示意：
RequestID: req-abc123
  [INFO]  Agent received user query
  [DEBUG] LLM call started (model=gpt-4, tokens_in=120)
  [DEBUG] Tool call: search_web("python asyncio")
  [INFO]  Tool returned 3 results (latency=340ms)
  [DEBUG] LLM call completed (tokens_out=85, latency=1200ms)
  [INFO]  Agent response sent to user
  [INFO]  Request completed (total_latency=1600ms, loops=2)
```

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 1 题：结构化 JSON 日志器
- 支持 DEBUG/INFO/WARNING/ERROR/CRITICAL 五个级别
- 基于 ContextVar 的请求级上下文自动注入
- JSON 格式输出，便于 ELK/Loki 等日志系统采集
- 支持子日志器（child logger）继承父上下文
"""

import json
import time
import uuid
from contextvars import ContextVar
from typing import Any, Optional
from dataclasses import dataclass, field

# ============================================================================
# 日志级别定义
# ============================================================================

# 日志级别常量——数字越大优先级越高
DEBUG = 10
INFO = 20
WARNING = 30
ERROR = 40
CRITICAL = 50

# 级别名称映射
LEVEL_NAMES = {
    DEBUG: "DEBUG",
    INFO: "INFO",
    WARNING: "WARNING",
    ERROR: "ERROR",
    CRITICAL: "CRITICAL",
}


# ============================================================================
# 上下文管理——基于 ContextVar 实现请求级隔离
# ============================================================================

# 请求级上下文变量——每个协程/线程有独立的值
_request_id_ctx: ContextVar[str] = ContextVar("request_id", default="")
_user_id_ctx: ContextVar[str] = ContextVar("user_id", default="")
_session_id_ctx: ContextVar[str] = ContextVar("session_id", default="")


@dataclass
class LogContext:
    """日志上下文——封装请求级别的追踪信息。"""
    request_id: str = ""
    user_id: str = ""
    session_id: str = ""
    extra: dict = field(default_factory=dict)

    def to_dict(self) -> dict:
        """将上下文转为字典，过滤空值。"""
        result = {}
        if self.request_id:
            result["request_id"] = self.request_id
        if self.user_id:
            result["user_id"] = self.user_id
        if self.session_id:
            result["session_id"] = self.session_id
        result.update(self.extra)
        return result


def set_log_context(
    request_id: str = "",
    user_id: str = "",
    session_id: str = "",
    **extra,
) -> LogContext:
    """设置当前上下文的日志追踪信息。

    在请求入口调用一次，之后该请求链路上的所有日志都会自动带上这些字段。
    """
    rid = request_id or f"req-{uuid.uuid4().hex[:12]}"
    _request_id_ctx.set(rid)
    if user_id:
        _user_id_ctx.set(user_id)
    if session_id:
        _session_id_ctx.set(session_id)
    return LogContext(request_id=rid, user_id=user_id, session_id=session_id, extra=extra)


def get_current_context() -> dict:
    """获取当前上下文信息（从 ContextVar 读取）。"""
    result = {}
    rid = _request_id_ctx.get()
    if rid:
        result["request_id"] = rid
    uid = _user_id_ctx.get()
    if uid:
        result["user_id"] = uid
    sid = _session_id_ctx.get()
    if sid:
        result["session_id"] = sid
    return result


# ============================================================================
# JSON 日志器实现
# ============================================================================

class JsonLogger:
    """结构化 JSON 日志器。

    特性：
    - 输出 JSON 格式日志，每行一条（JSONL）
    - 自动注入上下文（request_id 等）
    - 支持运行时级别切换
    - 支持子日志器（带固定前缀字段）
    """

    def __init__(
        self,
        name: str = "app",
        level: int = INFO,
        extra_fields: Optional[dict] = None,
    ):
        self.name = name
        self.level = level
        self._extra_fields = extra_fields or {}

    def child(self, name: str, **extra) -> "JsonLogger":
        """创建子日志器，继承父日志器名称并附加固定字段。"""
        child_name = f"{self.name}.{name}"
        merged = {**self._extra_fields, **extra}
        return JsonLogger(child_name, self.level, merged)

    def _emit(self, level: int, message: str, **kwargs) -> str:
        """核心方法：组装并输出一条 JSON 日志。"""
        if level < self.level:
            return ""

        # 组装日志记录
        record = {
            "timestamp": time.strftime("%Y-%m-%dT%H:%M:%S", time.localtime()),
            "level": LEVEL_NAMES.get(level, "UNKNOWN"),
            "logger": self.name,
            "message": message,
        }

        # 注入上下文（request_id, user_id, session_id）
        record.update(get_current_context())

        # 注入子日志器的固定字段
        record.update(self._extra_fields)

        # 注入调用方传入的动态字段
        record.update(kwargs)

        # 序列化为 JSON 并输出
        line = json.dumps(record, ensure_ascii=False, default=str)
        print(line)
        return line

    def debug(self, message: str, **kwargs) -> str:
        return self._emit(DEBUG, message, **kwargs)

    def info(self, message: str, **kwargs) -> str:
        return self._emit(INFO, message, **kwargs)

    def warning(self, message: str, **kwargs) -> str:
        return self._emit(WARNING, message, **kwargs)

    def error(self, message: str, **kwargs) -> str:
        return self._emit(ERROR, message, **kwargs)

    def critical(self, message: str, **kwargs) -> str:
        return self._emit(CRITICAL, message, **kwargs)

    def set_level(self, level: int) -> None:
        """运行时切换日志级别。"""
        self.level = level


# ============================================================================
# 日志查询器——从 JSON 字符串中提取并过滤日志
# ============================================================================

class LogQuery:
    """日志查询器——解析 JSON 日志并按条件过滤。

    模拟 ELK 中的查询功能：按 request_id 关联、按级别过滤、按字段搜索。
    """

    def __init__(self):
        self._entries: list[dict] = []

    def ingest(self, json_line: str) -> None:
        """摄入一条 JSON 日志。"""
        try:
            entry = json.loads(json_line)
            self._entries.append(entry)
        except json.JSONDecodeError:
            pass

    def by_request(self, request_id: str) -> list[dict]:
        """按 request_id 查询关联日志——还原一次请求的完整故事。"""
        return [e for e in self._entries if e.get("request_id") == request_id]

    def by_level(self, level: str) -> list[dict]:
        """按日志级别过滤。"""
        return [e for e in self._entries if e.get("level") == level.upper()]

    def by_field(self, key: str, value: Any) -> list[dict]:
        """按任意字段过滤。"""
        return [e for e in self._entries if e.get(key) == value]

    def summary(self) -> dict:
        """生成日志统计摘要。"""
        levels = {}
        for e in self._entries:
            lv = e.get("level", "UNKNOWN")
            levels[lv] = levels.get(lv, 0) + 1
        return {
            "total": len(self._entries),
            "by_level": levels,
            "unique_requests": len({e.get("request_id") for e in self._entries if e.get("request_id")}),
        }
```

### 第 2 题：Agent 指标采集器（延迟/token/工具调用/循环次数 4 类指标）

#### 知识点讲解

指标是可观测性的「概览视图」——它把大量离散事件聚合成可量化的数值，让你一眼看出系统是否健康。Agent 系统需要关注四类核心指标：

| 指标类别 | 具体指标 | 为什么重要 |
|---------|---------|-----------|
| 延迟 Latency | LLM 调用延迟、工具执行延迟、端到端延迟 | 用户体验直接受延迟影响 |
| Token 消耗 | 输入 token、输出 token、总 token | 直接影响成本 |
| 工具调用 | 调用次数、成功率、平均耗时 | 工具是 Agent 的「手」，坏了就瘫痪 |
| 循环次数 | Agent Loop 迭代次数 | 循环过多可能意味着 Agent 卡住了 |

**三种指标原语：**
- **Counter（计数器）**：单调递增，如总请求数、总 token 数
- **Histogram（直方图）**：分桶统计分布，如延迟 P50/P90/P99
- **Gauge（仪表盘）**：可增可减的瞬时值，如当前活跃请求数

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 2 题：Agent 指标采集器
- Counter：单调递增计数器（请求数、token 数、错误数）
- Histogram：分桶直方图（延迟分布 P50/P90/P99）
- Gauge：可增可减仪表盘（当前活跃请求数）
- 四类 Agent 核心指标：延迟、Token、工具调用、循环次数
"""

import time
from typing import Optional
from dataclasses import dataclass, field

import numpy as np

# ============================================================================
# 指标原语 1：Counter（计数器）
# ============================================================================

class Counter:
    """单调递增计数器。

    只能 inc() 不能 dec()，适合统计总请求数、总 token 数等。
    支持带标签的计数——不同标签维护独立的计数值。

    示例：
        c = Counter("tool_calls")
        c.inc(labels={"tool": "search"})       # search 工具调用 +1
        c.inc(2, labels={"tool": "search"})     # search 工具调用 +2
        c.inc(labels={"tool": "calculator"})    # calculator 工具调用 +1
    """

    def __init__(self, name: str, description: str = ""):
        self.name = name
        self.description = description
        # 用字典存储不同标签组合的值
        self._values: dict[str, float] = {}

    def _label_key(self, labels: Optional[dict]) -> str:
        """将标签字典转为可哈希的字符串键。"""
        if not labels:
            return ""
        return "|".join(f"{k}={v}" for k, v in sorted(labels.items()))

    def inc(self, amount: float = 1, labels: Optional[dict] = None) -> None:
        """增加计数值。"""
        key = self._label_key(labels)
        self._values[key] = self._values.get(key, 0) + amount

    def get(self, labels: Optional[dict] = None) -> float:
        """获取当前计数值。"""
        return self._values.get(self._label_key(labels), 0)

    def get_all(self) -> dict[str, float]:
        """获取所有标签组合的值。"""
        return dict(self._values)

    def reset(self) -> None:
        """重置所有计数。"""
        self._values.clear()


# ============================================================================
# 指标原语 2：Histogram（直方图）
# ============================================================================

class Histogram:
    """分桶直方图——统计值的分布。

    将观测值分配到预定义的桶中，支持计算分位数（P50/P90/P99）。
    同时保留所有原始值用于精确分位数计算。

    示例：
        h = Histogram("llm_latency_ms", buckets=[50, 100, 200, 500, 1000])
        h.observe(120)   # 落入 [100, 200) 桶
        h.observe(800)   # 落入 [500, 1000) 桶
        h.percentile(0.5)  # P50
        h.percentile(0.99) # P99
    """

    def __init__(self, name: str, buckets: list[float], description: str = ""):
        self.name = name
        self.description = description
        # 桶边界必须有序
        self.buckets = sorted(buckets)
        # 每个桶的计数（最后一个为 +Inf 桶）
        self.bucket_counts = [0] * (len(buckets) + 1)
        # 保留所有原始值用于精确分位数计算
        self._raw_values: list[float] = []
        self._sum = 0.0
        self._count = 0

    def observe(self, value: float) -> None:
        """观测一个值，分配到对应的桶。"""
        self._raw_values.append(value)
        self._sum += value
        self._count += 1

        # 找到合适的桶
        placed = False
        for i, boundary in enumerate(self.buckets):
            if value < boundary:
                self.bucket_counts[i] += 1
                placed = True
                break
        if not placed:
            self.bucket_counts[-1] += 1  # +Inf 桶

    def percentile(self, q: float) -> float:
        """计算分位数（0.0~1.0），使用原始值精确计算。"""
        if not self._raw_values:
            return 0.0
        return float(np.percentile(self._raw_values, q * 100))

    def mean(self) -> float:
        """平均值。"""
        return self._sum / self._count if self._count > 0 else 0.0

    def bucket_distribution(self) -> list[tuple[str, int]]:
        """返回桶分布（用于可视化）。"""
        result = []
        prev = 0
        for i, boundary in enumerate(self.buckets):
            result.append((f"[{prev}, {boundary})", self.bucket_counts[i]))
            prev = boundary
        result.append((f"[{prev}, +Inf)", self.bucket_counts[-1]))
        return result

    def reset(self) -> None:
        """重置直方图。"""
        self.bucket_counts = [0] * (len(self.buckets) + 1)
        self._raw_values.clear()
        self._sum = 0.0
        self._count = 0


# ============================================================================
# 指标原语 3：Gauge（仪表盘）
# ============================================================================

class Gauge:
    """可增可减的仪表盘——记录瞬时值。

    适合记录当前活跃请求数、队列长度、内存使用等可增可减的指标。
    """

    def __init__(self, name: str, description: str = ""):
        self.name = name
        self.description = description
        self._value: float = 0.0

    def inc(self, amount: float = 1) -> None:
        self._value += amount

    def dec(self, amount: float = 1) -> None:
        self._value -= amount

    def set(self, value: float) -> None:
        self._value = value

    def get(self) -> float:
        return self._value


# ============================================================================
# Agent 指标采集器——整合四类核心指标
# ============================================================================

class AgentMetrics:
    """Agent 核心指标采集器。

    整合四类指标：
    1. 延迟指标（LLM 延迟、工具延迟、端到端延迟） -> Histogram
    2. Token 消耗指标（输入/输出/总 token） -> Counter
    3. 工具调用指标（调用次数、成功率） -> Counter
    4. 循环次数指标（Agent Loop 迭代次数） -> Histogram + Counter
    """

    def __init__(self):
        # --- 1. 延迟指标 ---
        latency_buckets = [10, 50, 100, 200, 500, 1000, 2000, 5000, 10000]
        self.llm_latency = Histogram("llm_latency_ms", latency_buckets, "LLM call latency (ms)")
        self.tool_latency = Histogram("tool_latency_ms", latency_buckets, "Tool execution latency (ms)")
        self.e2e_latency = Histogram("e2e_latency_ms", [100, 500, 1000, 2000, 5000, 10000, 30000], "End-to-end latency (ms)")

        # --- 2. Token 消耗指标 ---
        self.tokens_in = Counter("tokens_in_total", "Total input tokens")
        self.tokens_out = Counter("tokens_out_total", "Total output tokens")
        self.tokens_total = Counter("tokens_total", "Total tokens")

        # --- 3. 工具调用指标 ---
        self.tool_calls = Counter("tool_calls_total", "Total tool calls")
        self.tool_success = Counter("tool_calls_success", "Successful tool calls")
        self.tool_failure = Counter("tool_calls_failure", "Failed tool calls")

        # --- 4. 循环次数指标 ---
        self.loop_count = Histogram(
            "agent_loop_count",
            [1, 2, 3, 5, 8, 10, 15, 20, 30],
            "Agent Loop iteration count distribution",
        )
        self.total_requests = Counter("requests_total", "Total requests")
        self.active_requests = Gauge("active_requests", "Current active requests")

    def record_llm_call(self, latency_ms: float, tokens_in: int, tokens_out: int) -> None:
        """记录一次 LLM 调用。"""
        self.llm_latency.observe(latency_ms)
        self.tokens_in.inc(tokens_in)
        self.tokens_out.inc(tokens_out)
        self.tokens_total.inc(tokens_in + tokens_out)

    def record_tool_call(self, tool_name: str, latency_ms: float, success: bool) -> None:
        """记录一次工具调用。"""
        labels = {"tool": tool_name}
        self.tool_calls.inc(labels=labels)
        self.tool_latency.observe(latency_ms)
        if success:
            self.tool_success.inc(labels=labels)
        else:
            self.tool_failure.inc(labels=labels)

    def record_request(self, e2e_ms: float, loops: int) -> None:
        """记录一次完整请求。"""
        self.e2e_latency.observe(e2e_ms)
        self.loop_count.observe(loops)
        self.total_requests.inc()
        self.active_requests.dec()

    def request_start(self) -> None:
        """请求开始时调用。"""
        self.active_requests.inc()

    def tool_success_rate(self, tool_name: str = None) -> float:
        """计算工具调用成功率。"""
        if tool_name:
            total = self.tool_calls.get(labels={"tool": tool_name})
            success = self.tool_success.get(labels={"tool": tool_name})
        else:
            total = sum(self.tool_calls.get_all().values())
            success = sum(self.tool_success.get_all().values())
        return success / total if total > 0 else 0.0

    def summary(self) -> dict:
        """生成指标摘要报告。"""
        return {
            "requests": {
                "total": self.total_requests.get(),
                "active": self.active_requests.get(),
            },
            "latency": {
                "llm_p50": round(self.llm_latency.percentile(0.5), 1),
                "llm_p90": round(self.llm_latency.percentile(0.9), 1),
                "llm_p99": round(self.llm_latency.percentile(0.99), 1),
                "tool_p50": round(self.tool_latency.percentile(0.5), 1),
                "tool_p90": round(self.tool_latency.percentile(0.9), 1),
                "e2e_p50": round(self.e2e_latency.percentile(0.5), 1),
                "e2e_p90": round(self.e2e_latency.percentile(0.9), 1),
                "e2e_p99": round(self.e2e_latency.percentile(0.99), 1),
            },
            "tokens": {
                "in": int(self.tokens_in.get()),
                "out": int(self.tokens_out.get()),
                "total": int(self.tokens_total.get()),
            },
            "tools": {
                "total_calls": sum(self.tool_calls.get_all().values()),
                "success_rate": round(self.tool_success_rate(), 4),
                "by_tool": {
                    k.split("=")[1] if "=" in k else k: {
                        "calls": self.tool_calls.get(labels={"tool": k.split("=")[1]} if "=" in k else None),
                        "success": self.tool_success.get(labels={"tool": k.split("=")[1]} if "=" in k else None),
                    }
                    for k in self.tool_calls.get_all()
                },
            },
            "loops": {
                "avg": round(self.loop_count.mean(), 1),
                "p50": round(self.loop_count.percentile(0.5), 1),
                "p90": round(self.loop_count.percentile(0.9), 1),
                "p99": round(self.loop_count.percentile(0.99), 1),
            },
        }
```

### 第 3 题：分布式追踪系统（Span 树构建 + 时间线序列化 + ASCII 可视化）

#### 知识点讲解

如果说日志是「发生了什么」、指标是「整体怎么样」，那么追踪回答的是「每一步花了多久、谁调用了谁」。

**核心概念：**
- **Trace（追踪）**：一次请求的完整调用链，由唯一 Trace ID 标识
- **Span（跨度）**：调用链中的一个操作单元，记录开始时间、结束时间、操作名、标签
- **父子关系**：Span 之间通过 parent_span_id 建立树形结构，形成调用层级

```
一次 Agent 请求的 Span 树：

TraceID: trace-abc123
┌─ span: agent.request [0ms ─────────────── 3200ms] ───────────────┐
│                                                                   │
│  ┌─ span: llm.call #1 [50ms ─────── 1200ms] ──────────────────┐  │
│  │  tags: model=gpt-4, tokens_in=120, tokens_out=85           │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─ span: tool.search [1250ms ─── 1590ms] ────────────────────┐  │
│  │  tags: tool=search, query="python asyncio", results=3      │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                   │
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 3 题：分布式追踪系统
- Span 数据结构：操作名、起止时间、标签、父子关系
- Trace 构建：通过 context manager 自动建立 Span 树
- 时间线序列化：将 Span 树转为时间线格式
- ASCII 可视化：终端输出甘特图风格的时间线
"""

import time
import uuid
from typing import Optional, Any
from dataclasses import dataclass, field


# ============================================================================
# Span 数据结构
# ============================================================================

@dataclass
class Span:
    """一个 Span 代表调用链中的一个操作单元。

    属性：
    - span_id: 唯一标识
    - trace_id: 所属追踪的 ID（同一条调用链共享）
    - parent_span_id: 父 Span 的 ID（根 Span 为 None）
    - name: 操作名称（如 "llm.call", "tool.search"）
    - start_time: 开始时间（毫秒时间戳）
    - end_time: 结束时间（毫秒时间戳）
    - tags: 标签字典（如 model="gpt-4", tokens=120）
    - status: 状态（OK / ERROR）
    """
    span_id: str = field(default_factory=lambda: f"span-{uuid.uuid4().hex[:8]}")
    trace_id: str = ""
    parent_span_id: Optional[str] = None
    name: str = ""
    start_time: float = 0.0  # 毫秒时间戳
    end_time: float = 0.0
    tags: dict[str, Any] = field(default_factory=dict)
    status: str = "OK"  # OK / ERROR

    @property
    def duration_ms(self) -> float:
        """Span 持续时间（毫秒）。"""
        return self.end_time - self.start_time if self.end_time > 0 else 0.0

    def set_tag(self, key: str, value: Any) -> None:
        """设置标签。"""
        self.tags[key] = value

    def set_error(self, error_msg: str) -> None:
        """标记为错误状态。"""
        self.status = "ERROR"
        self.tags["error"] = error_msg

    def to_dict(self) -> dict:
        """序列化为字典。"""
        return {
            "span_id": self.span_id,
            "trace_id": self.trace_id,
            "parent_span_id": self.parent_span_id,
            "name": self.name,
            "start_time": round(self.start_time, 2),
            "end_time": round(self.end_time, 2),
            "duration_ms": round(self.duration_ms, 2),
            "tags": self.tags,
            "status": self.status,
        }


# ============================================================================
# Trace 追踪管理器
# ============================================================================

class Tracer:
    """分布式追踪管理器。

    核心功能：
    - 创建 Span 并自动维护父子关系
    - 通过 context manager 管理 Span 生命周期
    - 收集所有 Span 并构建树形结构
    - 序列化为时间线格式

    使用示例：
        tracer = Tracer()
        with tracer.start_span("agent.request") as root:
            with tracer.start_span("llm.call") as llm_span:
                llm_span.set_tag("model", "gpt-4")
                time.sleep(0.1)  # 模拟 LLM 调用
            with tracer.start_span("tool.search") as tool_span:
                tool_span.set_tag("query", "python asyncio")
                time.sleep(0.05)
    """

    def __init__(self):
        self._spans: list[Span] = []
        self._trace_id: str = ""
        # 当前活跃的 Span 栈——用于维护父子关系
        self._active_stack: list[Span] = []

    def _now_ms(self) -> float:
        """获取当前时间（毫秒）。"""
        return time.time() * 1000

    def start_span(self, name: str, tags: Optional[dict] = None) -> "SpanContext":
        """开始一个新的 Span。

        自动建立与当前活跃 Span 的父子关系。
        返回一个 SpanContext（context manager），退出时自动结束 Span。
        """
        # 如果还没有 trace_id，创建一个
        if not self._trace_id:
            self._trace_id = f"trace-{uuid.uuid4().hex[:12]}"

        # 确定父 Span
        parent_span_id = self._active_stack[-1].span_id if self._active_stack else None

        span = Span(
            trace_id=self._trace_id,
            parent_span_id=parent_span_id,
            name=name,
            start_time=self._now_ms(),
        )
        if tags:
            span.tags.update(tags)

        self._active_stack.append(span)
        return SpanContext(self, span)

    def _finish_span(self, span: Span) -> None:
        """结束一个 Span。"""
        span.end_time = self._now_ms()
        self._spans.append(span)
        if self._active_stack and self._active_stack[-1].span_id == span.span_id:
            self._active_stack.pop()

    def get_trace(self) -> list[Span]:
        """获取当前追踪的所有 Span。"""
        return list(self._spans)

    def reset(self) -> None:
        """重置追踪器，开始新的追踪。"""
        self._spans.clear()
        self._trace_id = ""
        self._active_stack.clear()

    def build_span_tree(self) -> dict:
        """构建 Span 树形结构。

        返回嵌套字典，根 Span 作为树的根节点。
        """
        if not self._spans:
            return {}

        # 按 parent_span_id 分组
        children_map: dict[str, list[Span]] = {}
        root_spans: list[Span] = []

        for span in self._spans:
            if span.parent_span_id is None:
                root_spans.append(span)
            else:
                children_map.setdefault(span.parent_span_id, []).append(span)

        def build_node(span: Span) -> dict:
            children = [build_node(c) for c in children_map.get(span.span_id, [])]
            return {
                "span": span.to_dict(),
                "children": children,
            }

        if root_spans:
            return build_node(root_spans[0])
        return {}

    def serialize_timeline(self) -> list[dict]:
        """将 Span 序列化为时间线格式。

        时间线格式：每个 Span 的相对开始时间、持续时间、层级深度。
        """
        if not self._spans:
            return []

        # 以最早的 Span 开始时间为基准
        base_time = min(s.start_time for s in self._spans)

        # 计算每个 Span 的层级深度
        depth_map: dict[str, int] = {}
        for span in self._spans:
            if span.parent_span_id is None:
                depth_map[span.span_id] = 0
            else:
                # 查找父 Span 的深度
                parent_depth = depth_map.get(span.parent_span_id, 0)
                depth_map[span.span_id] = parent_depth + 1

        timeline = []
        for span in sorted(self._spans, key=lambda s: s.start_time):
            timeline.append({
                "name": span.name,
                "relative_start": round(span.start_time - base_time, 2),
                "duration": round(span.duration_ms, 2),
                "depth": depth_map.get(span.span_id, 0),
                "status": span.status,
                "tags": span.tags,
            })
        return timeline

    def render_ascii_timeline(self, width: int = 60) -> str:
        """ASCII 甘特图可视化。

        用字符画出每个 Span 的时间条，直观展示调用链的时间关系。

        示例输出：
        agent.request      [0ms ──────────────────────────── 3200ms]
          llm.call         [████████████████████ 50-1200ms]
          tool.search      [      ██████████ 1250-1590ms]
          llm.call         [          ██████████████████ 1600-3100ms]
        """
        timeline = self.serialize_timeline()
        if not timeline:
            return "(empty trace)"

        # 计算总时间跨度
        total_duration = max(t["relative_start"] + t["duration"] for t in timeline)

        lines = []
        lines.append(f"Trace ID: {self._trace_id}")
        lines.append(f"Total duration: {total_duration:.0f}ms")
        lines.append("")

        for entry in timeline:
            depth = entry["depth"]
            name = entry["name"]
            indent = "  " * depth
            start = entry["relative_start"]
            dur = entry["duration"]

            # 计算时间条在可视化中的位置
            start_pos = int(start / total_duration * width) if total_duration > 0 else 0
            bar_len = max(1, int(dur / total_duration * width)) if total_duration > 0 else 1

            # 构建时间条
            bar_chars = []
            for i in range(width):
                if start_pos <= i < start_pos + bar_len:
                    bar_chars.append("#")
                else:
                    bar_chars.append("-")

            status_mark = " [ERROR]" if entry["status"] == "ERROR" else ""
            label = f"{indent}{name}"
            bar = "".join(bar_chars)
            time_info = f"{start:.0f}-{start + dur:.0f}ms"

            lines.append(f"  {label:<30s} |{bar}| {time_info}{status_mark}")

        return "\n".join(lines)


# ============================================================================
# Span Context Manager——自动管理 Span 生命周期
# ============================================================================

class SpanContext:
    """Span 上下文管理器。

    配合 with 语句使用，进入时开始 Span，退出时自动结束。
    """

    def __init__(self, tracer: Tracer, span: Span):
        self._tracer = tracer
        self._span = span

    @property
    def span(self) -> Span:
        return self._span

    def set_tag(self, key: str, value: Any) -> "SpanContext":
        """设置标签（支持链式调用）。"""
        self._span.set_tag(key, value)
        return self

    def set_error(self, error_msg: str) -> "SpanContext":
        """标记错误。"""
        self._span.set_error(error_msg)
        return self

    def __enter__(self) -> "SpanContext":
        return self

    def __exit__(self, exc_type, exc_val, exc_tb) -> None:
        if exc_type is not None:
            self._span.set_error(str(exc_val))
        self._tracer._finish_span(self._span)

# ============================================================================
```

### 第 4 题：告警引擎（阈值规则 + 异常检测 + 通知渠道抽象）

#### 知识点讲解

告警是可观测性的「最后一公里」——当指标异常时，系统必须主动通知运维人员。一个完整的告警系统包含三个核心组件：

1. **告警规则（Alert Rule）**：定义「什么条件触发告警」，如「LLM 延迟 P99 > 3000ms 持续 5 分钟」
2. **异常检测（Anomaly Detection）**：不仅支持静态阈值，还能基于历史数据动态检测异常（如 Z-Score、移动平均）
3. **通知渠道（Notification Channel）**：告警触发后的通知方式，如控制台、邮件、Webhook、Slack

**告警状态机：**
```
                  条件满足
  OK ──────────────────────► FIRING（触发中）
  ▲                            │
  │         条件恢复            │
  │◄───────────────────────────┘
  │                            │ 持续触发超时
  │                            ▼
  └──────────────────── RESOLVED（已恢复）
```

**Z-Score 异常检测原理：**
- 计算历史数据的均值 μ 和标准差 σ
- 当前值 x 的 Z-Score = (x - μ) / σ
- 如果 |Z-Score| > 阈值（如 3），则判定为异常
- 适合检测「突然偏离正常范围」的异常

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 4 题：告警引擎
- AlertRule：静态阈值规则（>、<、>= 等比较）
- AnomalyDetector：基于 Z-Score 的动态异常检测
- AlertEngine：告警状态机管理（OK -> FIRING -> RESOLVED）
- NotificationChannel：通知渠道抽象（控制台 + Webhook 模拟）
"""

import time
from typing import Optional, Callable
from dataclasses import dataclass, field
from enum import Enum

import numpy as np


# ============================================================================
# 告警状态枚举
# ============================================================================

class AlertState(Enum):
    """告警状态。"""
    OK = "OK"              # 正常，未触发
    PENDING = "PENDING"    # 条件满足但未达到持续时间要求
    FIRING = "FIRING"      # 已触发，正在通知
    RESOLVED = "RESOLVED"  # 已恢复


# ============================================================================
# 告警规则
# ============================================================================

@dataclass
class AlertRule:
    """静态阈值告警规则。

    属性：
    - name: 规则名称
    - metric_name: 监控的指标名
    - operator: 比较运算符（>、<、>=、<=、==）
    - threshold: 阈值
    - duration_sec: 持续时间要求（条件需持续满足多少秒才触发）
    - description: 规则描述
    """
    name: str
    metric_name: str
    operator: str  # ">", "<", ">=", "<=", "=="
    threshold: float
    duration_sec: float = 0  # 0 表示立即触发
    description: str = ""

    def evaluate(self, value: float) -> bool:
        """评估当前值是否满足告警条件。"""
        ops = {
            ">": lambda a, b: a > b,
            "<": lambda a, b: a < b,
            ">=": lambda a, b: a >= b,
            "<=": lambda a, b: a <= b,
            "==": lambda a, b: a == b,
        }
        check = ops.get(self.operator, lambda a, b: False)
        return check(value, self.threshold)


# ============================================================================
# Z-Score 异常检测器
# ============================================================================

class AnomalyDetector:
    """基于 Z-Score 的动态异常检测器。

    维护一个滑动窗口的历史数据，计算均值和标准差，
    当新值偏离均值超过指定标准差倍数时判定为异常。

    示例：
        detector = AnomalyDetector(window_size=100, z_threshold=3.0)
        for value in data_stream:
            is_anomaly = detector.observe(value)
            if is_anomaly:
                print(f"Anomaly detected: {value}")
    """

    def __init__(self, window_size: int = 100, z_threshold: float = 3.0):
        self.window_size = window_size
        self.z_threshold = z_threshold
        self._history: list[float] = []
        self._mean: float = 0.0
        self._std: float = 0.0

    def observe(self, value: float) -> bool:
        """观测一个新值，返回是否为异常。"""
        # 需要足够的历史数据才能判断
        if len(self._history) < self.window_size // 2:
            self._history.append(value)
            self._update_stats()
            return False

        # 计算 Z-Score
        if self._std > 0:
            z_score = abs(value - self._mean) / self._std
            is_anomaly = z_score > self.z_threshold
        else:
            is_anomaly = False

        # 更新历史窗口
        self._history.append(value)
        if len(self._history) > self.window_size:
            self._history.pop(0)

        self._update_stats()
        return is_anomaly

    def _update_stats(self) -> None:
        """更新均值和标准差。"""
        if self._history:
            arr = np.array(self._history)
            self._mean = float(np.mean(arr))
            self._std = float(np.std(arr))

    @property
    def stats(self) -> dict:
        """返回当前统计信息。"""
        return {
            "mean": round(self._mean, 2),
            "std": round(self._std, 2),
            "window_size": len(self._history),
        }

# 告警引擎
# ============================================================================

class AlertEngine:
    """告警引擎——管理告警规则、状态机和通知。

    核心流程：
    1. 注册告警规则和通知渠道
    2. 周期性评估指标值
    3. 根据评估结果更新告警状态（状态机）
    4. 状态变化时触发通知

    状态机转换：
    - OK -> PENDING: 条件首次满足
    - PENDING -> FIRING: 持续时间达到要求
    - FIRING -> RESOLVED: 条件恢复
    - RESOLVED -> OK: 重置
    """

    def __init__(self):
        self._rules: dict[str, AlertRule] = {}
        self._channels: list[NotificationChannel] = []
        # 告警状态跟踪
        self._states: dict[str, AlertState] = {}
        self._first_triggered: dict[str, float] = {}  # 首次触发时间
        self._last_values: dict[str, float] = {}  # 最近一次的值
        self._alert_history: list[dict] = []  # 告警历史记录

    def add_rule(self, rule: AlertRule) -> None:
        """注册告警规则。"""
        self._rules[rule.name] = rule
        self._states[rule.name] = AlertState.OK

    def add_channel(self, channel: NotificationChannel) -> None:
        """注册通知渠道。"""
        self._channels.append(channel)

    def evaluate(self, metric_name: str, value: float) -> None:
        """评估一个指标值，触发告警状态机。

        Args:
            metric_name: 指标名称（需与 AlertRule.metric_name 匹配）
            value: 当前指标值
        """
        self._last_values[metric_name] = value

        for rule_name, rule in self._rules.items():
            if rule.metric_name != metric_name:
                continue

            triggered = rule.evaluate(value)
            current_state = self._states[rule_name]
            now = time.time()

            if triggered:
                if current_state == AlertState.OK:
                    # OK -> PENDING
                    self._states[rule_name] = AlertState.PENDING
                    self._first_triggered[rule_name] = now

                elif current_state == AlertState.PENDING:
                    # 检查是否达到持续时间要求
                    elapsed = now - self._first_triggered.get(rule_name, now)
                    if elapsed >= rule.duration_sec:
                        # PENDING -> FIRING
                        self._states[rule_name] = AlertState.FIRING
                        self._notify(
                            rule_name,
                            f"Alert triggered: {rule.metric_name} {rule.operator} {rule.threshold} "
                            f"(current={value:.2f})",
                            severity="critical",
                        )
                        self._alert_history.append({
                            "rule": rule_name,
                            "state": "FIRING",
                            "value": value,
                            "timestamp": time.strftime("%H:%M:%S"),
                        })

                elif current_state == AlertState.RESOLVED:
                    # RESOLVED -> PENDING（重新触发）
                    self._states[rule_name] = AlertState.PENDING
                    self._first_triggered[rule_name] = now
            else:
                # 条件恢复
                if current_state in (AlertState.FIRING, AlertState.PENDING):
                    # FIRING/PENDING -> RESOLVED
                    self._states[rule_name] = AlertState.RESOLVED
                    if current_state == AlertState.FIRING:
                        self._notify(
                            rule_name,
                            f"Alert resolved: {rule.metric_name} back to normal "
                            f"(current={value:.2f})",
                            severity="info",
                        )
                    self._alert_history.append({
                        "rule": rule_name,
                        "state": "RESOLVED",
                        "value": value,
                        "timestamp": time.strftime("%H:%M:%S"),
                    })

                elif current_state == AlertState.RESOLVED:
                    # RESOLVED -> OK
                    self._states[rule_name] = AlertState.OK

    def _notify(self, rule_name: str, message: str, severity: str) -> None:
        """通过所有渠道发送通知。"""
        for channel in self._channels:
            channel.send(rule_name, message, severity)

    def get_states(self) -> dict[str, str]:
        """获取所有规则的当前状态。"""
        return {name: state.value for name, state in self._states.items()}

    def get_history(self) -> list[dict]:
        """获取告警历史。"""
        return self._alert_history
```

### 第 5 题：可观测性中间件（与 Agent Loop 集成的 before/after 钩子）

#### 知识点讲解

前三题分别实现了日志、指标、追踪，但它们是独立的组件。在实际 Agent 系统中，需要一种机制将三者**统一集成到 Agent Loop 中**——这就是可观测性中间件的作用。

```python
# -*- coding: utf-8 -*-
"""
第 5 题：可观测性中间件
- ObservabilityMiddleware：整合日志器、指标采集器、追踪器
- before/after 钩子：自动在 Agent Loop 各步骤前后注入观测逻辑
- ObservableAgent：展示中间件如何与 Agent Loop 集成
- 一键生成可观测性报告

import uuid

# 精简版日志器（复用第 1 题核心逻辑）

class SimpleLogger:
    """精简版 JSON 日志器。"""

    def __init__(self, name: str = "agent"):
        self.name = name
        self._logs: list[dict] = []

    def log(self, level: str, message: str, **kwargs) -> None:
        entry = {
            "timestamp": time.strftime("%H:%M:%S"),
            "level": level,
            "logger": self.name,
            "message": message,
            **kwargs,
        }
        self._logs.append(entry)
        print(f"  [{level}] {message}" + (f" {kwargs}" if kwargs else ""))

    def info(self, msg: str, **kw) -> None:
        self.log("INFO", msg, **kw)

    def debug(self, msg: str, **kw) -> None:
        self.log("DEBUG", msg, **kw)

    def warning(self, msg: str, **kw) -> None:
        self.log("WARN", msg, **kw)

    def error(self, msg: str, **kw) -> None:
        self.log("ERROR", msg, **kw)

    @property
    def logs(self) -> list[dict]:
        return self._logs

# 精简版指标采集器（复用第 2 题核心逻辑）
# ============================================================================

class SimpleMetrics:
    """精简版指标采集器。"""

    def __init__(self):
        self.llm_latencies: list[float] = []
        self.tool_latencies: list[float] = []
        self.e2e_latencies: list[float] = []
        self.loop_counts: list[int] = []
        self.tokens_in: int = 0
        self.tokens_out: int = 0
        self.tool_calls: int = 0
        self.tool_success: int = 0
        self.tool_failures: int = 0
        self.total_requests: int = 0
        self.active_requests: int = 0

    def percentile(self, values: list[float], q: float) -> float:
        if not values:
            return 0.0
        sv = sorted(values)
        idx = int(len(sv) * q)
        return sv[min(idx, len(sv) - 1)]

    def summary(self) -> dict:
        return {
            "requests": {"total": self.total_requests, "active": self.active_requests},
            "latency": {
                "llm_p50": round(self.percentile(self.llm_latencies, 0.5), 1),
                "llm_p99": round(self.percentile(self.llm_latencies, 0.99), 1),
                "e2e_p50": round(self.percentile(self.e2e_latencies, 0.5), 1),
                "e2e_p99": round(self.percentile(self.e2e_latencies, 0.99), 1),
            },
            "tokens": {"in": self.tokens_in, "out": self.tokens_out},
            "tools": {
                "calls": self.tool_calls,
                "success": self.tool_success,
                "failures": self.tool_failures,
                "success_rate": round(self.tool_success / max(self.tool_calls, 1), 4),
            },
            "loops": {
                "avg": round(sum(self.loop_counts) / max(len(self.loop_counts), 1), 1),
                "max": max(self.loop_counts) if self.loop_counts else 0,
            },
        }


# ============================================================================
# 精简版追踪器（复用第 3 题核心逻辑）
# ============================================================================

@dataclass
class SimpleSpan:
    """精简版 Span。"""
    name: str
    start: float
    end: float = 0.0
    parent: Optional["SimpleSpan"] = None
    tags: dict = field(default_factory=dict)

    @property
    def duration(self) -> float:
        return self.end - self.start if self.end > 0 else 0.0


class SimpleTracer:
    """精简版追踪器。"""

    def __init__(self):
        self.spans: list[SimpleSpan] = []
        self._stack: list[SimpleSpan] = []

    def start(self, name: str, **tags) -> SimpleSpan:
        parent = self._stack[-1] if self._stack else None
        span = SimpleSpan(name=name, start=time.time() * 1000, parent=parent, tags=tags)
        self._stack.append(span)
        return span

    def end(self, span: SimpleSpan) -> None:
        span.end = time.time() * 1000
        self.spans.append(span)
        if self._stack and self._stack[-1] is span:
            self._stack.pop()

    def reset(self) -> None:
        self.spans.clear()
        self._stack.clear()

    def timeline(self) -> list[dict]:
        if not self.spans:
            return []
        base = min(s.start for s in self.spans)
        depth_map: dict[int, int] = {}
        for i, span in enumerate(self.spans):
            if span.parent is None:
                depth_map[i] = 0
            else:
                pidx = self.spans.index(span.parent)
                depth_map[i] = depth_map.get(pidx, 0) + 1
        result = []
        for i, span in enumerate(self.spans):
            result.append({
                "name": span.name,
                "start": round(span.start - base, 1),
                "duration": round(span.duration, 1),
                "depth": depth_map.get(i, 0),
            })
        return result


# ============================================================================
# 可观测性中间件
# ============================================================================

class ObservabilityMiddleware:
    """可观测性中间件——整合日志、指标、追踪。

    通过 before/after 钩子在 Agent Loop 各步骤前后自动注入观测逻辑。
    Agent 核心代码无需感知观测组件的存在。

    钩子方法：
    - before_request: 请求开始时设置上下文、启动追踪
    - after_request: 请求结束时记录端到端指标
    - before_llm_call: LLM 调用前启动 Span、记录开始时间
    - after_llm_call: LLM 调用后记录延迟和 token 指标
    - before_tool_call: 工具调用前启动 Span
    - after_tool_call: 工具调用后记录延迟和成功率
    """

    def __init__(self):
        self.logger = SimpleLogger("agent")
        self.metrics = SimpleMetrics()
        self.tracer = SimpleTracer()
        self._request_id: str = ""
        self._request_start: float = 0.0
        self._loop_count: int = 0

    # --- 请求级别钩子 ---

    def before_request(self, query: str, user_id: str = "anonymous") -> str:
        """请求开始前的钩子。"""
        self._request_id = f"req-{uuid.uuid4().hex[:8]}"
        self._request_start = time.time() * 1000
        self._loop_count = 0

        self.metrics.active_requests += 1
        self.logger.info(
            f"Request started [{self._request_id}]",
            query=query[:50],
            user_id=user_id,
        )
        self._root_span = self.tracer.start("agent.request", request_id=self._request_id)
        return self._request_id

    def after_request(self, response: str) -> None:
        """请求结束后的钩子。"""
        e2e_ms = time.time() * 1000 - self._request_start
        self.metrics.e2e_latencies.append(e2e_ms)
        self.metrics.loop_counts.append(self._loop_count)
        self.metrics.total_requests += 1
        self.metrics.active_requests -= 1

        self.tracer.end(self._root_span)
        self.logger.info(
            f"Request completed [{self._request_id}]",
            e2e_ms=round(e2e_ms, 1),
            loops=self._loop_count,
        )

    # --- LLM 调用钩子 ---

    def before_llm_call(self, model: str, messages: list) -> SimpleSpan:
        """LLM 调用前的钩子。"""
        self._loop_count += 1
        span = self.tracer.start("llm.call", model=model, round=self._loop_count)
        self.logger.debug(f"LLM call started", model=model, round=self._loop_count)
        return span

    def after_llm_call(self, span: SimpleSpan, response: str, tokens_in: int, tokens_out: int) -> None:
        """LLM 调用后的钩子。"""
        self.tracer.end(span)
        latency = span.duration
        self.metrics.llm_latencies.append(latency)
        self.metrics.tokens_in += tokens_in
        self.metrics.tokens_out += tokens_out
        self.logger.debug(
            f"LLM call completed",
            latency_ms=round(latency, 1),
            tokens_in=tokens_in,
            tokens_out=tokens_out,
        )

    # --- 工具调用钩子 ---

    def before_tool_call(self, tool_name: str, args: dict) -> SimpleSpan:
        """工具调用前的钩子。"""
        span = self.tracer.start(f"tool.{tool_name}", tool=tool_name)
        self.logger.debug(f"Tool call started", tool=tool_name)
        return span

    def after_tool_call(self, span: SimpleSpan, tool_name: str, success: bool, result: str = "") -> None:
        """工具调用后的钩子。"""
        self.tracer.end(span)
        latency = span.duration
        self.metrics.tool_latencies.append(latency)
        self.metrics.tool_calls += 1
        if success:
            self.metrics.tool_success += 1
        else:
            self.metrics.tool_failures += 1
        self.logger.info(
            f"Tool call completed",
            tool=tool_name,
            success=success,
            latency_ms=round(latency, 1),
        )

    # --- 报告生成 ---

    def generate_report(self) -> str:
        """生成可观测性报告。"""
        m = self.metrics.summary()
        lines = [
            "=" * 60,
            "  Observability Report",
            "=" * 60,
            f"\nRequests: total={m['requests']['total']}, active={m['requests']['active']}",
            f"\nLatency (ms):",
            f"  LLM:  P50={m['latency']['llm_p50']}, P99={m['latency']['llm_p99']}",
            f"  E2E:  P50={m['latency']['e2e_p50']}, P99={m['latency']['e2e_p99']}",
            f"\nTokens: in={m['tokens']['in']}, out={m['tokens']['out']}",
            f"\nTools: calls={m['tools']['calls']}, success={m['tools']['success']}, "
            f"rate={m['tools']['success_rate']:.1%}",
            f"\nLoops: avg={m['loops']['avg']}, max={m['loops']['max']}",
            f"\nTotal log entries: {len(self.logger.logs)}",
            f"Total spans: {len(self.tracer.spans)}",
            "\n" + "=" * 60,
        ]
        return "\n".join(lines)


# ============================================================================
# 可观测 Agent——展示中间件与 Agent Loop 的集成
# ============================================================================

class ObservableAgent:
    """集成了可观测性中间件的 Agent。

    Agent 的核心逻辑（LLM 调用、工具执行）保持不变，
    所有观测逻辑通过中间件的 before/after 钩子自动注入。
    """

    def __init__(self, model: str = "gpt-4"):
        self.model = model
        self.middleware = ObservabilityMiddleware()

    def _mock_llm_call(self, messages: list) -> tuple[str, int, int]:
        """模拟 LLM 调用（实际环境替换为真实 API 调用）。"""
        time.sleep(0.05)  # 模拟推理延迟
        response = f"Processed: {messages[-1].get('content', '')[:30]}..."
        tokens_in = sum(len(m.get("content", "").split()) for m in messages) * 2
        tokens_out = len(response.split()) * 2
        return response, tokens_in, tokens_out

    def _mock_tool_call(self, tool_name: str, args: dict) -> tuple[bool, str]:
        """模拟工具调用。"""
        time.sleep(0.02)  # 模拟工具执行延迟
        # 模拟 85% 成功率
        import random
        success = random.random() < 0.85
        if success:
            return True, f"Result from {tool_name}: ..."
        else:
            return False, f"Error: {tool_name} failed"

    def run(self, query: str, user_id: str = "anonymous") -> str:
        """运行 Agent——完整集成可观测性中间件。"""
        # 请求开始
        self.middleware.before_request(query, user_id)

        try:
            messages = [{"role": "user", "content": query}]

            # Agent Loop（简化版：2 轮迭代）
            for iteration in range(2):
                # LLM 调用
                span = self.middleware.before_llm_call(self.model, messages)
                response, tokens_in, tokens_out = self._mock_llm_call(messages)
                self.middleware.after_llm_call(span, response, tokens_in, tokens_out)

                messages.append({"role": "assistant", "content": response})

                # 第一轮后调用工具
                if iteration == 0:
                    tool_span = self.middleware.before_tool_call("search", {"query": query})
                    success, result = self._mock_tool_call("search", {"query": query})
                    self.middleware.after_tool_call(tool_span, "search", success, result)
                    messages.append({"role": "tool", "content": result})

            final_response = response

        except Exception as e:
            self.middleware.logger.error(f"Agent error: {e}")
            final_response = f"Error: {e}"
        finally:
            # 请求结束
            self.middleware.after_request(final_response)

        return final_response
```

## 模块二：AI Gateways（AI 网关）

### AI 网关核心功能总览

AI 网关是 Agent 系统的「交通枢纽」——所有 LLM 调用都经过网关，由网关统一管理路由、限流、降级和负载均衡。

| 核心功能 | 解决什么问题 | 对应练习 |
|---------|------------|---------|
| 统一路由 | 不同任务匹配最优模型 | 第 6 题 |
| 限流保护 | 防止 API 配额耗尽、控制成本 | 第 7 题 |
| 降级容错 | 主模型故障时自动切换备用 | 第 8 题 |
| AB 测试 | 对比不同模型效果、灰度发布 | 第 9 题 |

```
用户请求 ──► AI Gateway ──► 路由决策 ──► 限流检查 ──► 模型调用 ──► 响应
                │              │            │           │
                │              │            │           ├─ 成功 → 返回
                │              │            │           └─ 失败 → 降级链
                │              │            └─ 超限 → 排队/拒绝
                │              └─ 按能力/成本/延迟选模型
                └─ 统一入口、日志、指标
```

### 第 6 题：AI 网关路由器（多模型注册 + 能力匹配 + 成本/延迟路由）

#### 知识点讲解

AI 网关路由器的核心任务是：**根据请求特征，选择最合适的模型来处理**。

**三种路由策略：**

1. **能力路由**：根据任务类型匹配模型能力
   - 代码生成 → 选择擅长编程的模型（如 DeepSeek-Coder）
   - 日常对话 → 选择快速便宜的模型（如 GPT-4o-mini）
   - 复杂推理 → 选择强推理能力的模型（如 GPT-4 / Claude-3.5-Sonnet）

2. **成本路由**：在满足质量要求的前提下选择最便宜的模型
   - 按每百万 token 的输入/输出价格排序
   - 设置质量阈值，低于阈值的模型不选

3. **延迟路由**：选择响应最快的模型
   - 维护各模型的 P50/P99 延迟统计
   - 对延迟敏感的请求优先选择快速模型

```
路由决策流程：

请求进入
  │
  ├─ 任务类型 = "code" ──► 候选: [DeepSeek-Coder, GPT-4, Claude-3.5]
  │                         │
  │                         ├─ 按成本排序 ──► DeepSeek-Coder ($0.14/M)
  │                         ├─ 按延迟排序 ──► GPT-4 (P50=800ms)
  │                         └─ 综合 ──► DeepSeek-Coder
  │
  ├─ 任务类型 = "chat" ──► 候选: [GPT-4o-mini, Claude-3-Haiku]
  │                         └─ 成本优先 ──► GPT-4o-mini ($0.15/M)
  │
  └─ 任务类型 = "reasoning" ──► 候选: [GPT-4, Claude-3.5-Sonnet, o1]
                               └─ 质量优先 ──► GPT-4
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 6 题：AI 网关路由器
- ModelInfo：模型注册信息（名称、能力、成本、延迟）
- GatewayRouter：多策略路由（能力匹配 + 成本优先 + 延迟优先）
- 负载均衡：加权轮询
"""

import time
from typing import Optional
from dataclasses import dataclass, field
from enum import Enum

import numpy as np


# ============================================================================
# 模型能力枚举
# ============================================================================

class ModelCapability(Enum):
    """模型能力标签。"""
    CHAT = "chat"                # 日常对话
    CODE = "code"                # 代码生成
    REASONING = "reasoning"      # 复杂推理
    VISION = "vision"            # 视觉理解
    EMBEDDING = "embedding"      # 向量嵌入


# ============================================================================
# 模型信息
# ============================================================================

@dataclass
class ModelInfo:
    """已注册的模型信息。

    属性：
    - name: 模型名称
    - capabilities: 支持的能力列表
    - cost_per_million_input: 每百万输入 token 价格（美元）
    - cost_per_million_output: 每百万输出 token 价格（美元）
    - avg_latency_ms: 平均延迟（毫秒）
    - quality_score: 质量评分（0-10）
    - max_tokens: 最大上下文长度
    - weight: 负载均衡权重
    """
    name: str
    capabilities: list[ModelCapability]
    cost_per_million_input: float
    cost_per_million_output: float
    avg_latency_ms: float
    quality_score: float  # 0-10
    max_tokens: int = 128000
    weight: int = 1

    @property
    def avg_cost_per_million(self) -> float:
        """平均每百万 token 成本（输入+输出的平均值）。"""
        return (self.cost_per_million_input + self.cost_per_million_output) / 2


# ============================================================================
# 路由策略枚举
# ============================================================================

class RouteStrategy(Enum):
    """路由策略。"""
    CAPABILITY = "capability"     # 按能力匹配
    COST = "cost"                 # 按成本优先
    LATENCY = "latency"           # 按延迟优先
    QUALITY = "quality"           # 按质量优先
    WEIGHTED = "weighted"         # 加权轮询


# ============================================================================
# AI 网关路由器
# ============================================================================

class GatewayRouter:
    """AI 网关路由器。

    核心功能：
    1. 注册多个模型
    2. 根据请求的能力需求和路由策略选择模型
    3. 支持加权负载均衡
    4. 记录路由决策日志

    使用示例：
        router = GatewayRouter()
        router.register(ModelInfo("gpt-4", [ModelCapability.CHAT, ModelCapability.REASONING], 30, 60, 1200, 9.0))
        router.register(ModelInfo("gpt-4o-mini", [ModelCapability.CHAT], 0.15, 0.6, 300, 7.0))

        model = router.route(ModelCapability.CHAT, RouteStrategy.COST)
        # -> gpt-4o-mini（最便宜）
    """

    def __init__(self):
        self._models: dict[str, ModelInfo] = {}
        # 加权轮询状态
        self._rr_counters: dict[str, int] = {}

    def register(self, model: ModelInfo) -> None:
        """注册一个模型。"""
        self._models[model.name] = model
        self._rr_counters[model.name] = 0

    def unregister(self, model_name: str) -> None:
        """注销一个模型。"""
        self._models.pop(model_name, None)
        self._rr_counters.pop(model_name, None)

    def list_models(self) -> list[ModelInfo]:
        """列出所有已注册模型。"""
        return list(self._models.values())

    def route(
        self,
        required_capability: ModelCapability,
        strategy: RouteStrategy = RouteStrategy.CAPABILITY,
        max_cost: Optional[float] = None,
        max_latency: Optional[float] = None,
        min_quality: Optional[float] = None,
    ) -> Optional[ModelInfo]:
        """根据策略路由到合适的模型。

        Args:
            required_capability: 请求需要的能力
            strategy: 路由策略
            max_cost: 最大成本限制（美元/百万token）
            max_latency: 最大延迟限制（毫秒）
            min_quality: 最低质量要求

        Returns:
            选中的模型信息，如果没有匹配则返回 None
        """
        # 第一步：按能力过滤
        candidates = [
            m for m in self._models.values()
            if required_capability in m.capabilities
        ]

        if not candidates:
            return None

        # 第二步：应用约束条件
        if max_cost is not None:
            candidates = [m for m in candidates if m.avg_cost_per_million <= max_cost]
        if max_latency is not None:
            candidates = [m for m in candidates if m.avg_latency_ms <= max_latency]
        if min_quality is not None:
            candidates = [m for m in candidates if m.quality_score >= min_quality]

        if not candidates:
            return None

        # 第三步：按策略选择
        if strategy == RouteStrategy.COST:
            return min(candidates, key=lambda m: m.avg_cost_per_million)
        elif strategy == RouteStrategy.LATENCY:
            return min(candidates, key=lambda m: m.avg_latency_ms)
        elif strategy == RouteStrategy.QUALITY:
            return max(candidates, key=lambda m: m.quality_score)
        elif strategy == RouteStrategy.WEIGHTED:
            return self._weighted_round_robin(candidates)
        else:  # CAPABILITY 或默认
            # 能力匹配模式下，综合评分（质量/成本比）
            return max(candidates, key=lambda m: m.quality_score / max(m.avg_cost_per_million, 0.01))

    def _weighted_round_robin(self, candidates: list[ModelInfo]) -> ModelInfo:
        """加权轮询选择。"""
        # 简化实现：基于权重的随机选择
        weights = np.array([m.weight for m in candidates], dtype=float)
        probs = weights / weights.sum()
        idx = int(np.random.choice(len(candidates), p=probs))
        self._rr_counters[candidates[idx].name] += 1
        return candidates[idx]

    def route_multi(
        self,
        required_capabilities: list[ModelCapability],
        strategy: RouteStrategy = RouteStrategy.COST,
    ) -> list[ModelInfo]:
        """为多个能力需求分别路由（一个请求可能需要多种能力）。"""
        results = []
        for cap in required_capabilities:
            model = self.route(cap, strategy)
            if model and model not in results:
                results.append(model)
        return results

    def get_routing_table(self) -> list[dict]:
        """生成路由表（用于可视化）。"""
        table = []
        for m in self._models.values():
            table.append({
                "name": m.name,
                "capabilities": [c.value for c in m.capabilities],
                "cost_avg": round(m.avg_cost_per_million, 2),
                "latency_ms": m.avg_latency_ms,
                "quality": m.quality_score,
                "weight": m.weight,
                "rr_count": self._rr_counters.get(m.name, 0),
            })
        return table


# ============================================================================
# 测试与演示
# ============================================================================

def demo_router():
    """演示 AI 网关路由器的完整功能。"""
    print("=" * 70)
    print("  Exercise 6: AI Gateway Router")
    print("=" * 70)

    router = GatewayRouter()

    # 注册多个模型
    router.register(ModelInfo(
        "gpt-4", [ModelCapability.CHAT, ModelCapability.REASONING, ModelCapability.CODE],

    ))
    router.register(ModelInfo(

        cost_per_million_input=0.15, cost_per_million_output=0.6,
        avg_latency_ms=300, quality_score=7.0, weight=3,
    ))
    router.register(ModelInfo(
        "claude-3.5-sonnet", [ModelCapability.CHAT, ModelCapability.REASONING, ModelCapability.CODE, ModelCapability.VISION],
        cost_per_million_input=3, cost_per_million_output=15,
        avg_latency_ms=900, quality_score=8.5, weight=2,
    ))
    router.register(ModelInfo(
        "deepseek-coder", [ModelCapability.CODE],
        cost_per_million_input=0.14, cost_per_million_output=0.28,
        avg_latency_ms=500, quality_score=8.0, weight=2,
    ))
    router.register(ModelInfo(
        "o1-preview", [ModelCapability.REASONING],
        cost_per_million_input=15, cost_per_million_output=60,
        avg_latency_ms=5000, quality_score=9.5, weight=1,

    # 打印路由表
    print("\n--- Registered Models ---")
    print(f"  {'Model':<22s} {'Capabilities':<35s} {'Cost/M':>7s} {'Latency':>8s} {'Quality':>8s}")
    for m in router.get_routing_table():
        caps = ",".join(m["capabilities"])
        print(f"  {m['name']:<22s} {caps:<35s} ${m['cost_avg']:>5.2f}  {m['latency_ms']:>6.0f}ms  {m['quality']:>6.1f}")

    print("\n--- Scenario 1: Route by Capability ---")
    for cap in [ModelCapability.CHAT, ModelCapability.CODE, ModelCapability.REASONING, ModelCapability.VISION]:
        model = router.route(cap, RouteStrategy.CAPABILITY)
        print(f"  {cap.value:<12s} -> {model.name if model else 'None'}")

    # 场景 2：按成本路由
    print("\n--- Scenario 2: Route by Cost ---")
    for cap in [ModelCapability.CHAT, ModelCapability.CODE, ModelCapability.REASONING]:
        model = router.route(cap, RouteStrategy.COST)
        if model:
            print(f"  {cap.value:<12s} -> {model.name:<22s} (${model.avg_cost_per_million:.2f}/M)")

    # 场景 3：按延迟路由
    print("\n--- Scenario 3: Route by Latency ---")
    for cap in [ModelCapability.CHAT, ModelCapability.CODE, ModelCapability.REASONING]:
        model = router.route(cap, RouteStrategy.LATENCY)
        if model:
            print(f"  {cap.value:<12s} -> {model.name:<22s} ({model.avg_latency_ms:.0f}ms)")

    # 场景 4：带约束条件的路由
    print("\n--- Scenario 4: Route with Constraints ---")
    model = router.route(
```

### 第 7 题：令牌桶限流器（per-key + per-model 双维度限流）

#### 知识点讲解

限流是保护 Agent 系统的关键机制——LLM API 有严格的速率限制（RPM/TPM），不加限流会导致 429 错误甚至封禁。

**令牌桶算法原理：**

```
令牌桶模型：

  ┌─────────┐  以固定速率 R 添加令牌
  │ 令牌生成 │ ────► [桶] 容量 C（最多存 C 个令牌）
  └─────────┘         │
                      │ 请求到达时：
                      │ - 桶中有 >= N 个令牌 → 取走 N 个，放行
                      │ - 桶中令牌不足 → 排队等待或拒绝
                      ▼
                   请求处理

参数说明：
  - capacity (C): 桶容量 = 突发流量上限
  - rate (R): 令牌生成速率 = 平均流量上限
  - tokens: 当前令牌数（随时间增长，随请求消耗）

示例：
  capacity = 100, rate = 10/s
  - 突发：瞬间 100 个请求可以全部放行（桶满时）
  - 持续：稳态下每秒最多放行 10 个请求
```

**双维度限流：**
Agent 系统需要同时限制：
- **per-key**：每个 API key 的请求速率（防止单用户耗尽配额）
- **per-model**：每个模型的总请求速率（防止超出模型供应商限制）

```
请求: key=user-001, model=gpt-4
  │
  ├─ 检查 key=user-001 的令牌桶 → 有令牌？
  │     └─ 否 → 拒绝（用户限流）
  │
  └─ 检查 model=gpt-4 的令牌桶 → 有令牌？
        └─ 否 → 拒绝（模型限流）
        └─ 是 → 放行，两个桶各扣减令牌
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 7 题：令牌桶限流器
- TokenBucket：令牌桶核心实现（容量、速率、懒更新）
- RateLimiter：双维度限流（per-key + per-model）
- RateLimitResult：限流结果（允许/拒绝/排队等待时间）
- 统计：通过率、拒绝率、各维度令牌余量
"""

import time
from typing import Optional
from dataclasses import dataclass, field
from enum import Enum

import numpy as np


# ============================================================================
# 限流结果
# ============================================================================

class RateLimitDecision(Enum):
    """限流决策。"""
    ALLOWED = "ALLOWED"        # 放行
    REJECTED = "REJECTED"      # 拒绝（令牌不足）
    RETRY = "RETRY"            # 需要等待后重试


@dataclass
class RateLimitResult:
    """限流检查结果。"""
    decision: RateLimitDecision
    remaining_tokens: float = 0.0
    wait_time_sec: float = 0.0  # 如果需要等待，预计等待时间
    reason: str = ""


# ============================================================================
# 令牌桶
# ============================================================================

class TokenBucket:
    """令牌桶限流器。

    核心算法：
    - 桶中以固定速率 rate 添加令牌（每秒 rate 个）
    - 桶最多存 capacity 个令牌（超出则丢弃）
    - 请求需要消耗 tokens 个令牌
    - 采用「懒更新」策略：不使用后台线程添加令牌，
      而是在每次检查时根据时间差计算应添加的令牌数

    时间复杂度：O(1) 每次 acquire
    空间复杂度：O(1) 每个桶

    示例：
        bucket = TokenBucket(capacity=100, rate=10)  # 100容量，10/s
        result = bucket.acquire(tokens=1)
        if result.decision == RateLimitDecision.ALLOWED:
            # 放行请求
            pass
    """

    def __init__(self, capacity: float, rate: float):
        """
        Args:
            capacity: 桶容量（最大令牌数 = 突发流量上限）
            rate: 令牌生成速率（每秒生成 rate 个令牌 = 平均流量上限）
        """
        self.capacity = capacity
        self.rate = rate  # tokens per second
        self._tokens: float = capacity  # 初始满桶
        self._last_update: float = time.monotonic()

    def _refill(self) -> None:
        """懒更新——根据时间差补充令牌。"""
        now = time.monotonic()
        elapsed = now - self._last_update
        # 计算应添加的令牌数
        tokens_to_add = elapsed * self.rate
        # 更新令牌数（不超过容量）
        self._tokens = min(self.capacity, self._tokens + tokens_to_add)
        self._last_update = now

    def acquire(self, tokens: float = 1) -> RateLimitResult:
        """尝试获取令牌。

        Args:
            tokens: 需要消耗的令牌数

        Returns:
            RateLimitResult: 决策结果
        """
        self._refill()

        if self._tokens >= tokens:
            # 令牌充足，放行
            self._tokens -= tokens
            return RateLimitResult(
                decision=RateLimitDecision.ALLOWED,
                remaining_tokens=self._tokens,
            )
        else:
            # 令牌不足，计算需要等待的时间
            deficit = tokens - self._tokens
            wait_time = deficit / self.rate if self.rate > 0 else float("inf")
            return RateLimitResult(
                decision=RateLimitDecision.REJECTED,
                remaining_tokens=self._tokens,
                wait_time_sec=wait_time,
                reason=f"Insufficient tokens: need {tokens}, have {self._tokens:.1f}",
            )

    def try_acquire(self, tokens: float = 1) -> bool:
        """简化版：只返回是否成功。"""
        return self.acquire(tokens).decision == RateLimitDecision.ALLOWED

    @property
    def available_tokens(self) -> float:
        """当前可用令牌数（触发懒更新）。"""
        self._refill()
        return self._tokens

    def snapshot(self) -> dict:
        """获取桶状态快照。"""
        return {
            "capacity": self.capacity,
            "rate": self.rate,
            "tokens": round(self.available_tokens, 2),
            "utilization": round(1 - self.available_tokens / self.capacity, 4),
        }


# ============================================================================
# 双维度限流器
# ============================================================================

class RateLimiter:
    """双维度限流器（per-key + per-model）。

    维护两组令牌桶：
    - key_buckets: 每个 API key 的限流桶
    - model_buckets: 每个模型的全局限流桶

    请求必须同时通过两个维度的检查才能放行。

    示例：
        limiter = RateLimiter(
            default_key_rate=10,    # 每个 key: 10 req/s
            default_key_capacity=20,
            default_model_rate=50,  # 每个模型: 50 req/s
            default_model_capacity=100,
        )
        result = limiter.check(key="user-001", model="gpt-4")
    """

    def __init__(
        self,
        default_key_rate: float = 10,
        default_key_capacity: float = 20,
        default_model_rate: float = 50,
        default_model_capacity: float = 100,
    ):
        self.default_key_rate = default_key_rate
        self.default_key_capacity = default_key_capacity
        self.default_model_rate = default_model_rate
        self.default_model_capacity = default_model_capacity

        self._key_buckets: dict[str, TokenBucket] = {}
        self._model_buckets: dict[str, TokenBucket] = {}

        # 自定义限流配置
        self._key_config: dict[str, tuple[float, float]] = {}  # key -> (rate, capacity)
        self._model_config: dict[str, tuple[float, float]] = {}

        # 统计
        self._stats = {
            "total_requests": 0,
            "allowed": 0,
            "rejected_key": 0,
            "rejected_model": 0,
            "by_key": {},
            "by_model": {},
        }

    def configure_key(self, key: str, rate: float, capacity: float) -> None:
        """为特定 key 配置自定义限流参数。"""
        self._key_config[key] = (rate, capacity)
        if key in self._key_buckets:
            self._key_buckets[key] = TokenBucket(capacity, rate)

    def configure_model(self, model: str, rate: float, capacity: float) -> None:
        """为特定模型配置自定义限流参数。"""
        self._model_config[model] = (rate, capacity)
        if model in self._model_buckets:
            self._model_buckets[model] = TokenBucket(capacity, rate)

    def _get_key_bucket(self, key: str) -> TokenBucket:
        """获取或创建 key 的令牌桶。"""
        if key not in self._key_buckets:
            rate, cap = self._key_config.get(key, (self.default_key_rate, self.default_key_capacity))
            self._key_buckets[key] = TokenBucket(cap, rate)
        return self._key_buckets[key]

    def _get_model_bucket(self, model: str) -> TokenBucket:
        """获取或创建 model 的令牌桶。"""
        if model not in self._model_buckets:
            rate, cap = self._model_config.get(model, (self.default_model_rate, self.default_model_capacity))
            self._model_buckets[model] = TokenBucket(cap, rate)
        return self._model_buckets[model]

    def check(self, key: str, model: str, tokens: float = 1) -> RateLimitResult:
        """检查请求是否允许通过（双维度检查）。

        Args:
            key: API key / 用户标识
            model: 模型名称
            tokens: 需要消耗的令牌数

        Returns:
            RateLimitResult: 检查结果
        """
        self._stats["total_requests"] += 1

        # 更新按 key/model 的请求计数
        self._stats["by_key"][key] = self._stats["by_key"].get(key, 0) + 1
        self._stats["by_model"][model] = self._stats["by_model"].get(model, 0) + 1

        # 维度 1：检查 key 限流
        key_bucket = self._get_key_bucket(key)
        key_result = key_bucket.acquire(tokens)

        if key_result.decision != RateLimitDecision.ALLOWED:
            self._stats["rejected_key"] += 1
            return RateLimitResult(
                decision=RateLimitDecision.REJECTED,
                remaining_tokens=key_result.remaining_tokens,
                wait_time_sec=key_result.wait_time_sec,
                reason=f"Key '{key}' rate limited: {key_result.reason}",
            )

        # 维度 2：检查 model 限流
        model_bucket = self._get_model_bucket(model)
        model_result = model_bucket.acquire(tokens)

        if model_result.decision != RateLimitDecision.ALLOWED:
            # 回退 key 的令牌（因为 model 维度拒绝了）
            key_bucket._tokens += tokens
            self._stats["rejected_model"] += 1
            return RateLimitResult(
                decision=RateLimitDecision.REJECTED,
                remaining_tokens=model_result.remaining_tokens,
                wait_time_sec=model_result.wait_time_sec,
                reason=f"Model '{model}' rate limited: {model_result.reason}",
            )

        # 两个维度都通过
        self._stats["allowed"] += 1
        return RateLimitResult(
            decision=RateLimitDecision.ALLOWED,
            remaining_tokens=min(key_result.remaining_tokens, model_result.remaining_tokens),
        )

    def get_stats(self) -> dict:
        """获取限流统计。"""
        s = self._stats
        total = s["total_requests"]
        return {
            "total_requests": total,
            "allowed": s["allowed"],
            "rejected_key": s["rejected_key"],
            "rejected_model": s["rejected_model"],
            "allow_rate": round(s["allowed"] / max(total, 1), 4),
            "reject_rate": round((s["rejected_key"] + s["rejected_model"]) / max(total, 1), 4),
        }

    def get_bucket_status(self) -> dict:
        """获取所有令牌桶的状态。"""
        return {
            "key_buckets": {k: b.snapshot() for k, b in self._key_buckets.items()},
            "model_buckets": {k: b.snapshot() for k, b in self._model_buckets.items()},
        }
```

### 第 8 题：模型降级链（超时检测 → 自动切换 → 兜底响应）

#### 知识点讲解

LLM 服务不是 100% 可靠的——模型可能超时、限流、宕机。降级链确保在主模型故障时，Agent 能自动切换到备用模型，最终给出兜底响应，而不是直接报错。

**降级链工作流程：**

```
请求
  │
  ▼
┌─────────────────────────────────────────────────────────┐
│  层级 1: 主模型 (gpt-4)                                  │
│  - 超时阈值: 5s                                          │
│  - 如果成功 → 返回结果                                    │
│  - 如果超时/错误 → 降级到层级 2                           │
├─────────────────────────────────────────────────────────┤
│  层级 2: 备用模型 (claude-3.5-sonnet)                    │
│  - 超时阈值: 8s                                          │
│  - 如果成功 → 返回结果                                    │
│  - 如果超时/错误 → 降级到层级 3                           │
├─────────────────────────────────────────────────────────┤
│  层级 3: 轻量模型 (gpt-4o-mini)                          │
│  - 超时阈值: 3s                                          │
│  - 如果成功 → 返回结果                                    │
│  - 如果超时/错误 → 降级到层级 4                           │
├─────────────────────────────────────────────────────────┤
│  层级 4: 兜底响应                                         │
│  - 返回预设的降级提示                                     │
│  - 记录降级事件，触发告警                                  │
└─────────────────────────────────────────────────────────┘
```

**关键设计：**
1. **熔断器**：连续失败 N 次后短路跳过该模型（而不是每次都等超时）
2. **超时检测**：非阻塞式超时，避免请求堆积
3. **降级事件记录**：记录每次降级的原因和耗时，用于后续分析

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 8 题：模型降级链
- CircuitBreaker：熔断器（连续失败后短路）
- FallbackLayer：降级层（模型 + 超时 + 熔断器）
- FallbackChain：降级链（多层串联 + 兜底响应）
- 降级事件追踪与统计
"""

import time
from typing import Optional, Callable, Any
from dataclasses import dataclass, field
from enum import Enum

import numpy as np


# ============================================================================
# 熔断器
# ============================================================================

class CircuitState(Enum):
    """熔断器状态。"""
    CLOSED = "CLOSED"      # 正常，允许请求通过
    OPEN = "OPEN"          # 熔断，直接拒绝（短路）
    HALF_OPEN = "HALF_OPEN"  # 半开，允许试探性请求


class CircuitBreaker:
    """熔断器——连续失败后自动短路。

    状态机：
    - CLOSED -> OPEN: 连续失败次数 >= failure_threshold
    - OPEN -> HALF_OPEN: 经过 recovery_timeout 后
    - HALF_OPEN -> CLOSED: 下一次请求成功
    - HALF_OPEN -> OPEN: 下一次请求失败

    示例：
        cb = CircuitBreaker(failure_threshold=3, recovery_timeout=10)
        if cb.can_execute():
            try:
                result = call_api()
                cb.record_success()
            except Exception:
                cb.record_failure()
    """

    def __init__(self, failure_threshold: int = 3, recovery_timeout: float = 10.0):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self._state = CircuitState.CLOSED
        self._failure_count = 0
        self._last_failure_time: float = 0

    @property
    def state(self) -> CircuitState:
        """获取当前状态（可能触发 OPEN -> HALF_OPEN 转换）。"""
        if self._state == CircuitState.OPEN:
            if time.time() - self._last_failure_time >= self.recovery_timeout:
                self._state = CircuitState.HALF_OPEN
        return self._state

    def can_execute(self) -> bool:
        """是否允许执行请求。"""
        state = self.state
        return state in (CircuitState.CLOSED, CircuitState.HALF_OPEN)

    def record_success(self) -> None:
        """记录一次成功。"""
        self._failure_count = 0
        self._state = CircuitState.CLOSED

    def record_failure(self) -> None:
        """记录一次失败。"""
        self._failure_count += 1
        self._last_failure_time = time.time()
        if self._state == CircuitState.HALF_OPEN:
            # 半开状态下失败，重新打开
            self._state = CircuitState.OPEN
        elif self._failure_count >= self.failure_threshold:
            self._state = CircuitState.OPEN

    def reset(self) -> None:
        """重置熔断器。"""
        self._state = CircuitState.CLOSED
        self._failure_count = 0


# ============================================================================
# 降级事件
# ============================================================================

@dataclass
class FallbackEvent:
    """降级事件记录。"""
    layer_name: str
    model_name: str
    reason: str  # "timeout" / "error" / "circuit_open" / "success"
    latency_ms: float
    timestamp: str = field(default_factory=lambda: time.strftime("%H:%M:%S"))


# ============================================================================
# 降级层
# ============================================================================

@dataclass
class FallbackLayer:
    """降级链中的一层。

    每层包含：
    - model_name: 模型名称
    - handler: 调用函数（模拟 LLM API 调用）
    - timeout_sec: 超时阈值
    - circuit_breaker: 熔断器
    """
    model_name: str
    handler: Callable[[], str]
    timeout_sec: float
    circuit_breaker: CircuitBreaker = field(default_factory=CircuitBreaker)

    def execute(self) -> tuple[bool, str, str, float]:
        """执行本层调用。

        Returns:
            (success, result, reason, latency_ms)
        """
        # 检查熔断器
        if not self.circuit_breaker.can_execute():
            return False, "", "circuit_open", 0.0

        start = time.time()
        try:
            # 模拟超时检测
            result = self.handler()
            latency = (time.time() - start) * 1000

            if latency > self.timeout_sec * 1000:
                # 超时
                self.circuit_breaker.record_failure()
                return False, "", "timeout", latency

            self.circuit_breaker.record_success()
            return True, result, "success", latency

        except Exception as e:
            latency = (time.time() - start) * 1000
            self.circuit_breaker.record_failure()
            return False, "", f"error: {str(e)}", latency


# ============================================================================
# 降级链
# ============================================================================

class FallbackChain:
    """模型降级链。

    将多个降级层串联，依次尝试直到成功或到达兜底响应。

    使用示例：
        chain = FallbackChain()
        chain.add_layer("gpt-4", call_gpt4, timeout_sec=5)
        chain.add_layer("claude-3.5", call_claude, timeout_sec=8)
        chain.add_layer("gpt-4o-mini", call_mini, timeout_sec=3)
        chain.set_fallback_response("Service temporarily unavailable.")

        result = chain.execute()
    """

    def __init__(self):
        self._layers: list[FallbackLayer] = []
        self._fallback_response: str = "Service temporarily unavailable. Please try again later."
        self._events: list[FallbackEvent] = []

    def add_layer(
        self,
        model_name: str,
        handler: Callable[[], str],
        timeout_sec: float = 5.0,
        failure_threshold: int = 3,
        recovery_timeout: float = 10.0,
    ) -> None:
        """添加一个降级层。"""
        cb = CircuitBreaker(failure_threshold, recovery_timeout)
        layer = FallbackLayer(model_name, handler, timeout_sec, cb)
        self._layers.append(layer)

    def set_fallback_response(self, response: str) -> None:
        """设置兜底响应。"""
        self._fallback_response = response

    def execute(self) -> tuple[str, list[FallbackEvent]]:
        """执行降级链。

        Returns:
            (最终响应, 事件列表)
        """
        self._events.clear()

        for i, layer in enumerate(self._layers):
            success, result, reason, latency = layer.execute()

            event = FallbackEvent(
                layer_name=f"layer-{i+1}",
                model_name=layer.model_name,
                reason=reason,
                latency_ms=latency,
            )
            self._events.append(event)

            if success:
                return result, self._events

        # 所有层都失败，返回兜底响应
        self._events.append(FallbackEvent(
            layer_name="fallback",
            model_name="none",
            reason="all_layers_failed",
            latency_ms=0.0,
        ))
        return self._fallback_response, self._events

    def get_events(self) -> list[FallbackEvent]:
        """获取降级事件。"""
        return self._events

    def get_circuit_states(self) -> dict[str, str]:
        """获取所有熔断器状态。"""
        return {layer.model_name: layer.circuit_breaker.state.value for layer in self._layers}

    def reset_circuits(self) -> None:
        """重置所有熔断器。"""
        for layer in self._layers:
            layer.circuit_breaker.reset()
```

### 第 9 题：模型 AB 测试框架（流量分割 + 结果对比 + 统计显著性检验）

#### 知识点讲解

AB 测试是数据驱动决策的核心工具——在 Agent 系统中，你需要知道「换一个模型是否真的更好」「修改 prompt 后效果是否提升」。

**AB 测试核心流程：**

```
                   ┌─ Group A (50%) ──► Model A ──► 结果 A
用户请求 ──► 分流 ─┤
                   └─ Group B (50%) ──► Model B ──► 结果 B

收集数据:
  Group A: [score=4, score=3, score=5, score=4, ...]
  Group B: [score=5, score=4, score=4, score=5, ...]

统计分析:
  - 均值对比: A_avg=4.0, B_avg=4.5 → B 更好？
  - 统计显著性: p-value < 0.05 → 差异不是偶然？
  - 置信区间: [0.1, 0.9] → B 比 A 好 0.1~0.9 分（95%置信度）
```

**统计显著性检验（Z 检验）：**
- 零假设 H0: 两组均值无差异（μ_A = μ_B）
- 计算Z值: Z = (mean_A - mean_B) / sqrt(var_A/n_A + var_B/n_B)
- 计算 p-value: 如果 p < 0.05，拒绝零假设，认为差异显著
- 样本量越大，越容易检测到小的差异

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 9 题：模型 AB 测试框架
- ABTestConfig: 实验配置（流量分割比例、实验组定义）
- ABTestRouter: 流量分割路由（基于 hash 确定性分流）
- ABTestAnalyzer: 结果分析（均值对比 + Z检验 + 置信区间）
- 最小样本量计算
"""

import hashlib
from typing import Optional
from dataclasses import dataclass, field

import numpy as np
from scipy import stats as scipy_stats


# ============================================================================
# 实验配置
# ============================================================================

@dataclass
class ExperimentVariant:
    """实验变体（对照组或实验组）。"""
    name: str
    model_name: str
    weight: float  # 流量权重（0-1）


@dataclass
class ABTestConfig:
    """AB 测试配置。"""
    experiment_name: str
    variants: list[ExperimentVariant]
    description: str = ""
    # 评估指标
    metric_name: str = "quality_score"  # 评估指标名称
    metric_range: tuple[float, float] = (0, 10)  # 指标范围

    def total_weight(self) -> float:
        return sum(v.weight for v in self.variants)


# ============================================================================
# AB 测试路由器
# ============================================================================

class ABTestRouter:
    """AB 测试流量分割路由器。

    核心功能：
    1. 基于用户 ID 的确定性分流（同一用户始终分到同一组）
    2. 按权重比例分配流量
    3. 记录每个请求的分组结果

    确定性分流原理：
    - 对用户 ID 计算 hash（MD5/SHA256）
    - 取 hash 值的模运算映射到 [0, 1) 区间
    - 根据变体权重确定分组
    - 好处：同一用户始终分到同一组，避免体验不一致
    """

    def __init__(self, config: ABTestConfig):
        self.config = config
        self._assignments: dict[str, str] = {}  # user_id -> variant_name
        self._results: dict[str, list[float]] = {v.name: [] for v in config.variants}

    def assign(self, user_id: str) -> ExperimentVariant:
        """为用户分配实验组。

        使用 hash(user_id) 确保同一用户始终分到同一组。
        """
        # 如果已经分配过，直接返回
        if user_id in self._assignments:
            variant_name = self._assignments[user_id]
            return next(v for v in self.config.variants if v.name == variant_name)

        # 基于 hash 的确定性分流
        hash_val = int(hashlib.md5(user_id.encode()).hexdigest(), 16)
        normalized = (hash_val % 10000) / 10000.0  # 映射到 [0, 1)

        # 按权重分配
        cumulative = 0.0
        selected = self.config.variants[0]
        for variant in self.config.variants:
            cumulative += variant.weight / self.config.total_weight()
            if normalized < cumulative:
                selected = variant
                break

        self._assignments[user_id] = selected.name
        return selected

    def record_result(self, user_id: str, score: float) -> None:
        """记录用户的评估结果。"""
        if user_id in self._assignments:
            variant_name = self._assignments[user_id]
            if variant_name in self._results:
                self._results[variant_name].append(score)

    def get_results(self) -> dict[str, list[float]]:
        """获取各组的评估结果。"""
        return dict(self._results)

    def get_assignment_summary(self) -> dict[str, int]:
        """获取分组统计。"""
        summary: dict[str, int] = {v.name: 0 for v in self.config.variants}
        for variant_name in self._assignments.values():
            summary[variant_name] = summary.get(variant_name, 0) + 1
        return summary


# ============================================================================
# AB 测试分析器
# ============================================================================

class ABTestAnalyzer:
    """AB 测试结果分析器。

    核心功能：
    1. 描述性统计（均值、标准差、样本量）
    2. Z 检验（两组均值差异的统计显著性）
    3. 置信区间计算
    4. 最小样本量估算
    5. 效应量计算（Cohen's d）
    """

    @staticmethod
    def descriptive_stats(samples: list[float]) -> dict:
        """计算描述性统计。"""
        if not samples:
            return {"n": 0, "mean": 0, "std": 0, "min": 0, "max": 0}
        arr = np.array(samples)
        return {
            "n": len(samples),
            "mean": round(float(np.mean(arr)), 4),
            "std": round(float(np.std(arr, ddof=1)), 4) if len(arr) > 1 else 0,
            "min": round(float(np.min(arr)), 4),
            "max": round(float(np.max(arr)), 4),
        }

    @staticmethod
    def z_test(group_a: list[float], group_b: list[float]) -> dict:
        """Z 检验——比较两组均值差异是否显著。

        零假设 H0: mean_A = mean_B
        备择假设 H1: mean_A != mean_B

        Z = (mean_A - mean_B) / sqrt(var_A/n_A + var_B/n_B)
        p_value = 2 * (1 - Phi(|Z|))

        判定规则：p_value < 0.05 → 拒绝 H0 → 差异显著
        """
        if len(group_a) < 2 or len(group_b) < 2:
            return {"z_score": 0, "p_value": 1.0, "significant": False, "reason": "insufficient samples"}

        mean_a, mean_b = np.mean(group_a), np.mean(group_b)
        var_a, var_b = np.var(group_a, ddof=1), np.var(group_b, ddof=1)
        n_a, n_b = len(group_a), len(group_b)

        # Z 分数
        se = np.sqrt(var_a / n_a + var_b / n_b)
        if se == 0:
            return {"z_score": 0, "p_value": 1.0, "significant": False, "reason": "zero standard error"}

        z_score = (mean_a - mean_b) / se

        # 双侧 p-value
        p_value = 2 * (1 - scipy_stats.norm.cdf(abs(z_score)))

        # 效应量 (Cohen's d)
        pooled_std = np.sqrt(((n_a - 1) * var_a + (n_b - 1) * var_b) / (n_a + n_b - 2))
        cohens_d = (mean_a - mean_b) / pooled_std if pooled_std > 0 else 0

        # 置信区间 (95%)
        margin = 1.96 * se
        ci_lower = (mean_a - mean_b) - margin
        ci_upper = (mean_a - mean_b) + margin

        return {
            "z_score": round(float(z_score), 4),
            "p_value": round(float(p_value), 6),
            "significant": p_value < 0.05,
            "mean_diff": round(float(mean_a - mean_b), 4),
            "ci_95": (round(float(ci_lower), 4), round(float(ci_upper), 4)),
            "cohens_d": round(float(cohens_d), 4),
            "effect_size": "small" if abs(cohens_d) < 0.5 else ("medium" if abs(cohens_d) < 0.8 else "large"),
        }

    @staticmethod
    def minimum_sample_size(
        effect_size: float = 0.5,
        alpha: float = 0.05,
        power: float = 0.8,
    ) -> int:
        """计算检测指定效应量所需的最小样本量。

        公式: n = (Z_alpha/2 + Z_beta)^2 * 2 / effect_size^2

        Args:
            effect_size: 预期效应量（Cohen's d）
            alpha: 显著性水平（默认 0.05）
            power: 统计功效（默认 0.8）

        Returns:
            每组所需的最小样本量
        """
        z_alpha = scipy_stats.norm.ppf(1 - alpha / 2)
        z_beta = scipy_stats.norm.ppf(power)
        n = ((z_alpha + z_beta) ** 2 * 2) / (effect_size ** 2)
        return int(np.ceil(n))

    @staticmethod
    def analyze_experiment(
        results: dict[str, list[float]],
        control_name: str = "control",
    ) -> dict:
        """完整分析 AB 测试结果。

        Args:
            results: 各组的评估结果
            control_name: 对照组名称

        Returns:
            完整分析报告
        """
        report = {
            "variant_stats": {},
            "comparisons": [],
            "recommendation": "",
        }

        # 描述性统计
        for name, samples in results.items():
            report["variant_stats"][name] = ABTestAnalyzer.descriptive_stats(samples)

        # 与对照组比较
        if control_name not in results:
            report["recommendation"] = "Control group not found"
            return report

        control_samples = results[control_name]
        control_mean = np.mean(control_samples) if control_samples else 0

        for name, samples in results.items():
            if name == control_name:
                continue
            comparison = ABTestAnalyzer.z_test(control_samples, samples)
            comparison["variant"] = name
            comparison["control"] = control_name
            report["comparisons"].append(comparison)

        # 生成建议
        best_variant = control_name
        best_mean = control_mean
        for name, samples in results.items():
            if samples and np.mean(samples) > best_mean:
                best_mean = np.mean(samples)
                best_variant = name

        # 检查最佳变体是否显著优于对照组
        significant = False
        for comp in report["comparisons"]:
            if comp["variant"] == best_variant and comp["significant"] and comp["mean_diff"] < 0:
                significant = True

        if best_variant != control_name:
            comp = next((c for c in report["comparisons"] if c["variant"] == best_variant), None)
            if comp and comp["significant"]:
                report["recommendation"] = (
                    f"Variant '{best_variant}' is significantly better than control "
                    f"(p={comp['p_value']:.4f}, diff={-comp['mean_diff']:.4f}). "
                    f"Recommend deploying '{best_variant}'."
                )
            else:
                report["recommendation"] = (
                    f"Variant '{best_variant}' has higher mean but difference is NOT significant. "
                    f"Need more samples or larger effect."
                )
        else:
            report["recommendation"] = "Control group is best. No improvement detected."

        return report

        print(f"    {name:<12s}: n={stats['n']}, mean={stats['mean']:.3f}, "
              f"std={stats['std']:.3f}, range=[{stats['min']:.1f}, {stats['max']:.1f}]")

    print("\n  Statistical Comparison (Z-test):")
    for comp in report["comparisons"]:
        print(f"    {comp['control']} vs {comp['variant']}:")

        print(f"      Mean diff:   {comp['mean_diff']:.4f} (control - treatment)")
        print(f"      95% CI:      [{comp['ci_95'][0]:.4f}, {comp['ci_95'][1]:.4f}]")
        print(f"      Cohen's d:   {comp['cohens_d']:.4f} ({comp['effect_size']} effect)")

    print(f"\n  Recommendation: {report['recommendation']}")

    # --- 4. 最小样本量计算 ---
    print("\n--- Part 4: Minimum Sample Size ---\n")

    for effect in [0.2, 0.5, 0.8]:
        n = ABTestAnalyzer.minimum_sample_size(effect_size=effect)
        print(f"  Effect size {effect} ({'small' if effect < 0.5 else 'medium' if effect < 0.8 else 'large'}): "
              f"need {n} samples per group")

    # --- 5. 不显著场景演示 ---
    print("\n--- Part 5: Non-Significant Result ---\n")

    # 模拟两组几乎没有差异的场景
    rng2 = np.random.default_rng(99)
    results_no_diff = {
        "control": list(rng2.normal(7.0, 1.2, 50)),

    report2 = ABTestAnalyzer.analyze_experiment(results_no_diff, control_name="control")
    comp2 = report2["comparisons"][0]
    print(f"  Control mean: {np.mean(results_no_diff['control']):.3f}")
    print(f"  Treatment mean: {np.mean(results_no_diff['treatment']):.3f}")
    print(f"  p-value: {comp2['p_value']:.4f} -> Significant: {comp2['significant']}")
    print(f"  Recommendation: {report2['recommendation']}")

    print("  Demo complete!")
    print("=" * 70)
```

## 模块三：Multi-Agent Systems（多智能体系统）

### 多智能体编排模式总览

### 第 10 题：编排者-执行者模式（Orchestrator 分解任务 → Workers 并行执行 → 结果汇总）

#### 知识点讲解

编排者-执行者是最常见的多 Agent 模式：一个中心化的编排者负责任务分解和结果汇总，多个执行者并行处理子任务。

**核心流程：**

1. **任务分解**：编排者将复杂任务拆分成多个独立的子任务
2. **并行执行**：每个子任务分配给一个 Worker Agent 并行处理
3. **结果汇总**：编排者收集所有 Worker 的结果，合并成最终答案

**适用场景：**
- 调研报告：分解为「市场分析」「竞品分析」「技术评估」等子任务
- 代码生成：分解为「前端」「后端」「数据库设计」等子任务
- 文档处理：分解为「摘要」「翻译」「校对」等子任务

**关键设计点：**
- 子任务之间的**独立性**：子任务应尽量不依赖彼此的输出
- 编排者的**汇总策略**：简单拼接 vs 深度整合 vs 去重
- Worker 的**负载均衡**：避免某个 Worker 任务过重

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 10 题：编排者-执行者模式
- SubTask: 子任务数据结构
- WorkerAgent: 执行者 Agent（处理单个子任务）
- Orchestrator: 编排者（任务分解 + 分配 + 汇总）
- 并行执行模拟（基于线程池）
"""

import time
from typing import Optional, Any
from dataclasses import dataclass, field
from concurrent.futures import ThreadPoolExecutor, as_completed

import numpy as np


# ============================================================================
# 子任务定义
# ============================================================================

@dataclass
class SubTask:
    """子任务定义。

    属性：
    - id: 子任务唯一标识
    - name: 任务名称
    - description: 任务描述
    - worker_type: 需要的 Worker 类型
    - priority: 优先级（数字越大越优先）
    - status: 任务状态
    - result: 执行结果
    """
    id: str
    name: str
    description: str
    worker_type: str  # "researcher" / "coder" / "analyst" / "writer"
    priority: int = 0
    status: str = "pending"  # pending / running / completed / failed
    result: Optional[str] = None
    latency_ms: float = 0.0


# ============================================================================
# 执行者 Agent
# ============================================================================

class WorkerAgent:
    """执行者 Agent——处理单个子任务。

    每个 Worker 有自己的「能力」和「处理逻辑」。
    在实际系统中，Worker 会调用 LLM 来完成任务；
    这里用模拟逻辑演示架构。
    """

    def __init__(self, worker_id: str, worker_type: str, name: str = ""):
        self.worker_id = worker_id
        self.worker_type = worker_type
        self.name = name or f"{worker_type}-{worker_id}"
        self.tasks_completed: int = 0
        self.total_latency: float = 0.0

    def execute(self, task: SubTask) -> str:
        """执行子任务，返回结果字符串。"""
        start = time.time()

        # 模拟不同类型 Worker 的处理逻辑
        if self.worker_type == "researcher":
            # 研究型 Worker：模拟搜索和分析
            time.sleep(0.1 + np.random.random() * 0.15)
            result = f"[Research] Found 3 key insights for '{task.name}':\n" \
                     f"  1. Key finding about {task.description[:30]}...\n" \
                     f"  2. Supporting data from multiple sources\n" \
                     f"  3. Relevant trend analysis"

        elif self.worker_type == "coder":
            # 编码型 Worker：模拟代码生成
            time.sleep(0.08 + np.random.random() * 0.12)
            result = f"[Code] Generated solution for '{task.name}':\n" \
                     f"  - Module structure designed\n" \
                     f"  - Core functions implemented\n" \
                     f"  - Unit tests written"

        elif self.worker_type == "analyst":
            # 分析型 Worker：模拟数据分析
            time.sleep(0.06 + np.random.random() * 0.1)
            result = f"[Analysis] Analyzed '{task.name}':\n" \
                     f"  - Data points: {np.random.randint(100, 500)}\n" \
                     f"  - Key metric: {np.random.uniform(0.7, 0.95):.2f}\n" \
                     f"  - Confidence: {np.random.uniform(0.8, 0.99):.2f}"

        elif self.worker_type == "writer":
            # 写作型 Worker：模拟内容生成
            time.sleep(0.05 + np.random.random() * 0.08)
            result = f"[Content] Wrote section for '{task.name}':\n" \
                     f"  - Word count: {np.random.randint(200, 800)}\n" \
                     f"  - Tone: professional\n" \
                     f"  - Key points covered: 3/3"

        else:
            time.sleep(0.05)
            result = f"[Unknown] Processed '{task.name}'"

        latency = (time.time() - start) * 1000
        self.tasks_completed += 1
        self.total_latency += latency
        task.latency_ms = latency

        return result

    @property
    def avg_latency(self) -> float:
        return self.total_latency / max(self.tasks_completed, 1)

    def __repr__(self) -> str:
        return f"<Worker {self.name} ({self.worker_type})>"


# ============================================================================
# 编排者
# ============================================================================

class Orchestrator:
    """编排者 Agent——任务分解、分配、汇总。

    核心职责：
    1. 将复杂任务分解为子任务列表
    2. 根据子任务类型匹配 Worker
    3. 并行执行子任务
    4. 汇总所有结果

    使用示例：
        orch = Orchestrator()
        orch.register_worker(WorkerAgent("w1", "researcher"))
        orch.register_worker(WorkerAgent("w2", "coder"))
        result = orch.run("Build a recommendation system")
    """

    def __init__(self, max_workers: int = 4):
        self.max_workers = max_workers
        # 按类型分组的 Worker 池
        self._worker_pool: dict[str, list[WorkerAgent]] = {}
        self._orchestration_log: list[dict] = []

    def register_worker(self, worker: WorkerAgent) -> None:
        """注册一个 Worker。"""
        if worker.worker_type not in self._worker_pool:
            self._worker_pool[worker.worker_type] = []
        self._worker_pool[worker.worker_type].append(worker)

    def decompose(self, task_description: str) -> list[SubTask]:
        """任务分解——将复杂任务拆分为子任务。

        在实际系统中，这一步由 LLM 完成（通过 prompt 让 LLM 输出子任务列表）。
        这里用规则模拟分解逻辑。
        """
        # 根据任务描述模拟不同的分解策略
        if "system" in task_description.lower() or "build" in task_description.lower():
            # 工程类任务分解
            subtasks = [
                SubTask("t1", "Requirements Analysis", "Analyze requirements and constraints", "researcher", priority=3),
                SubTask("t2", "Architecture Design", "Design system architecture", "analyst", priority=3),
                SubTask("t3", "Core Implementation", "Implement core modules", "coder", priority=2),
                SubTask("t4", "API Layer", "Build API endpoints", "coder", priority=2),
                SubTask("t5", "Documentation", "Write technical docs", "writer", priority=1),
            ]
        elif "report" in task_description.lower() or "research" in task_description.lower():
            # 研究类任务分解
            subtasks = [
                SubTask("t1", "Market Research", "Gather market data", "researcher", priority=3),
                SubTask("t2", "Competitor Analysis", "Analyze competitors", "analyst", priority=3),
                SubTask("t3", "Trend Analysis", "Identify industry trends", "analyst", priority=2),
                SubTask("t4", "Report Writing", "Compile findings into report", "writer", priority=1),
            ]
        else:
            # 通用任务分解
            subtasks = [
                SubTask("t1", "Research", f"Research aspects of: {task_description}", "researcher", priority=2),
                SubTask("t2", "Analysis", f"Analyze findings for: {task_description}", "analyst", priority=2),
                SubTask("t3", "Implementation", f"Implement solution for: {task_description}", "coder", priority=1),
                SubTask("t4", "Documentation", f"Document: {task_description}", "writer", priority=1),
            ]

        return subtasks

    def _assign_worker(self, task: SubTask) -> Optional[WorkerAgent]:
        """为子任务分配一个 Worker（最空闲的）。"""
        workers = self._worker_pool.get(task.worker_type, [])
        if not workers:
            return None
        # 选择当前任务最少的 Worker
        return min(workers, key=lambda w: w.tasks_completed)

    def _execute_task(self, task: SubTask) -> tuple[SubTask, str]:
        """执行单个子任务（用于线程池）。"""
        worker = self._assign_worker(task)
        if worker is None:
            task.status = "failed"
            return task, f"No available worker for type '{task.worker_type}'"

        task.status = "running"
        try:
            result = worker.execute(task)
            task.status = "completed"
            task.result = result
            return task, result
        except Exception as e:
            task.status = "failed"
            return task, f"Error: {str(e)}"

    def run(self, task_description: str) -> dict:
        """执行完整的编排流程。

        1. 分解任务
        2. 并行执行子任务
        3. 汇总结果

        Returns:
            包含任务列表、结果汇总、执行统计的字典
        """
        start_time = time.time()

        # 步骤 1：任务分解
        subtasks = self.decompose(task_description)
        self._log("decompose", f"Decomposed into {len(subtasks)} subtasks")

        # 步骤 2：并行执行
        results: dict[str, str] = {}
        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            # 按优先级排序后提交
            sorted_tasks = sorted(subtasks, key=lambda t: -t.priority)
            futures = {executor.submit(self._execute_task, task): task for task in sorted_tasks}

            for future in as_completed(futures):
                task, result = future.result()
                results[task.id] = result
                self._log("task_complete", f"{task.name} ({task.status}) - {task.latency_ms:.0f}ms")

        # 步骤 3：结果汇总
        summary = self._summarize(subtasks, results)

        total_time = (time.time() - start_time) * 1000

        return {
            "task_description": task_description,
            "subtasks": [{"id": t.id, "name": t.name, "type": t.worker_type,
                          "status": t.status, "latency_ms": round(t.latency_ms, 1)}
                         for t in subtasks],
            "results": results,
            "summary": summary,
            "total_time_ms": round(total_time, 1),
            "worker_stats": self._worker_stats(),
        }

    def _summarize(self, subtasks: list[SubTask], results: dict[str, str]) -> str:
        """汇总所有子任务的结果。"""
        lines = ["=== Orchestration Summary ===\n"]
        for task in sorted(subtasks, key=lambda t: t.priority, reverse=True):
            status_icon = "[OK]" if task.status == "completed" else "[FAIL]"
            lines.append(f"{status_icon} {task.name} ({task.worker_type})")
            if task.id in results:
                # 只取结果的第一行作为摘要
                first_line = results[task.id].split("\n")[0]
                lines.append(f"    -> {first_line}")
            lines.append("")

        completed = sum(1 for t in subtasks if t.status == "completed")
        lines.append(f"Completed: {completed}/{len(subtasks)} subtasks")
        return "\n".join(lines)

    def _worker_stats(self) -> list[dict]:
        """获取所有 Worker 的统计信息。"""
        stats = []
        for worker_type, workers in self._worker_pool.items():
            for w in workers:
                stats.append({
                    "name": w.name,
                    "type": w.worker_type,
                    "tasks_completed": w.tasks_completed,
                    "avg_latency_ms": round(w.avg_latency, 1),
                })
        return stats

    def _log(self, event: str, message: str) -> None:
        """记录编排日志。"""
        self._orchestration_log.append({
            "timestamp": time.strftime("%H:%M:%S"),
            "event": event,
            "message": message,
        })

    @property
    def log(self) -> list[dict]:
        return self._orchestration_log


# ============================================================================
# 测试与演示
# ============================================================================

def demo_orchestrator():
    """演示编排者-执行者模式的完整功能。"""
    print("=" * 70)
    print("  Exercise 10: Orchestrator-Worker Pattern")
    print("=" * 70)

    # 创建编排者
    orch = Orchestrator(max_workers=4)

    # 注册多个 Worker（每种类型 2 个）
    for wt in ["researcher", "coder", "analyst", "writer"]:
        for i in range(2):
            orch.register_worker(WorkerAgent(f"w-{wt}-{i}", wt))

    # --- 场景 1：工程类任务 ---
    print("\n--- Scenario 1: Build a Recommendation System ---\n")
    result = orch.run("Build a recommendation system")

    print(f"Task: {result['task_description']}")
    print(f"Total time: {result['total_time_ms']:.0f}ms\n")

    print("Subtasks:")
    for st in result["subtasks"]:
        print(f"  {st['id']}: {st['name']:<25s} ({st['type']:<12s}) "
              f"[{st['status']}] {st['latency_ms']:.0f}ms")

    print(f"\n{result['summary']}")

    print("\nWorker Stats:")
    for ws in result["worker_stats"]:
        print(f"  {ws['name']:<20s}: tasks={ws['tasks_completed']}, "
              f"avg_latency={ws['avg_latency_ms']:.0f}ms")

    # --- 场景 2：研究类任务 ---
    print("\n\n--- Scenario 2: Research Report on AI Trends ---\n")
    result2 = orch.run("Write a research report on AI trends")

    print(f"Task: {result2['task_description']}")
    print(f"Total time: {result2['total_time_ms']:.0f}ms\n")

    print("Subtasks:")
    for st in result2["subtasks"]:
        print(f"  {st['id']}: {st['name']:<25s} ({st['type']:<12s}) "
              f"[{st['status']}] {st['latency_ms']:.0f}ms")

    # 编排日志
    print(f"\n--- Orchestration Log ({len(orch.log)} events) ---")
    for entry in orch.log[-6:]:

    print("  Demo complete!")
    print("=" * 70)
```

### 第 11 题：管道链模式（Agent A 输出 → Agent B 输入 → Agent C 总结）

#### 知识点讲解

管道链是另一种经典的多 Agent 协作模式——每个 Agent 负责一个阶段，前一个 Agent 的输出作为后一个 Agent 的输入，形成流水线。

**与编排者-执行者模式的区别：**
- 编排者-执行者：子任务并行，结果汇总
- 管道链：阶段串行，数据流转

```
管道链示意：

用户输入: "分析2024年AI行业趋势"
  │
  ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Agent A    │────►│  Agent B    │────►│  Agent C    │────►│  Agent D    │
│  数据收集   │     │  数据分析   │     │  报告生成   │     │  校对润色   │
│             │     │             │     │             │     │             │
│ 输入: 主题  │     │ 输入: 原始  │     │ 输入: 分析  │     │ 输入: 草稿  │
│ 输出: 数据  │     │ 输出: 洞察  │     │ 输出: 草稿  │     │ 输出: 终稿  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                                                                │
                                                                ▼
                                                            最终输出
```

**关键设计：**
1. **数据契约**：每个 Agent 的输出格式必须与下一个 Agent 的输入格式匹配
2. **错误传播**：某个阶段失败时，是否中断整个管道还是跳过
3. **中间结果缓存**：避免重复计算，支持断点续跑

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 11 题：管道链模式
- PipelineStage: 管道阶段定义（Agent + 输入/输出契约）
- Pipeline: 管道执行器（串行执行 + 中间结果缓存 + 错误处理）
- PipelineBuilder: 流式 API 构建管道
"""

import time
from typing import Any, Optional, Callable
from dataclasses import dataclass, field

import numpy as np


# ============================================================================
# 管道阶段
# ============================================================================

@dataclass
class PipelineStage:
    """管道中的一个阶段。

    每个阶段包含：
    - name: 阶段名称
    - agent_name: 执行该阶段的 Agent 名称
    - handler: 处理函数（接收上一个阶段的输出，返回本阶段的输出）
    - timeout_sec: 超时阈值
    """
    name: str
    agent_name: str
    handler: Callable[[Any], Any]
    timeout_sec: float = 30.0

    def execute(self, input_data: Any) -> tuple[bool, Any, float]:
        """执行本阶段。

        Returns:
            (success, output, latency_ms)
        """
        start = time.time()
        try:
            output = self.handler(input_data)
            latency = (time.time() - start) * 1000

            # 超时检查
            if latency > self.timeout_sec * 1000:
                return False, None, latency

            return True, output, latency
        except Exception as e:
            latency = (time.time() - start) * 1000
            return False, str(e), latency


# ============================================================================
# 管道执行器
# ============================================================================

class Pipeline:
    """管道链执行器。

    将多个 PipelineStage 串联，数据依次流过每个阶段。

    特性：
    - 串行执行：前一阶段输出作为后一阶段输入
    - 中间结果缓存：可查看每个阶段的输出
    - 错误处理：失败时可选择中断或用默认值继续
    - 执行追踪：记录每个阶段的耗时和状态

    使用示例：
        pipeline = Pipeline("content_generation")
        pipeline.add_stage("collect", "agent-a", collect_handler)
        pipeline.add_stage("analyze", "agent-b", analyze_handler)
        pipeline.add_stage("write", "agent-c", write_handler)

        result = pipeline.run("AI trends 2024")
    """

    def __init__(self, name: str = "pipeline"):
        self.name = name
        self._stages: list[PipelineStage] = []
        # 中间结果缓存
        self._intermediate_results: dict[str, Any] = {}
        # 执行追踪
        self._trace: list[dict] = []

    def add_stage(
        self,
        name: str,
        agent_name: str,
        handler: Callable[[Any], Any],
        timeout_sec: float = 30.0,
    ) -> "Pipeline":
        """添加一个阶段（支持链式调用）。"""
        stage = PipelineStage(name, agent_name, handler, timeout_sec)
        self._stages.append(stage)
        return self

    def run(self, initial_input: Any, fail_fast: bool = True) -> dict:
        """执行管道。

        Args:
            initial_input: 管道的初始输入
            fail_fast: True = 某阶段失败时立即中断；False = 用 None 继续执行

        Returns:
            执行结果字典
        """
        self._intermediate_results.clear()
        self._trace.clear()

        current_data = initial_input
        self._intermediate_results["_input"] = initial_input
        start_time = time.time()

        for i, stage in enumerate(self._stages):
            stage_start = time.time()

            success, output, latency = stage.execute(current_data)

            trace_entry = {
                "stage_index": i,
                "stage_name": stage.name,
                "agent_name": stage.agent_name,
                "success": success,
                "latency_ms": round(latency, 1),
                "timestamp": time.strftime("%H:%M:%S"),
            }
            self._trace.append(trace_entry)

            if success:
                self._intermediate_results[stage.name] = output
                current_data = output
            else:
                if fail_fast:
                    return {
                        "success": False,
                        "failed_stage": stage.name,
                        "error": output,
                        "trace": self._trace,
                        "intermediate_results": self._intermediate_results,
                        "total_time_ms": round((time.time() - start_time) * 1000, 1),
                    }
                else:
                    # 用 None 继续
                    self._intermediate_results[stage.name] = None
                    current_data = None

        total_time = (time.time() - start_time) * 1000
        return {
            "success": True,
            "output": current_data,
            "trace": self._trace,
            "intermediate_results": self._intermediate_results,
            "total_time_ms": round(total_time, 1),
        }

    def get_intermediate(self, stage_name: str) -> Any:
        """获取某个阶段的中间结果。"""
        return self._intermediate_results.get(stage_name)

    @property
    def trace(self) -> list[dict]:
        """获取执行追踪。"""
        return self._trace

    @property
    def stage_count(self) -> int:
        return len(self._stages)


# ============================================================================
# 流式管道构建器（模拟 LLM Agent 的处理逻辑）
# ============================================================================

class PipelineBuilder:
    """流式管道构建器——提供便捷的管道构建 API。

    使用示例：
        pipeline = (PipelineBuilder("research_pipeline")
            .collect(lambda topic: f"Raw data about {topic}")
            .analyze(lambda data: f"Insights from: {data}")
            .write(lambda insights: f"Report: {insights}")
            .review(lambda report: f"Final: {report}")
            .build())
    """

    def __init__(self, name: str):
        self._pipeline = Pipeline(name)

    def collect(self, handler: Callable) -> "PipelineBuilder":
        """数据收集阶段。"""
        self._pipeline.add_stage("collect", "collector-agent", handler)
        return self

    def analyze(self, handler: Callable) -> "PipelineBuilder":
        """数据分析阶段。"""
        self._pipeline.add_stage("analyze", "analyst-agent", handler)
        return self

    def write(self, handler: Callable) -> "PipelineBuilder":
        """内容写作阶段。"""
        self._pipeline.add_stage("write", "writer-agent", handler)
        return self

    def review(self, handler: Callable) -> "PipelineBuilder":
        """校对审阅阶段。"""
        self._pipeline.add_stage("review", "reviewer-agent", handler)
        return self

    def custom(self, name: str, agent_name: str, handler: Callable) -> "PipelineBuilder":
        """自定义阶段。"""
        self._pipeline.add_stage(name, agent_name, handler)
        return self

    def build(self) -> Pipeline:
        return self._pipeline
```

### 第 12 题：共享黑板模式（多个 Agent 读写共享状态空间）

#### 知识点讲解

共享黑板模式是一种去中心化的多 Agent 协作模式——所有 Agent 共享一个「黑板」（黑板 = 共享状态空间），每个 Agent 可以读取黑板上的信息，也可以将自己的结果写入黑板。

**与其他模式的区别：**
- 编排者-执行者：中心化控制，Worker 之间不直接通信
- 管道链：线性数据流，前一个 Agent 的输出只给下一个
- 共享黑板：所有 Agent 都可以读写同一个黑板，信息自由流动

```
共享黑板模式示意：

         ┌── Agent A (研究员) ──┐
         │                      │
         │   写入: 市场数据      │
         │                      │
         ▼                      ▼
    ┌─────────────────────────────────┐
    │          Blackboard              │
    │  (共享状态空间)                   │
    │                                  │
    │  [市场数据] ← Agent A 写入        │
    │  [技术分析] ← Agent B 写入        │
    │  [风险评估] ← Agent C 写入        │
    │  [投资建议] ← Agent D 读取后写入   │
    │                                  │
    └─────────────────────────────────┘
         ▲                      ▲
         │   读取: 技术分析      │
         │                      │
    Agent B (分析师)     Agent C (风控)
    Agent D (顾问) 读取全部后综合
```

**关键设计：**
1. **黑板数据结构**：分区存储不同类型的信息（如 facts, hypotheses, decisions）
2. **读写控制**：Agent 可以订阅特定区域的变化
3. **冲突处理**：多个 Agent 同时写入同一区域时的策略

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 12 题：共享黑板模式
- Blackboard: 共享状态空间（分区域存储 + 订阅通知 + 历史记录）
- BlackboardAgent: 读写黑板的 Agent
- BlackboardCoordinator: 协调多个 Agent 的读写循环
- 冲突检测与版本控制
"""

import time
from typing import Any, Optional, Callable
from dataclasses import dataclass, field
from collections import defaultdict

import numpy as np


# ============================================================================
# 黑板条目
# ============================================================================

@dataclass
class BlackboardEntry:
    """黑板上的一个条目。"""
    section: str          # 所属区域（如 "facts", "analysis", "decisions"）
    key: str              # 条目键
    value: Any            # 条目值
    author: str           # 写入者（Agent 名称）
    timestamp: float = field(default_factory=time.time)
    version: int = 1      # 版本号（每次更新递增）

    def update(self, new_value: Any, author: str) -> None:
        """更新条目值。"""
        self.value = new_value
        self.author = author
        self.timestamp = time.time()
        self.version += 1


# ============================================================================
# 共享黑板
# ============================================================================

class Blackboard:
    """共享黑板——多 Agent 协作的中心数据结构。

    核心功能：
    1. 分区域存储：不同类型的信息存在不同区域（facts/analysis/decisions）
    2. 读写控制：Agent 可以读写指定区域
    3. 订阅通知：Agent 可以订阅区域变化，有新数据时收到通知
    4. 历史记录：记录所有写操作，支持审计和回放
    5. 版本控制：每个条目有版本号，支持乐观并发

    使用示例：
        bb = Blackboard()
        bb.write("facts", "market_size", "$10B", "agent-a")
        value = bb.read("facts", "market_size")
        bb.subscribe("analysis", callback_func)
    """

    def __init__(self):
        # 分区域存储：{section: {key: BlackboardEntry}}
        self._sections: dict[str, dict[str, BlackboardEntry]] = defaultdict(dict)
        # 订阅者：{section: [callback_functions]}
        self._subscribers: dict[str, list[Callable]] = defaultdict(list)
        # 操作历史
        self._history: list[dict] = []
        # 锁计数（模拟乐观并发控制）
        self._write_count: int = 0

    def write(self, section: str, key: str, value: Any, author: str) -> None:
        """写入（或更新）一个条目。"""
        self._write_count += 1

        if key in self._sections[section]:
            # 更新已有条目
            entry = self._sections[section][key]
            old_value = entry.value
            entry.update(value, author)
            action = "update"
        else:
            # 创建新条目
            entry = BlackboardEntry(section=section, key=key, value=value, author=author)
            self._sections[section][key] = entry
            old_value = None
            action = "create"

        # 记录历史
        self._history.append({
            "action": action,
            "section": section,
            "key": key,
            "old_value": old_value,
            "new_value": value,
            "author": author,
            "timestamp": time.strftime("%H:%M:%S"),
            "version": entry.version,
        })

        # 通知订阅者
        for callback in self._subscribers.get(section, []):
            callback(section, key, value, author)

    def read(self, section: str, key: str) -> Optional[Any]:
        """读取一个条目。"""
        entry = self._sections.get(section, {}).get(key)
        return entry.value if entry else None

    def read_section(self, section: str) -> dict[str, Any]:
        """读取整个区域的所有条目。"""
        return {k: e.value for k, e in self._sections.get(section, {}).items()}

    def read_all(self) -> dict[str, dict[str, Any]]:
        """读取黑板上的所有内容。"""
        return {section: self.read_section(section) for section in self._sections}

    def subscribe(self, section: str, callback: Callable) -> None:
        """订阅区域变化。"""
        self._subscribers[section].append(callback)

    def get_history(self, section: Optional[str] = None) -> list[dict]:
        """获取操作历史。"""
        if section:
            return [h for h in self._history if h["section"] == section]
        return list(self._history)

    def get_sections(self) -> list[str]:
        """获取所有区域名称。"""
        return list(self._sections.keys())

    def get_stats(self) -> dict:
        """获取黑板统计信息。"""
        section_counts = {s: len(entries) for s, entries in self._sections.items()}
        return {
            "total_sections": len(self._sections),
            "total_entries": sum(section_counts.values()),
            "total_writes": self._write_count,
            "by_section": section_counts,
        }


# ============================================================================
# 黑板 Agent
# ============================================================================

class BlackboardAgent:
    """基于黑板的 Agent。

    每个 Agent 有自己的专长区域，可以读取其他区域的数据，
    处理后将结果写入自己的专长区域。
    """

    def __init__(self, name: str, expertise: str, read_sections: list[str], write_section: str):
        """
        Args:
            name: Agent 名称
            expertise: 专长描述
            read_sections: 需要读取的区域列表
            write_section: 写入结果的区域
        """
        self.name = name
        self.expertise = expertise
        self.read_sections = read_sections
        self.write_section = write_section
        self.writes_count: int = 0

    def process(self, blackboard: Blackboard) -> dict[str, Any]:
        """处理逻辑——读取黑板数据，处理后写入结果。

        返回写入的内容摘要。
        """
        # 1. 读取依赖区域的数据
        context = {}
        for section in self.read_sections:
            context[section] = blackboard.read_section(section)

        # 2. 模拟处理逻辑（实际系统中调用 LLM）
        time.sleep(0.05 + np.random.random() * 0.05)

        # 3. 生成结果并写入黑板
        results = self._generate_results(context)

        for key, value in results.items():
            blackboard.write(self.write_section, key, value, self.name)
            self.writes_count += 1

        return results

    def _generate_results(self, context: dict) -> dict[str, Any]:
        """根据上下文生成结果（模拟 LLM 输出）。"""
        # 根据专长生成不同类型的结果
        if self.expertise == "researcher":
            return {
                "market_data": {"size": "$10B", "growth": "15% YoY"},
                "key_players": ["Company A", "Company B", "Company C"],
            }
        elif self.expertise == "analyst":
            # 分析师需要读取研究员的数据
            market = context.get("facts", {})
            return {
                "trend_analysis": "Upward trend with strong momentum",
                "risk_factors": ["Regulatory changes", "Competition"],
                "confidence": 0.85,
            }
        elif self.expertise == "risk_manager":
            # 风控需要读取分析结果
            analysis = context.get("analysis", {})
            return {
                "risk_level": "Medium",
                "mitigation": "Diversify portfolio, set stop-loss",
            }
        elif self.expertise == "advisor":
            # 顾问需要读取所有数据
            return {
                "recommendation": "Proceed with caution, allocate 20% to this sector",
                "priority": "Medium-High",
            }
        else:
            return {"output": "Unknown expertise"}


# ============================================================================
# 黑板协调器
# ============================================================================

class BlackboardCoordinator:
    """黑板协调器——管理多个 Agent 的协作循环。

    协调策略：
    1. 按依赖顺序执行（先执行无依赖的 Agent）
    2. 支持多轮迭代（Agent 可以在后续轮次中利用其他 Agent 的输出）
    3. 检测收敛（黑板不再变化时停止）
    """

    def __init__(self, blackboard: Blackboard):
        self.blackboard = blackboard
        self._agents: list[BlackboardAgent] = []

    def add_agent(self, agent: BlackboardAgent) -> None:
        """注册一个 Agent。"""
        self._agents.append(agent)

    def run(self, max_rounds: int = 3) -> dict:
        """运行协作循环。

        Args:
            max_rounds: 最大迭代轮次

        Returns:
            执行报告
        """
        report = {
            "rounds": [],
            "final_blackboard": {},
            "agent_stats": [],
        }

        for round_num in range(max_rounds):
            round_start = time.time()
            round_writes = 0

            # 按依赖顺序执行 Agent（通过读取区域判断依赖）
            # 简化：按注册顺序执行
            for agent in self._agents:
                results = agent.process(self.blackboard)
                round_writes += len(results)

            round_time = (time.time() - round_start) * 1000

            report["rounds"].append({
                "round": round_num + 1,
                "writes": round_writes,
                "time_ms": round(round_time, 1),
            })

            # 检查收敛（没有新写入则停止）
            if round_writes == 0:
                break

        report["final_blackboard"] = self.blackboard.read_all()
        report["agent_stats"] = [
            {"name": a.name, "expertise": a.expertise,
             "writes": a.writes_count, "write_section": a.write_section}
            for a in self._agents
        ]

        return report
```

### 第 13 题：投票决策器（多 Agent 独立回答 → 加权投票 → 置信度聚合）

#### 知识点讲解

投票决策是多 Agent 系统中处理「不确定性」的经典方法——当问题没有唯一正确答案时，让多个 Agent 独立给出回答，然后通过投票机制选出最佳答案。

**三种投票策略：**

1. **多数投票**：每个 Agent 一票，票数最多的答案获胜
   - 简单但忽略 Agent 间的能力差异

2. **加权投票**：不同 Agent 有不同的权重（如专家 Agent 权重更高）
   - 权重 × 置信度 = 投票分数

3. **置信度聚合**：不仅考虑答案选择，还考虑每个 Agent 的置信度
   - 加权平均置信度 = Σ(weight_i × confidence_i × answer_i) / Σ(weight_i × confidence_i)

```
投票决策流程：

问题: "Python 中 GIL 是什么？"

Agent A (权重 0.3): "全局解释器锁" (置信度 0.9)
Agent B (权重 0.3): "全局解释器锁" (置信度 0.8)
Agent C (权重 0.2): "通用索引库"   (置信度 0.6)  ← 错误
Agent D (权重 0.2): "全局解释器锁" (置信度 0.95)

多数投票: "全局解释器锁" (3:1)
加权投票: "全局解释器锁" (0.3*0.9 + 0.3*0.8 + 0.2*0.95 = 0.71 vs 0.2*0.6 = 0.12)
最终决策: "全局解释器锁" (置信度 0.86)
```

```python
"""
第 13 题：投票决策器
- AgentVote: 单个 Agent 的投票（答案 + 置信度 + 权重）
- VotingStrategy: 投票策略（多数/加权/置信度聚合）
- VotingDecisionMaker: 投票决策器
- 冲突检测与质量评估
"""

import time
from typing import Any, Optional
from dataclasses import dataclass, field
from enum import Enum
from collections import defaultdict

import numpy as np


# ============================================================================
# 投票数据结构
# ============================================================================

@dataclass
class AgentVote:
    """单个 Agent 的投票。"""
    agent_name: str
    answer: str           # Agent 给出的答案
    confidence: float     # 置信度 (0-1)
    weight: float = 1.0   # Agent 的权重（专家 > 普通）
    reasoning: str = ""   # 推理过程（可选）
    latency_ms: float = 0.0


# ============================================================================
# 投票策略
# ============================================================================

class VotingStrategy(Enum):
    """投票策略。"""
    MAJORITY = "majority"           # 多数投票
    WEIGHTED = "weighted"           # 加权投票
    CONFIDENCE = "confidence"       # 置信度聚合
    BORDA = "borda"                 # Borda 计数（排名投票）


# ============================================================================
# 投票决策器
# ============================================================================

class VotingDecisionMaker:
    """投票决策器——收集多 Agent 的回答，通过投票选出最佳答案。

    核心功能：
    1. 收集多个 Agent 的投票
    2. 按指定策略聚合投票
    3. 计算最终答案和置信度
    4. 检测答案分歧（一致性分析）

    使用示例：
        voter = VotingDecisionMaker(strategy=VotingStrategy.WEIGHTED)
        voter.add_vote(AgentVote("agent-a", "answer1", 0.9, weight=0.3))
        voter.add_vote(AgentVote("agent-b", "answer2", 0.7, weight=0.3))
        result = voter.decide()
    """

    def __init__(self, strategy: VotingStrategy = VotingStrategy.WEIGHTED):
        self.strategy = strategy
        self._votes: list[AgentVote] = []

    def add_vote(self, vote: AgentVote) -> None:
        """添加一个投票。"""
        self._votes.append(vote)

    def add_votes(self, votes: list[AgentVote]) -> None:
        """批量添加投票。"""
        self._votes.extend(votes)

    def decide(self) -> dict:
        """执行投票决策。

        Returns:
            决策结果字典，包含：
            - winning_answer: 获胜答案
            - confidence: 最终置信度
            - consensus: 共识度 (0-1)
            - vote_distribution: 各答案的得票分布
            - strategy: 使用的投票策略
        """
        if not self._votes:
            return {"winning_answer": None, "confidence": 0, "consensus": 0}

        if self.strategy == VotingStrategy.MAJORITY:
            return self._majority_vote()
        elif self.strategy == VotingStrategy.WEIGHTED:
            return self._weighted_vote()
        elif self.strategy == VotingStrategy.CONFIDENCE:
            return self._confidence_vote()
        else:
            return self._majority_vote()

    def _majority_vote(self) -> dict:
        """多数投票——每个 Agent 一票，票数最多的获胜。"""
        answer_counts: dict[str, int] = defaultdict(int)
        for vote in self._votes:
            answer_counts[vote.answer] += 1

        winning_answer = max(answer_counts, key=answer_counts.get)
        winning_count = answer_counts[winning_answer]
        total = len(self._votes)

        # 置信度 = 获胜票数 / 总票数
        confidence = winning_count / total

        # 共识度 = 1 - (不同答案数 - 1) / 总答案数
        consensus = 1 - (len(answer_counts) - 1) / max(len(answer_counts), 1)

        return {
            "winning_answer": winning_answer,
            "confidence": round(confidence, 4),
            "consensus": round(consensus, 4),
            "vote_distribution": dict(answer_counts),
            "strategy": "majority",
            "total_votes": total,
        }

    def _weighted_vote(self) -> dict:
        """加权投票——每个 Agent 的票按权重计算。"""
        answer_scores: dict[str, float] = defaultdict(float)
        answer_weights: dict[str, float] = defaultdict(float)

        for vote in self._votes:
            score = vote.weight * vote.confidence
            answer_scores[vote.answer] += score
            answer_weights[vote.answer] += vote.weight

        winning_answer = max(answer_scores, key=answer_scores.get)
        winning_score = answer_scores[winning_answer]
        total_score = sum(answer_scores.values())

        confidence = winning_score / total_score if total_score > 0 else 0
        consensus = winning_score / max(total_score, 0.001)

        return {
            "winning_answer": winning_answer,
            "confidence": round(confidence, 4),
            "consensus": round(consensus, 4),
            "vote_distribution": {k: round(v, 4) for k, v in answer_scores.items()},
            "strategy": "weighted",
            "total_votes": len(self._votes),
        }

    def _confidence_vote(self) -> dict:
        """置信度聚合——加权平均置信度。"""
        answer_confs: dict[str, list[tuple[float, float]]] = defaultdict(list)

        for vote in self._votes:
            answer_confs[vote.answer].append((vote.confidence, vote.weight))

        # 计算每个答案的加权平均置信度
        answer_scores: dict[str, float] = {}
        for answer, confs in answer_confs.items():
            total_weight = sum(w for _, w in confs)
            weighted_conf = sum(c * w for c, w in confs) / max(total_weight, 0.001)
            # 最终分数 = 加权置信度 × 支持者比例
            supporter_ratio = len(confs) / len(self._votes)
            answer_scores[answer] = weighted_conf * supporter_ratio

        winning_answer = max(answer_scores, key=answer_scores.get)
        winning_score = answer_scores[winning_answer]
        total_score = sum(answer_scores.values())

        confidence = winning_score / max(total_score, 0.001)

        return {
            "winning_answer": winning_answer,
            "confidence": round(confidence, 4),
            "consensus": round(winning_score, 4),
            "vote_distribution": {k: round(v, 4) for k, v in answer_scores.items()},
            "strategy": "confidence",
            "total_votes": len(self._votes),
        }

    def analyze_consensus(self) -> dict:
        """分析投票的一致性。

        Returns:
            一致性分析报告
        """
        if not self._votes:
            return {"status": "no_votes"}

        answers = [v.answer for v in self._votes]
        unique_answers = set(answers)

        # 如果所有 Agent 都给出相同答案
        if len(unique_answers) == 1:
            return {
                "status": "unanimous",
                "answer": answers[0],
                "avg_confidence": round(np.mean([v.confidence for v in self._votes]), 4),
            }

        # 如果有分歧
        max_count = max(answers.count(a) for a in unique_answers)
        agreement_ratio = max_count / len(answers)

        if agreement_ratio >= 0.8:
            status = "strong_majority"
        elif agreement_ratio >= 0.6:
            status = "weak_majority"
        else:
            status = "split"

        # 计算平均置信度
        confidences = [v.confidence for v in self._votes]

        return {
            "status": status,
            "agreement_ratio": round(agreement_ratio, 4),
            "unique_answers": len(unique_answers),
            "avg_confidence": round(float(np.mean(confidences)), 4),
            "min_confidence": round(float(np.min(confidences)), 4),
            "max_confidence": round(float(np.max(confidences)), 4),
            "dissenting_answers": [a for a in unique_answers if answers.count(a) < max_count],
        }

class VotingAgentPool:
    """投票 Agent 池——模拟多个 Agent 独立回答问题。

    每个 Agent 有不同的「准确率」和「置信度校准」，
    用于模拟真实场景中 Agent 能力的差异。
    """

    def __init__(self):
        self._agents: list[dict] = []

    def add_agent(self, name: str, accuracy: float, weight: float = 1.0) -> None:
        """注册一个投票 Agent。

        Args:
            name: Agent 名称
            accuracy: 准确率 (0-1)，模拟该 Agent 回答正确的概率
            weight: 投票权重
        """
        self._agents.append({"name": name, "accuracy": accuracy, "weight": weight})

    def vote_on_question(self, question: str, correct_answer: str,
                         num_alternatives: int = 2) -> list[AgentVote]:
        """模拟多个 Agent 对同一问题投票。

        Args:
            question: 问题
            correct_answer: 正确答案
            num_alternatives: 错误答案的数量

        Returns:
            所有 Agent 的投票列表
        """
        # 生成错误答案选项
        alternatives = [f"wrong_answer_{i}" for i in range(num_alternatives)]
        all_options = [correct_answer] + alternatives

        votes = []
        rng = np.random.default_rng(hash(question) % 2**32)

        for agent in self._agents:
            start = time.time()
            # 按准确率决定是否回答正确
            if rng.random() < agent["accuracy"]:
                answer = correct_answer
                # 正确时置信度较高
                confidence = float(rng.uniform(0.7, 0.95))
            else:
                answer = str(rng.choice(alternatives))
                # 错误时置信度也较高（模拟过度自信）
                confidence = float(rng.uniform(0.5, 0.85))

            latency = (time.time() - start) * 1000
            votes.append(AgentVote(
                agent_name=agent["name"],
                answer=answer,
                confidence=confidence,
                weight=agent["weight"],
                latency_ms=latency,
            ))

        return votes
```

### 第 14 题：Agent 生命周期管理器（创建/监控/超时回收/结果收集）

#### 知识点讲解

在复杂的多 Agent 系统中，子 Agent 是有生命周期的资源——需要创建、分配任务、监控状态、超时回收、收集结果。Agent 生命周期管理器就是负责这些工作的「容器」。

**生命周期状态机：**

```
                创建
                 │
                 ▼
            ┌─────────┐
            │ CREATED  │ ← Agent 已创建但未开始执行
            └────┬────┘
                 │ 分配任务
                 ▼
            ┌─────────┐
            │  RUNNING │ ← 正在执行任务
            └────┬────┘
                 │
        ┌────────┼────────┐
        │        │        │
        ▼        ▼        ▼
   ┌────────┐ ┌──────┐ ┌─────────┐
   │COMPLETED│ │TIMEOUT│ │  FAILED  │
   └────────┘ └──────┘ └─────────┘
        │        │        │
        └────────┼────────┘
                 ▼
            ┌─────────┐
            │RECYCLED │ ← 资源已回收
            └─────────┘
```

**关键设计：**
1. **创建池**：预创建一批 Agent，避免频繁创建/销毁的开销
2. **健康监控**：定期检查 Agent 状态（心跳机制）
3. **超时回收**：超过最大执行时间的 Agent 被强制终止
4. **结果收集**：Agent 完成后自动收集结果，支持回调通知

#### 完整代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第 14 题：Agent 生命周期管理器
- AgentState: 生命周期状态枚举
- ManagedAgent: 受管理的 Agent（带状态、超时、结果）
- AgentLifecycleManager: 生命周期管理器（创建/监控/超时回收/结果收集）
- 资源池模式 + 心跳监控
"""

import time
from typing import Any, Optional, Callable
from dataclasses import dataclass, field
from enum import Enum
from concurrent.futures import ThreadPoolExecutor, Future

import numpy as np


# ============================================================================
# 生命周期状态
# ============================================================================

class AgentState(Enum):
    """Agent 生命周期状态。"""
    CREATED = "CREATED"        # 已创建，未开始
    RUNNING = "RUNNING"        # 正在执行
    COMPLETED = "COMPLETED"    # 已完成
    TIMEOUT = "TIMEOUT"        # 超时终止
    FAILED = "FAILED"          # 执行失败
    RECYCLED = "RECYCLED"      # 已回收


# ============================================================================
# 受管理的 Agent
# ============================================================================

@dataclass
class ManagedAgent:
    """受管理的 Agent 实例。

    封装了 Agent 的状态、任务、结果和生命周期信息。
    """
    agent_id: str
    name: str
    task: Optional[str] = None
    state: AgentState = AgentState.CREATED
    result: Any = None
    error: Optional[str] = None
    created_at: float = field(default_factory=time.time)
    started_at: float = 0.0
    completed_at: float = 0.0
    timeout_sec: float = 30.0
    last_heartbeat: float = field(default_factory=time.time)
    metadata: dict = field(default_factory=dict)

    @property
    def runtime_ms(self) -> float:
        """已运行时间（毫秒）。"""
        if self.state == AgentState.RUNNING:
            return (time.time() - self.started_at) * 1000
        elif self.completed_at > 0:
            return (self.completed_at - self.started_at) * 1000
        return 0.0

    @property
    def is_alive(self) -> bool:
        """是否仍在运行。"""
        return self.state == AgentState.RUNNING

    def heartbeat(self) -> None:
        """更新心跳时间。"""
        self.last_heartbeat = time.time()

    def is_timed_out(self) -> bool:
        """是否已超时。"""
        if self.state != AgentState.RUNNING:
            return False
        return time.time() - self.started_at > self.timeout_sec


# ============================================================================
# Agent 生命周期管理器
# ============================================================================

class AgentLifecycleManager:
    """Agent 生命周期管理器。

    核心功能：
    1. 创建和注册 Agent
    2. 分配任务并启动执行
    3. 心跳监控和超时检测
    4. 结果收集和回调通知
    5. 资源回收

    使用示例：
        manager = AgentLifecycleManager(max_concurrent=5)
        agent_id = manager.create_agent("worker-1")
        manager.assign_task(agent_id, "process data", handler_func)
        manager.wait_for_completion(agent_id)
        result = manager.get_result(agent_id)
    """

    def __init__(self, max_concurrent: int = 10, heartbeat_interval: float = 1.0):
        self.max_concurrent = max_concurrent
        self.heartbeat_interval = heartbeat_interval
        self._agents: dict[str, ManagedAgent] = {}
        self._futures: dict[str, Future] = {}
        self._callbacks: dict[str, list[Callable]] = {}
        self._executor = ThreadPoolExecutor(max_workers=max_concurrent)
        self._counter = 0
        # 统计
        self._stats = {
            "total_created": 0,
            "total_completed": 0,
            "total_timeout": 0,
            "total_failed": 0,
            "total_recycled": 0,
        }

    def create_agent(self, name: str = "", timeout_sec: float = 30.0) -> str:
        """创建一个新的 Agent。

        Returns:
            agent_id: 新创建的 Agent 的 ID
        """
        self._counter += 1
        agent_id = f"agent-{self._counter:04d}"
        agent = ManagedAgent(
            agent_id=agent_id,
            name=name or f"agent-{self._counter}",
            timeout_sec=timeout_sec,
        )
        self._agents[agent_id] = agent
        self._callbacks[agent_id] = []
        self._stats["total_created"] += 1
        return agent_id

    def on_complete(self, agent_id: str, callback: Callable) -> None:
        """注册完成回调。"""
        if agent_id in self._callbacks:
            self._callbacks[agent_id].append(callback)

    def assign_task(self, agent_id: str, task: str, handler: Callable, **kwargs) -> bool:
        """为 Agent 分配任务并启动执行。

        Args:
            agent_id: Agent ID
            task: 任务描述
            handler: 任务处理函数
            **kwargs: 传递给 handler 的额外参数

        Returns:
            是否成功启动
        """
        agent = self._agents.get(agent_id)
        if not agent or agent.state != AgentState.CREATED:
            return False

        agent.task = task
        agent.state = AgentState.RUNNING
        agent.started_at = time.time()
        agent.heartbeat()

        # 提交到线程池
        def _run():
            try:
                agent.heartbeat()
                result = handler(task, **kwargs)
                agent.result = result
                agent.state = AgentState.COMPLETED
                agent.completed_at = time.time()
                self._stats["total_completed"] += 1
                # 触发回调
                for cb in self._callbacks.get(agent_id, []):
                    cb(agent_id, True, result)
                return result
            except Exception as e:
                agent.error = str(e)
                agent.state = AgentState.FAILED
                agent.completed_at = time.time()
                self._stats["total_failed"] += 1
                # 触发回调
                for cb in self._callbacks.get(agent_id, []):
                    cb(agent_id, False, str(e))
                raise

        future = self._executor.submit(_run)
        self._futures[agent_id] = future
        return True

    def check_timeouts(self) -> list[str]:
        """检查所有运行中的 Agent 是否超时。

        Returns:
            超时的 Agent ID 列表
        """
        timed_out = []
        for agent_id, agent in self._agents.items():
            if agent.is_timed_out():
                agent.state = AgentState.TIMEOUT
                agent.completed_at = time.time()
                agent.error = f"Timed out after {agent.timeout_sec}s"
                self._stats["total_timeout"] += 1
                timed_out.append(agent_id)
                # 触发回调
                for cb in self._callbacks.get(agent_id, []):
                    cb(agent_id, False, "timeout")
        return timed_out

    def get_state(self, agent_id: str) -> Optional[AgentState]:
        """获取 Agent 状态。"""
        agent = self._agents.get(agent_id)
        return agent.state if agent else None

    def get_result(self, agent_id: str) -> Any:
        """获取 Agent 的执行结果。"""
        agent = self._agents.get(agent_id)
        if agent and agent.state == AgentState.COMPLETED:
            return agent.result
        return None

    def wait_for_completion(self, agent_id: str, timeout: float = 60.0) -> bool:
        """等待 Agent 完成。

        Returns:
            是否成功完成
        """
        future = self._futures.get(agent_id)
        if not future:
            return False

        try:
            future.result(timeout=timeout)
            return True
        except Exception:
            return False

    def wait_all(self, timeout: float = 120.0) -> dict:
        """等待所有运行中的 Agent 完成。

        Returns:
            各 Agent 的完成状态
        """
        results = {}
        for agent_id, future in list(self._futures.items()):
            try:
                future.result(timeout=timeout)
                results[agent_id] = "completed"
            except Exception as e:
                results[agent_id] = f"failed: {str(e)}"
        return results

    def recycle(self, agent_id: str) -> None:
        """回收一个 Agent（释放资源）。"""
        agent = self._agents.get(agent_id)
        if agent and agent.state in (AgentState.COMPLETED, AgentState.TIMEOUT, AgentState.FAILED):
            agent.state = AgentState.RECYCLED
            self._stats["total_recycled"] += 1
            self._futures.pop(agent_id, None)

    def recycle_all_finished(self) -> int:
        """回收所有已完成的 Agent。"""
        count = 0
        for agent_id in list(self._agents.keys()):
            agent = self._agents[agent_id]
            if agent.state in (AgentState.COMPLETED, AgentState.TIMEOUT, AgentState.FAILED):
                self.recycle(agent_id)
                count += 1
        return count

    def get_active_agents(self) -> list[ManagedAgent]:
        """获取所有活跃的 Agent。"""
        return [a for a in self._agents.values() if a.is_alive]

    def get_all_agents(self) -> list[dict]:
        """获取所有 Agent 的信息。"""
        return [
            {
                "agent_id": a.agent_id,
                "name": a.name,
                "state": a.state.value,
                "task": a.task,
                "runtime_ms": round(a.runtime_ms, 1),
                "has_result": a.result is not None,
                "error": a.error,
            }
            for a in self._agents.values()
        ]

    def get_stats(self) -> dict:
        """获取管理器统计信息。"""
        active = len(self.get_active_agents())
        return {
            **self._stats,
            "currently_active": active,
            "total_registered": len(self._agents),
        }

    def shutdown(self) -> None:
        """关闭管理器，释放所有资源。"""
        self._executor.shutdown(wait=False)

def demo_lifecycle():
    """演示 Agent 生命周期管理器的完整功能。"""
    print("=" * 70)
    print("  Exercise 14: Agent Lifecycle Manager")
    print("=" * 70)

    manager = AgentLifecycleManager(max_concurrent=5)

    # --- 场景 1：基本生命周期 ---
    print("\n--- Scenario 1: Basic Lifecycle ---\n")

    # 创建 Agent
    agent_id = manager.create_agent("worker-01", timeout_sec=5)
    print(f"  Created agent: {agent_id}, state={manager.get_state(agent_id).value}")

    # 定义任务处理函数
    def quick_task(task_desc: str) -> str:
        time.sleep(0.1)
        return f"Completed: {task_desc}"

    # 分配任务
    success = manager.assign_task(agent_id, "Process data", quick_task)
    print(f"  Assigned task, state={manager.get_state(agent_id).value}")

    # 等待完成
    manager.wait_for_completion(agent_id)
    print(f"  After completion, state={manager.get_state(agent_id).value}")
    print(f"  Result: {manager.get_result(agent_id)}")

    # 回收
    manager.recycle(agent_id)
    print(f"  After recycle, state={manager.get_state(agent_id).value}")

    # --- 场景 2：超时回收 ---
    print("\n--- Scenario 2: Timeout Recovery ---\n")

    timeout_agent = manager.create_agent("slow-worker", timeout_sec=0.2)

    def slow_task(task_desc: str) -> str:
        time.sleep(1.0)  # 模拟慢任务
        return "Done (but slow)"

    manager.assign_task(timeout_agent, "Long running task", slow_task)
    print(f"  Started slow agent, state={manager.get_state(timeout_agent).value}")

    # 等待超时
    time.sleep(0.3)
    timed_out = manager.check_timeouts()
    print(f"  Timed out agents: {timed_out}")
    print(f"  Agent state: {manager.get_state(timeout_agent).value}")

    # --- 场景 3：批量管理 ---
    print("\n--- Scenario 3: Batch Management ---\n")

    # 创建回调收集器
    completion_log = []
    def on_complete(aid: str, success: bool, result: Any) -> None:
        completion_log.append({"agent": aid, "success": success, "result": str(result)[:40]})

    # 创建 5 个 Agent 并行执行
    task_configs = [
        ("research-task", 0.15),
        ("analysis-task", 0.10),
        ("code-task", 0.20),
        ("write-task", 0.08),
        ("review-task", 0.12),
    ]

    for task_name, duration in task_configs:
        aid = manager.create_agent(task_name, timeout_sec=5)
        manager.on_complete(aid, on_complete)

        def make_handler(dur):
            def handler(task_desc: str) -> str:
                time.sleep(dur)
                return f"Result of {task_desc}"
            return handler

        manager.assign_task(aid, task_name, make_handler(duration))

    # 等待所有完成
    results = manager.wait_all(timeout=10)

    print(f"  Batch results:")
    for aid, status in results.items():
        agent = manager._agents[aid]
        print(f"    {agent.name:<20s}: {status} ({agent.runtime_ms:.0f}ms)")

    print(f"\n  Callback log ({len(completion_log)} events):")
    for log in completion_log:
        print(f"    {log['agent']}: success={log['success']}, result={log['result']}")

    # --- 场景 4：统计与状态 ---
    print("\n--- Scenario 4: Statistics ---\n")

    # 回收所有已完成的
    recycled = manager.recycle_all_finished()
    print(f"  Recycled {recycled} finished agents")

    stats = manager.get_stats()
    print(f"\n  Manager Statistics:")
    for k, v in stats.items():
        print(f"    {k}: {v}")

    print(f"\n  All Agents:")
    for agent_info in manager.get_all_agents():
        print(f"    {agent_info['agent_id']}: {agent_info['name']:<20s} "
              f"[{agent_info['state']:<10s}] {agent_info['runtime_ms']:.0f}ms")

    manager.shutdown()

    print("\n" + "=" * 70)
    print("  Demo complete!")
    print("=" * 70)


if __name__ == "__main__":
    demo_lifecycle()
```
