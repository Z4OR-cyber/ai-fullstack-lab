# 模块一：Fine-Tuning（模型微调）

## 知识总览

**微调 vs 预训练 vs Prompt 工程：**

| 维度 | 预训练 (Pre-training) | 微调 (Fine-Tuning) | Prompt 工程 |
|------|----------------------|--------------------|--------------|
| 目标 | 从零学习通用语言表示 | 在已有模型上适配特定任务 | 不改权重，靠输入设计引导模型 |
| 数据量 | 万亿 token 级 | 千～百万条 | 零（仅推理时设计） |
| 计算成本 | 极高（千卡·天） | 中等（单卡～多卡） | 极低 |
| 适用场景 | 基座模型训练 | 领域适配、风格定制、对齐 | 快速原型、零成本试错 |

**核心概念速览：**

- **SFT（Supervised Fine-Tuning）**：用 instruction-response 对监督微调，损失函数为交叉熵，但只在 response 部分计算 loss（instruction 部分做 mask）。
- **LoRA（Low-Rank Adaptation）**：冻结原模型权重 W，新增低秩矩阵 ΔW = B·A（A: d×r, B: r×d, r≪d），只训练 A 和 B，可训练参数量从 d² 降到 2dr。
- **DPO（Direct Preference Optimization）**：跳过奖励模型，直接从偏好对 (chosen, rejected) 学习。损失函数基于 chosen/rejected 的 log-ratio 差。
- **微调数据准备**：JSONL 格式化 → tokenize → batch → pad/mask，还需去重和质量过滤。

## 第 482 题：实现 SFT 损失函数（交叉熵 + Instruction Masking）

### 知识讲解

在监督微调（SFT）中，一条训练样本通常是：

```
{"instruction": "请翻译以下句子", "input": "Hello world", "output": "你好世界"}
```

将整条样本拼接后 tokenize，得到 token 序列。**关键点**：损失函数只在 `output`（即 response）部分的 token 上计算交叉熵损失，instruction 和 input 部分的 loss 被 mask 掉（设为 0）。这样做的原因是：我们只想教模型"如何回答"，而不是"如何复述问题"。

**交叉熵损失**：对于位置 t 的预测 logits z_t 和真实标签 y_t：

$$\mathcal{L}_t = -\log \frac{e^{z_{t,y_t}}}{\sum_{k} e^{z_{t,k}}}$$

**SFT Loss** = 对所有 response 位置的 $\mathcal{L}_t$ 求平均。

### 完整代码

```python
import numpy as np


def softmax(logits):
    """数值稳定的 softmax，沿最后一个维度计算。

    Args:
        logits: shape (..., vocab_size)
    Returns:
        probs: shape (..., vocab_size)，每行和为 1
    """
    # 减去最大值防止 exp 溢出
    max_logits = np.max(logits, axis=-1, keepdims=True)
    exp_logits = np.exp(logits - max_logits)
    return exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)


def cross_entropy_loss(logits, targets):
    """计算逐 token 的交叉熵损失。

    Args:
        logits:  (batch, seq_len, vocab_size) 模型输出
        targets: (batch, seq_len)             真实 token id
    Returns:
        per_token_loss: (batch, seq_len) 每个 token 的损失值
    """
    batch, seq_len, vocab_size = logits.shape
    probs = softmax(logits)  # (batch, seq_len, vocab_size)

    # 取出每个位置真实 token 对应的概率
    # targets: (batch, seq_len) → 展平后索引
    flat_targets = targets.reshape(-1)  # (batch * seq_len,)
    flat_probs = probs.reshape(-1, vocab_size)  # (batch * seq_len, vocab_size)

    # 取出真实 token 对应概率，加 epsilon 防 log(0)
    correct_probs = flat_probs[np.arange(len(flat_targets)), flat_targets]
    per_token_loss = -np.log(correct_probs + 1e-12)

    return per_token_loss.reshape(batch, seq_len)


def sft_loss(logits, targets, loss_mask):
    """SFT 损失函数：只在 response 部分计算交叉熵。

    Args:
        logits:    (batch, seq_len, vocab_size) 模型输出 logits
        targets:   (batch, seq_len)             真实 token id（右移一位的目标）
        loss_mask: (batch, seq_len)             1 表示该位置参与损失计算，0 表示 mask
    Returns:
        loss: 标量，被 mask 位置的平均损失
    """
    per_token_loss = cross_entropy_loss(logits, targets)  # (batch, seq_len)

    # 只保留 mask=1 的位置
    masked_loss = per_token_loss * loss_mask  # 逐元素乘以 mask

    # 求平均：总和 / mask 中 1 的个数
    total_loss = np.sum(masked_loss)
    num_tokens = np.sum(loss_mask)

    if num_tokens == 0:
        return 0.0

    return total_loss / num_tokens


# ======================== 测试 ========================
if __name__ == "__main__":
    np.random.seed(42)

    # 模拟一个 batch：batch_size=2, seq_len=6, vocab_size=10
    batch_size, seq_len, vocab_size = 2, 6, 10

    # 随机生成模型输出 logits
    logits = np.random.randn(batch_size, seq_len, vocab_size)

    # 样本1: instruction(2) + response(4)
    # 样本2: instruction(3) + response(3)
    targets = np.array([
        [3, 5, 1, 7, 2, 8],   # token id 序列
        [0, 4, 6, 1, 9, 3],
    ])

    # loss_mask: instruction 部分为 0，response 部分为 1
    # 样本1: 前2位是 instruction(mask=0)，后4位是 response(mask=1)
    # 样本2: 前3位是 instruction(mask=0)，后3位是 response(mask=1)
    loss_mask = np.array([
        [0, 0, 1, 1, 1, 1],
        [0, 0, 0, 1, 1, 1],
    ], dtype=np.float32)

    loss = sft_loss(logits, targets, loss_mask)
    print(f"SFT Loss: {loss:.4f}")

    # 验证：如果不 mask，全序列的 loss 应该不同

    # 验证 mask 逻辑：手动计算样本1的 response 部分损失

    manual_loss_0 /= 4  # 4 个 response token

    # 样本2的 response 部分损失
    probs_sample1 = softmax(logits[1])
    manual_loss_1 = 0.0
    for t in range(3, 6):
        p = probs_sample1[t, targets[1, t]]

    manual_loss_1 /= 3

    manual_avg = (manual_loss_0 + manual_loss_1) / 2
```

## 第 483 题：实现 LoRA 层（低秩矩阵分解 + 前向传播 + 只训练 A/B 矩阵）

### 知识讲解

**LoRA（Low-Rank Adaptation）** 的核心思想：

原始线性层的前向传播为 `y = W·x`，其中 W 是 d_out × d_in 的大矩阵。LoRA 不修改 W，而是增加一个低秩更新：

$$y = W \cdot x + \Delta W \cdot x = W \cdot x + B \cdot A \cdot x$$

其中：
- A: r × d_in（降维矩阵，r ≪ d_in）
- B: d_out × r（升维矩阵）
- r 是秩（rank），通常取 4、8、16、64

**参数量对比**：
- 全量微调：d_out × d_in
- LoRA：r × d_in + d_out × r = r × (d_in + d_out)，当 r ≪ d 时远小于全量

**初始化策略**：
- A 用高斯随机初始化
- B 用零初始化（这样训练初期 ΔW = B·A = 0，不改变原模型输出）

**缩放因子 α**：ΔW = (α/r) · B·A，用于控制 LoRA 更新的幅度。

### 完整代码

```python
import numpy as np


class LoRALinear:
    """LoRA 线性层：冻结原始权重 W，只训练低秩矩阵 A 和 B。

    前向传播: y = W @ x + (alpha / r) * B @ A @ x
    """

    def __init__(self, d_in, d_out, rank=8, alpha=16, seed=42):
        """初始化 LoRA 层。

        Args:
            d_in:  输入维度
            d_out: 输出维度
            rank:  LoRA 秩（低秩矩阵的中间维度）
            alpha: 缩放因子
            seed:  随机种子
        """
        rng = np.random.RandomState(seed)

        # ---- 冻结的原始权重 W（模拟预训练好的模型参数）----
        self.W = rng.randn(d_out, d_in) * 0.02  # 小随机初始化
        self.W_frozen = True  # 标记：W 不会被更新

        # ---- LoRA 低秩矩阵 ----
        # A: (rank, d_in) — 降维，高斯初始化
        self.A = rng.randn(rank, d_in) * 0.01
        # B: (d_out, rank) — 升维，零初始化（保证训练初始 ΔW=0）
        self.B = np.zeros((d_out, rank))

        self.rank = rank
        self.alpha = alpha
        self.scaling = alpha / rank  # 缩放因子

        # 梯度和 Adam 优化器状态
        self._init_adam()

    def _init_adam(self):
        """初始化 Adam 优化器状态。"""
        self.m_A = np.zeros_like(self.A)
        self.v_A = np.zeros_like(self.A)
        self.m_B = np.zeros_like(self.B)
        self.v_B = np.zeros_like(self.B)
        self.t = 0  # 时间步

    def forward(self, x):
        """前向传播。

        Args:
            x: (batch, d_in) 或 (d_in,)
        Returns:
            y: (batch, d_out) 或 (d_out,)
        """
        # 原始层输出（冻结权重）
        y_base = x @ self.W.T  # (batch, d_out)

        # LoRA 增量: (alpha/r) * B @ A @ x
        # A @ x: (rank, d_in) @ (batch, d_in).T = (rank, batch) → 转置为 (batch, rank)
        # B @ (A @ x): (batch, rank) @ (rank, d_out).T → (batch, d_out)
        Ax = x @ self.A.T  # (batch, rank)
        y_lora = Ax @ self.B.T  # (batch, d_out)

        y = y_base + self.scaling * y_lora

        # 保存中间结果供反向传播使用
        self._cache = {"x": x, "Ax": Ax}
        return y

    def backward(self, grad_output):
        """反向传播：计算 A 和 B 的梯度（W 不更新）。

        Args:
            grad_output: (batch, d_out) 上游传来的梯度
        """
        x = self._cache["x"]   # (batch, d_in)
        Ax = self._cache["Ax"]  # (batch, rank)

        # LoRA 输出的梯度: grad_output * scaling
        grad_lora = grad_output * self.scaling  # (batch, d_out)

        # ---- B 的梯度 ----
        # y_lora = Ax @ B.T → dL/dB = grad_lora.T @ Ax
        # grad_B: (d_out, rank) = (d_out, batch) @ (batch, rank)
        self.grad_B = grad_lora.T @ Ax  # (d_out, rank)

        # ---- A 的梯度 ----
        # y_lora = (x @ A.T) @ B.T
        # dL/dAx = grad_lora @ B → (batch, rank)
        grad_Ax = grad_lora @ self.B  # (batch, rank)
        # dL/dA = grad_Ax.T @ x → (rank, d_in)
        self.grad_A = grad_Ax.T @ x  # (rank, d_in)

        # 注意：W 的梯度不计算，因为 W 被冻结

    def adam_step(self, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        """Adam 优化器更新 A 和 B（不更新 W）。"""
        self.t += 1

        # 更新 A
        self.m_A = beta1 * self.m_A + (1 - beta1) * self.grad_A
        self.v_A = beta2 * self.v_A + (1 - beta2) * self.grad_A ** 2
        m_hat_A = self.m_A / (1 - beta1 ** self.t)
        v_hat_A = self.v_A / (1 - beta2 ** self.t)
        self.A -= lr * m_hat_A / (np.sqrt(v_hat_A) + eps)

        # 更新 B
        self.m_B = beta1 * self.m_B + (1 - beta1) * self.grad_B
        self.v_B = beta2 * self.v_B + (1 - beta2) * self.grad_B ** 2
        m_hat_B = self.m_B / (1 - beta1 ** self.t)
        v_hat_B = self.v_B / (1 - beta2 ** self.t)
        self.B -= lr * m_hat_B / (np.sqrt(v_hat_B) + eps)

    def count_parameters(self):
        """统计可训练参数量。"""
        trainable = self.A.size + self.B.size
        frozen = self.W.size
        return trainable, frozen


# ======================== 测试 ========================
if __name__ == "__main__":
    np.random.seed(42)

    # 创建 LoRA 线性层：d_in=512, d_out=512, rank=8
    d_in, d_out = 512, 512
    lora_layer = LoRALinear(d_in, d_out, rank=8, alpha=16)

    # 参数量对比
    trainable, frozen = lora_layer.count_parameters()
    print(f"可训练参数: {trainable:,}  (A: {lora_layer.A.size}, B: {lora_layer.B.size})")
    print(f"冻结参数:   {frozen:,}  (W)")
    print(f"参数压缩比: {trainable / frozen:.2%}  (可训练/总参数)")

    # 验证初始时 ΔW = 0（B 初始化为零）
    x = np.random.randn(4, d_in)
    y = lora_layer.forward(x)
    y_base_expected = x @ lora_layer.W.T
    print(f"\n初始时 LoRA 增量为零: {np.allclose(y, y_base_expected)}")

    # 模拟训练：目标是用 LoRA 拟合一个目标函数
    target_W = np.random.randn(d_out, d_in) * 0.05  # 目标权重
    num_steps = 500
    losses = []

    for step in range(num_steps):
        # 随机输入
        x_batch = np.random.randn(8, d_in)
        # 目标输出（用目标权重计算）
        y_target = x_batch @ target_W.T

        # 前向传播
        y_pred = lora_layer.forward(x_batch)

        # 计算 MSE 损失
        loss = np.mean((y_pred - y_target) ** 2)
        losses.append(loss)

        # 反向传播
        grad_output = 2 * (y_pred - y_target) / x_batch.shape[0]
        lora_layer.backward(grad_output)

        # 参数更新
        lora_layer.adam_step(lr=1e-2)

    print(f"\n训练 {num_steps} 步:")
    print(f"  初始 Loss: {losses[0]:.6f}")
    print(f"  最终 Loss: {losses[-1]:.6f}")
    print(f"  Loss 下降: {(1 - losses[-1] / losses[0]) * 100:.1f}%")

    # 验证 B 不再为零（已经学到了东西）
    print(f"\nB 矩阵范数 (训练后): {np.linalg.norm(lora_layer.B):.4f}")
    print(f"A 矩阵范数 (训练后): {np.linalg.norm(lora_layer.A):.4f}")

    # 验证 W 没有变化
    print(f"W 矩阵未变化: {np.allclose(lora_layer.W, lora_layer.W)}")
```

## 第 484 题：实现 DPO 损失函数（偏好对的 Log-Ratio 差）

### 知识讲解

**DPO（Direct Preference Optimization）** 是一种无需训练奖励模型的对齐方法。给定一个 prompt 和两个回答（chosen 和 rejected），DPO 直接从偏好数据中学习。

**核心公式**：

$$\mathcal{L}_{DPO} = -\log \sigma\left(\beta \left[\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right]\right)$$

其中：
- $y_w$：chosen（偏好回答），$y_l$：rejected（不偏好回答）
- $\pi_\theta$：当前策略（正在训练的模型）
- $\pi_{ref}$：参考策略（通常是 SFT 后的模型，冻结不动）
- $\beta$：温度参数，控制偏离参考模型的程度
- $\sigma$：sigmoid 函数

**直觉理解**：
- $\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}$ 衡量当前模型相对于参考模型，对 chosen 回答的偏好变化
- 整个损失鼓励模型提升 chosen 的概率、降低 rejected 的概率（相对于参考模型）
- 当 β 很大时，模型被严格限制在参考模型附近；β 很小时，模型可以大幅偏离

### 完整代码

```python
import numpy as np


def sigmoid(x):
    """数值稳定的 sigmoid 函数。"""
    # 对正负值分别处理防止溢出
    result = np.zeros_like(x, dtype=np.float64)
    pos_mask = x >= 0
    neg_mask = ~pos_mask
    result[pos_mask] = 1.0 / (1.0 + np.exp(-x[pos_mask]))
    exp_x = np.exp(x[neg_mask])
    result[neg_mask] = exp_x / (1.0 + exp_x)
    return result


def log_softmax(logits):
    """数值稳定的 log-softmax，沿最后一个维度。"""
    max_logits = np.max(logits, axis=-1, keepdims=True)
    shifted = logits - max_logits
    log_sum_exp = np.log(np.sum(np.exp(shifted), axis=-1, keepdims=True))
    return shifted - log_sum_exp


def compute_sequence_logprob(logits, targets):
    """计算一个 token 序列的对数概率。

    Args:
        logits:  (seq_len, vocab_size) 模型在该序列上的输出
        targets: (seq_len,)            真实 token id
    Returns:
        logprob: 标量，序列的对数概率 = sum(log p(token_t | context))
    """
    log_probs = log_softmax(logits)  # (seq_len, vocab_size)
    # 取出每个位置真实 token 的 log 概率
    seq_len = targets.shape[0]
    token_log_probs = log_probs[np.arange(seq_len), targets]  # (seq_len,)
    return np.sum(token_log_probs)


def dpo_loss(policy_chosen_logps,    # (batch,) 策略模型对 chosen 的 log-prob
             policy_rejected_logps,  # (batch,) 策略模型对 rejected 的 log-prob
             ref_chosen_logps,       # (batch,) 参考模型对 chosen 的 log-prob
             ref_rejected_logps,     # (batch,) 参考模型对 rejected 的 log-prob
             beta=0.1):
    """DPO 损失函数。

    Args:
        policy_chosen_logps:   当前策略模型对 chosen 回答的对数概率
        policy_rejected_logps: 当前策略模型对 rejected 回答的对数概率
        ref_chosen_logps:      参考模型对 chosen 回答的对数概率
        ref_rejected_logps:    参考模型对 rejected 回答的对数概率
        beta: 温度参数，控制偏离参考模型的程度
    Returns:
        loss: 标量损失
        metrics: dict 包含 chosen/reward 等中间量
    """
    # 计算 log-ratio: log(π_θ(y) / π_ref(y))
    chosen_logratio = policy_chosen_logps - ref_chosen_logps      # (batch,)
    rejected_logratio = policy_rejected_logps - ref_rejected_logps  # (batch,)

    # DPO 的 logits: β * (chosen_logratio - rejected_logratio)
    dpo_logits = beta * (chosen_logratio - rejected_logratio)  # (batch,)

    # 损失: -log(sigmoid(dpo_logits))
    loss = -np.log(sigmoid(dpo_logits) + 1e-12)  # (batch,)
    loss = np.mean(loss)

    # 计算隐式奖励（用于监控）
    chosen_rewards = beta * chosen_logratio      # (batch,)
    rejected_rewards = beta * rejected_logratio  # (batch,)

    # 奖励差（应 > 0 表示 chosen 优于 rejected）
    reward_margin = chosen_rewards - rejected_rewards

    # 准确率：chosen 被偏好的比例
    accuracy = np.mean(dpo_logits > 0)

    metrics = {
        "loss": loss,
        "chosen_reward": np.mean(chosen_rewards),
        "rejected_reward": np.mean(rejected_rewards),
        "reward_margin": np.mean(reward_margin),
        "accuracy": accuracy,
    }
    return loss, metrics


def dpo_loss_grad(policy_chosen_logps, policy_rejected_logps,
                  ref_chosen_logps, ref_rejected_logps, beta=0.1):
    """计算 DPO 损失对策略模型 log-prob 的梯度（用于反向传播）。

    Returns:
        grad_chosen:   (batch,) 对 chosen log-prob 的梯度
        grad_rejected: (batch,) 对 rejected log-prob 的梯度
    """
    chosen_logratio = policy_chosen_logps - ref_chosen_logps
    rejected_logratio = policy_rejected_logps - ref_rejected_logps
    dpo_logits = beta * (chosen_logratio - rejected_logratio)

    # dL/d(dpo_logits) = -(1 - sigmoid(dpo_logits)) / batch_size
    # 因为 L = -log(sigmoid(z)), dL/dz = -(1-sigmoid(z))
    batch_size = len(policy_chosen_logps)
    grad_dpo_logits = -(1 - sigmoid(dpo_logits)) / batch_size  # (batch,)

    # d(dpo_logits)/d(chosen_logratio) = beta
    # d(chosen_logratio)/d(policy_chosen_logps) = 1
    grad_chosen = grad_dpo_logits * beta      # (batch,)
    grad_rejected = -grad_dpo_logits * beta   # (batch,) 注意符号

    return grad_chosen, grad_rejected
```

## 第 485 题：实现微调数据管道（JSONL 读取 → Tokenize → Batch → Pad/Mask）

### 知识讲解

微调数据管道是 SFT 训练的前置步骤，完整流程如下：

```
原始 JSONL 文件 → 逐条解析 → Tokenize → 拼接 instruction+response → 填充对齐 → 构建 batch → 生成 loss_mask
```

**关键步骤**：

1. **JSONL 读取**：每行是一个 JSON 对象，包含 instruction、input（可选）、output 字段。
2. **Tokenize**：将文本转为 token id 序列。这里实现一个简化的 BPE-like 分词器。
3. **拼接**：`[BOS] + instruction_tokens + [SEP] + response_tokens + [EOS]`
4. **Loss Mask**：instruction 部分标记为 0（不计算损失），response 部分标记为 1。
5. **Padding**：将同一 batch 内不同长度的序列填充到相同长度，用 pad_token 填充，attention_mask 标记有效位置。
6. **Batching**：将多条样本组成 batch。

### 完整代码

```python
import numpy as np
import json


# ======================== 简化版分词器 ========================
class SimpleTokenizer:
    """简化版字符级分词器（仅用于演示数据管道流程）。

    实际场景中应使用 BPE/SentencePiece 等分词器。
    """

    def __init__(self):
        # 特殊 token
        self.pad_token = "<pad>"
        self.bos_token = "<bos>"
        self.eos_token = "<eos>"
        self.sep_token = "<sep>"

        # 构建 vocab：特殊 token + 常见字符
        special_tokens = [self.pad_token, self.bos_token, self.eos_token, self.sep_token]
        chars = list("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789 ,.!?;:'\"-()[]{}@#\n")
        self.vocab = special_tokens + chars
        self.token_to_id = {t: i for i, t in enumerate(self.vocab)}
        self.id_to_token = {i: t for i, t in enumerate(self.vocab)}

        # 特殊 token id
        self.pad_id = self.token_to_id[self.pad_token]
        self.bos_id = self.token_to_id[self.bos_token]
        self.eos_id = self.token_to_id[self.eos_token]
        self.sep_id = self.token_to_id[self.sep_token]

        self.vocab_size = len(self.vocab)

    def encode(self, text):
        """将文本编码为 token id 列表。"""
        ids = []
        for ch in text:
            if ch in self.token_to_id:
                ids.append(self.token_to_id[ch])
            # 未知字符跳过（实际应使用 <unk> token）
        return ids

    def decode(self, ids):
        """将 token id 列表解码为文本。"""
        tokens = []
        for i in ids:
            if i in self.id_to_token:
                t = self.id_to_token[i]
                if t not in [self.pad_token, self.bos_token, self.eos_token, self.sep_token]:
                    tokens.append(t)
        return "".join(tokens)


# ======================== 数据管道 ========================
def create_sample(instruction, response, tokenizer, input_text=""):
    """将一条 instruction-response 对转换为 token 序列 + loss_mask。

    格式: [BOS] + instruction + [SEP] + response + [EOS]
    Loss mask: instruction 部分为 0，response + [EOS] 部分为 1

    Returns:
        input_ids:  list[int]  token id 序列
        loss_mask:  list[int]  与 input_ids 等长，1 表示该位置计算损失
    """
    # 编码各部分
    inst_ids = tokenizer.encode(instruction)
    if input_text:
        inst_ids += tokenizer.encode(input_text)
    resp_ids = tokenizer.encode(response)

    # 拼接: [BOS] + instruction + [SEP] + response + [EOS]
    input_ids = [tokenizer.bos_id] + inst_ids + [tokenizer.sep_id] + resp_ids + [tokenizer.eos_id]

    # 构建 loss_mask: instruction 部分为 0，response + EOS 部分为 1
    # 注意: SEP 也不计算 loss（它是分隔符）
    inst_len = len(inst_ids)
    loss_mask = (
        [0]                          # BOS: 不计算
        + [0] * inst_len             # instruction: 不计算
        + [0]                        # SEP: 不计算
        + [1] * len(resp_ids)        # response: 计算
        + [1]                        # EOS: 计算（教模型学会停止）
    )

    assert len(input_ids) == len(loss_mask), f"长度不匹配: {len(input_ids)} vs {len(loss_mask)}"
    return input_ids, loss_mask


def pad_sequences(sequences, pad_id, max_len=None):
    """将不等长序列填充到相同长度。

    Args:
        sequences: list of list[int]
        pad_id:    填充 token id
        max_len:   最大长度，None 则取 batch 内最长
    Returns:
        padded:    (batch, max_len) numpy 数组
        attention_mask: (batch, max_len) 1=有效, 0=padding
    """
    if max_len is None:
        max_len = max(len(seq) for seq in sequences)

    padded = np.full((len(sequences), max_len), pad_id, dtype=np.int64)
    attention_mask = np.zeros((len(sequences), max_len), dtype=np.int64)

    for i, seq in enumerate(sequences):
        length = min(len(seq), max_len)
        padded[i, :length] = seq[:length]
        attention_mask[i, :length] = 1

    return padded, attention_mask


def create_batches(samples, batch_size, pad_id, shuffle=True, seed=42):
    """将样本列表组织成 batch。

    Args:
        samples:    list of (input_ids, loss_mask) 元组
        batch_size: 每个 batch 的样本数
        pad_id:     填充 token id
        shuffle:    是否打乱顺序
        seed:       随机种子
    Returns:
        list of dict, 每个包含:
            - input_ids:       (batch, seq_len)
            - attention_mask:  (batch, seq_len)
            - loss_mask:       (batch, seq_len)
            - labels:          (batch, seq_len) 右移一位的目标
    """
    rng = np.random.RandomState(seed)
    indices = list(range(len(samples)))
    if shuffle:
        rng.shuffle(indices)

    batches = []
    for start in range(0, len(indices), batch_size):
        batch_indices = indices[start:start + batch_size]
        batch_samples = [samples[i] for i in batch_indices]

        input_id_list = [s[0] for s in batch_samples]
        loss_mask_list = [s[1] for s in batch_samples]

        # 填充对齐
        input_ids, attention_mask = pad_sequences(input_id_list, pad_id)
        loss_masks, _ = pad_sequences(loss_mask_list, 0)  # loss_mask 用 0 填充

        # 构建标签：右移一位（next token prediction）
        # labels[t] = input_ids[t+1], 最后一位用 pad_id
        labels = np.full_like(input_ids, pad_id)
        labels[:, :-1] = input_ids[:, 1:]
        # 只有 attention_mask=1 且 loss_mask=1 的位置计算损失
        # labels 中 padding 位置设为 -100（PyTorch 风格的 ignore_index）
        labels[attention_mask == 0] = -100

        batches.append({
            "input_ids": input_ids,
            "attention_mask": attention_mask,
            "loss_mask": loss_masks,
            "labels": labels,
        })

    return batches
```

## 第 486 题：实现微调训练循环（前向 → 损失 → 反向 → 更新）

### 知识讲解

本题将前面几题的组件整合成一个完整的微调训练循环。使用 numpy 实现一个简化但完整的训练流程：

```
for each batch:
    1. 前向传播：input_ids → embedding → linear → logits
    2. 计算损失：SFT loss（带 instruction masking）
    3. 反向传播：计算各层参数的梯度
    4. 参数更新：Adam 优化器
    5. 记录指标：loss、accuracy
```

**模型结构（简化版）**：
- Embedding 层：token id → 向量
- 单层线性变换：模拟 Transformer 的一层
- 输出投影：映射到词表大小

**反向传播**：
- 对交叉熵损失求导 → softmax 梯度 → 线性层梯度 → embedding 梯度

### 完整代码

```python
import numpy as np


# ======================== 简化模型 ========================
class SimpleLanguageModel:
    """极简语言模型：Embedding + 单层线性变换 + 输出投影。

    仅用于演示微调训练循环的完整流程。
    实际微调使用的是完整的 Transformer/GPT 模型。
    """

    def __init__(self, vocab_size, d_model=64, seed=42):
        rng = np.random.RandomState(seed)
        self.vocab_size = vocab_size
        self.d_model = d_model

        # Embedding 层: (vocab_size, d_model)
        self.embedding = rng.randn(vocab_size, d_model) * 0.1

        # 线性层权重: (d_model, d_model)
        self.W1 = rng.randn(d_model, d_model) * np.sqrt(2.0 / d_model)
        self.b1 = np.zeros(d_model)

        # 输出投影: (d_model, vocab_size)
        self.W_out = rng.randn(d_model, vocab_size) * np.sqrt(2.0 / d_model)
        self.b_out = np.zeros(vocab_size)

        # 收集所有参数
        self.params = {
            "embedding": self.embedding,
            "W1": self.W1, "b1": self.b1,
            "W_out": self.W_out, "b_out": self.b_out,
        }
        self._init_adam()

    def _init_adam(self):
        """初始化 Adam 状态。"""
        self.adam_state = {}
        for name, param in self.params.items():
            self.adam_state[name] = {
                "m": np.zeros_like(param),
                "v": np.zeros_like(param),
            }
        self.t = 0

    def forward(self, input_ids):
        """前向传播。

        Args:
            input_ids: (batch, seq_len) token id
        Returns:
            logits: (batch, seq_len, vocab_size)
            cache:  中间结果用于反向传播
        """
        batch, seq_len = input_ids.shape

        # 1. Embedding 查表
        x = self.embedding[input_ids]  # (batch, seq_len, d_model)

        # 2. 线性变换 + ReLU
        z1 = x @ self.W1 + self.b1     # (batch, seq_len, d_model)
        a1 = np.maximum(0, z1)          # ReLU 激活

        # 3. 输出投影
        logits = a1 @ self.W_out + self.b_out  # (batch, seq_len, vocab_size)

        cache = {"input_ids": input_ids, "x": x, "z1": z1, "a1": a1}
        return logits, cache

    def backward(self, logits, targets, loss_mask, cache):
        """反向传播：计算所有参数的梯度。

        Args:
            logits:    (batch, seq_len, vocab_size)
            targets:   (batch, seq_len)
            loss_mask: (batch, seq_len) 1=参与损失
            cache:     前向传播的中间结果
        Returns:
            grads: dict, 各参数的梯度
        """
        batch, seq_len, vocab_size = logits.shape
        input_ids = cache["input_ids"]
        x = cache["x"]      # (batch, seq_len, d_model)
        z1 = cache["z1"]    # (batch, seq_len, d_model)
        a1 = cache["a1"]    # (batch, seq_len, d_model)

        # ---- 1. 交叉熵对 logits 的梯度 ----
        # softmax(logits)
        max_logits = np.max(logits, axis=-1, keepdims=True)
        exp_logits = np.exp(logits - max_logits)
        probs = exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)

        # dL/d_logits = (probs - one_hot(target)) / num_loss_tokens
        # 但只在 loss_mask=1 的位置有梯度
        num_tokens = np.sum(loss_mask)
        if num_tokens == 0:
            num_tokens = 1  # 防除零

        grad_logits = probs.copy()  # (batch, seq_len, vocab_size)
        # 减去 one-hot
        for b in range(batch):
            for t in range(seq_len):
                if loss_mask[b, t] == 1:
                    grad_logits[b, t, targets[b, t]] -= 1
        grad_logits /= num_tokens
        # mask 掉不参与损失的位置
        grad_logits *= loss_mask[:, :, np.newaxis]  # (batch, seq_len, 1)

        # ---- 2. 输出投影的梯度 ----
        # logits = a1 @ W_out + b_out
        # dL/dW_out = sum over batch,seq of a1[b,t].T @ grad_logits[b,t]
        a1_flat = a1.reshape(-1, self.d_model)             # (batch*seq, d_model)
        grad_logits_flat = grad_logits.reshape(-1, vocab_size)  # (batch*seq, vocab)
        grad_W_out = a1_flat.T @ grad_logits_flat          # (d_model, vocab)
        grad_b_out = np.sum(grad_logits_flat, axis=0)      # (vocab,)

        # dL/da1 = grad_logits @ W_out.T
        grad_a1 = grad_logits_flat @ self.W_out.T           # (batch*seq, d_model)
        grad_a1 = grad_a1.reshape(batch, seq_len, self.d_model)

        # ---- 3. ReLU 反向 ----
        grad_z1 = grad_a1 * (z1 > 0)  # ReLU 的导数

        # ---- 4. 线性层的梯度 ----
        # z1 = x @ W1 + b1
        grad_z1_flat = grad_z1.reshape(-1, self.d_model)   # (batch*seq, d_model)
        x_flat = x.reshape(-1, self.d_model)               # (batch*seq, d_model)
        grad_W1 = x_flat.T @ grad_z1_flat                   # (d_model, d_model)
        grad_b1 = np.sum(grad_z1_flat, axis=0)             # (d_model,)

        # dL/dx = grad_z1 @ W1.T
        grad_x = grad_z1_flat @ self.W1.T                   # (batch*seq, d_model)

        # ---- 5. Embedding 的梯度 ----
        grad_embedding = np.zeros_like(self.embedding)
        input_ids_flat = input_ids.reshape(-1)
        grad_x_flat = grad_x  # (batch*seq, d_model)
        np.add.at(grad_embedding, input_ids_flat, grad_x_flat)

        grads = {
            "embedding": grad_embedding,
            "W1": grad_W1, "b1": grad_b1,
            "W_out": grad_W_out, "b_out": grad_b_out,
        }
        return grads

    def adam_step(self, grads, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        """Adam 优化器更新。"""
        self.t += 1
        for name in self.params:
            g = grads[name]
            self.adam_state[name]["m"] = beta1 * self.adam_state[name]["m"] + (1 - beta1) * g
            self.adam_state[name]["v"] = beta2 * self.adam_state[name]["v"] + (1 - beta2) * g ** 2
            m_hat = self.adam_state[name]["m"] / (1 - beta1 ** self.t)
            v_hat = self.adam_state[name]["v"] / (1 - beta2 ** self.t)
            self.params[name] -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # 同步引用
        self.embedding = self.params["embedding"]
        self.W1 = self.params["W1"]
        self.b1 = self.params["b1"]
        self.W_out = self.params["W_out"]
        self.b_out = self.params["b_out"]


# ======================== 训练循环 ========================
def compute_sft_loss_and_acc(logits, targets, loss_mask):
    """计算 SFT 损失和 token 级准确率。

    Args:
        logits:    (batch, seq_len, vocab_size)
        targets:   (batch, seq_len)
        loss_mask: (batch, seq_len)
    Returns:
        loss: 标量
        accuracy: 标量，response 部分的 token 预测准确率
    """
    batch, seq_len, vocab_size = logits.shape

    # softmax
    max_logits = np.max(logits, axis=-1, keepdims=True)
    exp_logits = np.exp(logits - max_logits)
    probs = exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)

    # 逐 token 交叉熵
    correct_probs = np.zeros((batch, seq_len))
    for b in range(batch):
        for t in range(seq_len):
            correct_probs[b, t] = probs[b, t, targets[b, t]]

    per_token_loss = -np.log(correct_probs + 1e-12)
    masked_loss = per_token_loss * loss_mask
    num_tokens = np.sum(loss_mask)
    loss = np.sum(masked_loss) / max(num_tokens, 1)

    # 准确率：预测的 token 是否等于真实 token
    pred_tokens = np.argmax(logits, axis=-1)  # (batch, seq_len)
    correct = (pred_tokens == targets).astype(np.float64) * loss_mask
    accuracy = np.sum(correct) / max(num_tokens, 1)

    return loss, accuracy


def train_loop(model, batches, num_epochs=20, lr=1e-3, verbose=True):
    """微调训练循环。

    Args:
        model:      SimpleLanguageModel 实例
        batches:    list of batch dict (来自数据管道)
        num_epochs: 训练轮数
        lr:         学习率
        verbose:    是否打印训练日志
    Returns:
        history: dict, 每轮的 loss 和 accuracy
    """
    history = {"loss": [], "accuracy": []}

    for epoch in range(num_epochs):
        epoch_loss = 0.0
        epoch_acc = 0.0
        num_batches = 0

        for batch in batches:
            input_ids = batch["input_ids"]       # (batch, seq_len)
            attention_mask = batch["attention_mask"]
            loss_mask = batch["loss_mask"]
            labels = batch["labels"]              # (batch, seq_len), -100 表示忽略

            # 将 -100 替换为 0（避免索引越界），但 loss_mask 已经标记了有效位置
            safe_labels = np.where(labels == -100, 0, labels)

            # 1. 前向传播
            logits, cache = model.forward(input_ids)

            # 2. 计算损失和准确率
            loss, acc = compute_sft_loss_and_acc(logits, safe_labels, loss_mask)
            epoch_loss += loss
            epoch_acc += acc
            num_batches += 1

            # 3. 反向传播
            grads = model.backward(logits, safe_labels, loss_mask, cache)

            # 4. 参数更新
            model.adam_step(grads, lr=lr)

        avg_loss = epoch_loss / max(num_batches, 1)
        avg_acc = epoch_acc / max(num_batches, 1)
        history["loss"].append(avg_loss)
        history["accuracy"].append(avg_acc)

        if verbose and (epoch % 5 == 0 or epoch == num_epochs - 1):
            print(f"Epoch {epoch:3d}/{num_epochs} | Loss: {avg_loss:.4f} | Acc: {avg_acc:.2%}")

    return history
```

# 模块二：Distillation（模型蒸馏）

## 知识总览

**知识蒸馏（Knowledge Distillation）** 的核心思想：用一个大的、能力强的 **Teacher 模型** 指导训练一个小的、高效的 **Student 模型**，使 Student 在保持接近 Teacher 性能的同时大幅减少参数量和推理成本。

**关键概念：**

- **Soft Labels vs Hard Labels**：
  - Hard label：one-hot 向量，如 `[0, 0, 1, 0]`，信息量少
  - Soft label：Teacher 输出的概率分布，如 `[0.01, 0.05, 0.80, 0.14]`，包含类间关系（"暗知识"）
  
- **温度参数 T**：softmax 中引入温度 T，T 越大分布越平滑：
  $$p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$
  高温使 Student 能学到更多类间关系。

- **蒸馏损失**：
  $$\mathcal{L} = \alpha \cdot \mathcal{L}_{soft} + (1 - \alpha) \cdot \mathcal{L}_{hard}$$
  - $\mathcal{L}_{soft}$：Student 与 Teacher 的 soft label 之间的 KL 散度
  - $\mathcal{L}_{hard}$：Student 与真实标签之间的交叉熵
  - $\alpha$：平衡系数

- **Feature-based 蒸馏**：除了输出层，还匹配中间层特征（Teacher 和 Student 的隐藏表示对齐）。

## 第 487 题：实现带温度的 Softmax 和 KL 散度损失

### 知识讲解

**带温度的 Softmax**：

$$p_i^{(T)} = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

- T=1 时退化为标准 softmax
- T→∞ 时趋向均匀分布
- T→0 时趋向 one-hot（argmax）

**KL 散度**（Kullback-Leibler Divergence）衡量两个分布的差异：

$$D_{KL}(P \| Q) = \sum_i P_i \log \frac{P_i}{Q_i}$$

在蒸馏中，P 是 Teacher 的 soft label，Q 是 Student 的 soft label。KL 散度越小，Student 越接近 Teacher。

**蒸馏中的 KL 损失**：

$$\mathcal{L}_{soft} = T^2 \cdot D_{KL}(p_T^{(T)} \| p_S^{(T)})$$

乘以 $T^2$ 是因为高温 softmax 使梯度变小，需要补偿以保持梯度量级与 hard label 损失可比。

### 完整代码

```python
import numpy as np


def softmax_with_temperature(logits, temperature=1.0):
    """带温度的 softmax。

    Args:
        logits: (..., vocab_size)
        temperature: 温度参数 T，T>1 使分布更平滑，T<1 使分布更尖锐
    Returns:
        probs: (..., vocab_size)
    """
    # 数值稳定：减去最大值
    scaled_logits = logits / temperature
    max_logits = np.max(scaled_logits, axis=-1, keepdims=True)
    exp_logits = np.exp(scaled_logits - max_logits)
    return exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)


def kl_divergence(p, q, eps=1e-12):
    """计算 KL(P || Q) = sum_i P_i * log(P_i / Q_i)。

    Args:
        p: (..., vocab_size) Teacher 的概率分布
        q: (..., vocab_size) Student 的概率分布
        eps: 防止 log(0)
    Returns:
        kl: 标量或逐元素 KL 散度
    """
    # KL 散度: sum P * log(P/Q)
    ratio = np.log((p + eps) / (q + eps))
    kl = np.sum(p * ratio, axis=-1)
    return kl


def distillation_soft_loss(student_logits, teacher_logits, temperature=4.0):
    """计算蒸馏的 soft label 损失。

    L_soft = T^2 * KL(softmax(teacher_logits / T) || softmax(student_logits / T))

    Args:
        student_logits: (batch, num_classes) Student 模型输出
        teacher_logits: (batch, num_classes) Teacher 模型输出
        temperature:    温度参数
    Returns:
        loss: 标量
    """
    # Teacher 和 Student 的 soft label
    teacher_probs = softmax_with_temperature(teacher_logits, temperature)
    student_probs = softmax_with_temperature(student_logits, temperature)

    # KL 散度（注意方向：KL(teacher || student)）
    kl = kl_divergence(teacher_probs, student_probs)  # (batch,)

    # 乘以 T^2 补偿梯度缩放
    loss = temperature ** 2 * np.mean(kl)
    return loss


def hard_label_loss(student_logits, targets):
    """标准交叉熵损失（hard label）。

    Args:
        student_logits: (batch, num_classes)
        targets:        (batch,) 真实类别索引
    Returns:
        loss: 标量
    """
    probs = softmax_with_temperature(student_logits, temperature=1.0)
    batch_size = student_logits.shape[0]
    correct_probs = probs[np.arange(batch_size), targets]
    return -np.mean(np.log(correct_probs + 1e-12))


def total_distillation_loss(student_logits, teacher_logits, targets,
                             temperature=4.0, alpha=0.7):
    """总蒸馏损失 = α * soft_loss + (1-α) * hard_loss。

    Args:
        student_logits: (batch, num_classes)
        teacher_logits: (batch, num_classes)
        targets:        (batch,) 真实标签
        temperature:    温度参数
        alpha:          soft loss 权重（0~1）
    Returns:
        loss:  标量总损失
        parts: dict 分项损失
    """
    soft_loss = distillation_soft_loss(student_logits, teacher_logits, temperature)
    hard_loss = hard_label_loss(student_logits, targets)

    total = alpha * soft_loss + (1 - alpha) * hard_loss

    parts = {
        "total": total,
        "soft": soft_loss,
        "hard": hard_loss,
    }
    return total, parts
```

## 第 488 题：实现知识蒸馏训练循环（Teacher 指导 Student）

### 知识讲解

本题将第 487 题的蒸馏损失整合到完整的训练循环中。流程如下：

```
for each batch:
    1. Teacher 前向传播（冻结，不更新）
    2. Student 前向传播
    3. 计算 soft loss（Student vs Teacher 的 KL 散度）
    4. 计算 hard loss（Student vs 真实标签的交叉熵）
    5. 总损失 = α * soft_loss + (1-α) * hard_loss
    6. 反向传播更新 Student 参数
```

**Teacher 模型**：参数量大、已训练好、完全冻结。
**Student 模型**：参数量小、从随机初始化开始训练。

通过蒸馏，Student 不仅学习"正确答案是什么"（hard label），还学习"Teacher 认为其他答案的概率分布"（soft label），从而获得更好的泛化能力。

### 完整代码

```python
import numpy as np


def softmax(z, T=1.0):
    """带温度的 softmax。"""
    z = z / T
    z = z - np.max(z, axis=-1, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=-1, keepdims=True)


def cross_entropy(logits, targets):
    """交叉熵损失。"""
    probs = softmax(logits)
    batch_size = logits.shape[0]
    return -np.mean(np.log(probs[np.arange(batch_size), targets] + 1e-12))


class DistillationModel:
    """简单的两层全连接分类器，用于演示蒸馏训练。

    结构: input → hidden(ReLU) → output(softmax)
    """

    def __init__(self, input_dim, hidden_dim, output_dim, seed=42):
        rng = np.random.RandomState(seed)
        self.W1 = rng.randn(input_dim, hidden_dim) * np.sqrt(2.0 / input_dim)
        self.b1 = np.zeros(hidden_dim)
        self.W2 = rng.randn(hidden_dim, output_dim) * np.sqrt(2.0 / hidden_dim)
        self.b2 = np.zeros(output_dim)
        self._init_adam()

    def _init_adam(self):
        self.adam = {
            name: {"m": np.zeros_like(getattr(self, name)),
                   "v": np.zeros_like(getattr(self, name))}
            for name in ["W1", "b1", "W2", "b2"]
        }
        self.t = 0

    def forward(self, x):
        """前向传播。

        Args:
            x: (batch, input_dim)
        Returns:
            logits: (batch, output_dim)
            cache:  中间结果
        """
        z1 = x @ self.W1 + self.b1     # (batch, hidden)
        a1 = np.maximum(0, z1)          # ReLU
        logits = a1 @ self.W2 + self.b2  # (batch, output)
        cache = {"x": x, "z1": z1, "a1": a1}
        return logits, cache

    def backward(self, grad_logits, cache):
        """反向传播。

        Args:
            grad_logits: (batch, output_dim) 对 logits 的梯度
            cache:       前向传播的中间结果
        Returns:
            grads: dict
        """
        x = cache["x"]
        a1 = cache["a1"]
        z1 = cache["z1"]
        batch_size = x.shape[0]

        grad_W2 = a1.T @ grad_logits / batch_size     # (hidden, output)
        grad_b2 = np.mean(grad_logits, axis=0)        # (output,)
        grad_a1 = grad_logits @ self.W2.T             # (batch, hidden)
        grad_z1 = grad_a1 * (z1 > 0)                  # ReLU 反向
        grad_W1 = x.T @ grad_z1 / batch_size          # (input, hidden)
        grad_b1 = np.mean(grad_z1, axis=0)            # (hidden,)

        return {"W1": grad_W1, "b1": grad_b1, "W2": grad_W2, "b2": grad_b2}

    def adam_step(self, grads, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        self.t += 1
        for name in ["W1", "b1", "W2", "b2"]:
            g = grads[name]
            self.adam[name]["m"] = beta1 * self.adam[name]["m"] + (1 - beta1) * g
            self.adam[name]["v"] = beta2 * self.adam[name]["v"] + (1 - beta2) * g ** 2
            m_hat = self.adam[name]["m"] / (1 - beta1 ** self.t)
            v_hat = self.adam[name]["v"] / (1 - beta2 ** self.t)
            setattr(self, name, getattr(self, name) - lr * m_hat / (np.sqrt(v_hat) + eps))


def distillation_train_step(student, teacher, x, y, temperature=4.0, alpha=0.7, lr=1e-3):
    """单步蒸馏训练。

    Args:
        student:     Student 模型（可训练）
        teacher:     Teacher 模型（冻结）
        x:           (batch, input_dim) 输入
        y:           (batch,) 真实标签
        temperature: 蒸馏温度
        alpha:       soft loss 权重
        lr:          学习率
    Returns:
        metrics: dict 包含各项损失
    """
    batch_size = x.shape[0]

    # 1. Teacher 前向（不计算梯度）
    teacher_logits, _ = teacher.forward(x)
    teacher_probs_T = softmax(teacher_logits, T=temperature)  # (batch, num_classes)

    # 2. Student 前向
    student_logits, cache = student.forward(x)
    student_probs_T = softmax(student_logits, T=temperature)
    student_probs_1 = softmax(student_logits, T=1.0)

    # 3. 计算 soft loss (KL散度 * T^2)
    # KL(teacher || student) = sum teacher * log(teacher/student)
    kl = np.sum(teacher_probs_T * (np.log(teacher_probs_T + 1e-12) -
                                    np.log(student_probs_T + 1e-12)), axis=-1)
    soft_loss = temperature ** 2 * np.mean(kl)

    # 4. 计算 hard loss (交叉熵)
    hard_loss = -np.mean(np.log(student_probs_1[np.arange(batch_size), y] + 1e-12))

    # 5. 总损失
    total_loss = alpha * soft_loss + (1 - alpha) * hard_loss

    # 6. 反向传播
    # 对 student_logits 的梯度:
    # d(soft_loss)/d(logits) = alpha * T^2 * (1/T) * (student_probs_T - teacher_probs_T)
    #                        = alpha * T * (student_probs_T - teacher_probs_T)
    grad_soft = alpha * temperature * (student_probs_T - teacher_probs_T) / batch_size

    # d(hard_loss)/d(logits) = (1-alpha) * (student_probs_1 - one_hot(y)) / batch_size
    one_hot = np.zeros_like(student_probs_1)
    one_hot[np.arange(batch_size), y] = 1
    grad_hard = (1 - alpha) * (student_probs_1 - one_hot) / batch_size

    grad_logits = grad_soft + grad_hard

    # 反向传播 + 更新
    grads = student.backward(grad_logits, cache)
    student.adam_step(grads, lr=lr)

    # 计算准确率
    pred = np.argmax(student_logits, axis=-1)
    accuracy = np.mean(pred == y)

    return {
        "total_loss": total_loss,
        "soft_loss": soft_loss,
        "hard_loss": hard_loss,
        "accuracy": accuracy,
    }


def pure_hard_label_train_step(student, x, y, lr=1e-3):
    """纯 hard label 训练（作为对照组）。

    不使用 Teacher 的 soft label，只使用真实标签。
    """
    batch_size = x.shape[0]
    student_logits, cache = student.forward(x)
    probs = softmax(student_logits, T=1.0)

    hard_loss = -np.mean(np.log(probs[np.arange(batch_size), y] + 1e-12))

    one_hot = np.zeros_like(probs)
    one_hot[np.arange(batch_size), y] = 1
    grad_logits = (probs - one_hot) / batch_size

    grads = student.backward(grad_logits, cache)
    student.adam_step(grads, lr=lr)

    pred = np.argmax(student_logits, axis=-1)
    accuracy = np.mean(pred == y)
    return {"loss": hard_loss, "accuracy": accuracy}
```

## 第 489 题：实现 Feature-based 蒸馏（中间层特征匹配）

### 知识讲解

**Feature-based 蒸馏**（也叫中间层蒸馏）不仅匹配输出层的概率分布，还匹配中间层的特征表示。

**核心思想**：Teacher 的中间层特征包含了丰富的语义信息，让 Student 学习这些特征可以加速收敛并提升性能。

**损失函数**：

$$\mathcal{L}_{feature} = \|f_S(x) - f_T(x)\|^2$$

其中 $f_S$ 和 $f_T$ 分别是 Student 和 Teacher 的中间层特征。

**维度对齐问题**：Teacher 和 Student 的中间层维度可能不同，需要一个投影矩阵将 Student 的特征映射到 Teacher 的维度：

$$\mathcal{L}_{feature} = \|\mathbf{W}_{proj} \cdot f_S(x) - f_T(x)\|^2$$

**总损失**：

$$\mathcal{L} = \alpha \cdot \mathcal{L}_{soft} + \beta \cdot \mathcal{L}_{feature} + (1-\alpha-\beta) \cdot \mathcal{L}_{hard}$$

```python
import numpy as np


def softmax(z, T=1.0):
    """带温度的 softmax。"""
    z = z / T
    z = z - np.max(z, axis=-1, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=-1, keepdims=True)


class FeatureDistillationModel:
    """带中间层特征提取的模型，用于 feature-based 蒸馏。

    结构: input → hidden1(ReLU) → hidden2(ReLU) → output
    特征提取点: hidden2 的输出
    """

    def __init__(self, input_dim, hidden1, hidden2, output_dim, seed=42):
        rng = np.random.RandomState(seed)
        self.W1 = rng.randn(input_dim, hidden1) * np.sqrt(2.0 / input_dim)
        self.b1 = np.zeros(hidden1)
        self.W2 = rng.randn(hidden1, hidden2) * np.sqrt(2.0 / hidden1)
        self.b2 = np.zeros(hidden2)
        self.W3 = rng.randn(hidden2, output_dim) * np.sqrt(2.0 / hidden2)
        self.b3 = np.zeros(output_dim)
        self._init_adam()

    def _init_adam(self):
        self.adam = {
            name: {"m": np.zeros_like(getattr(self, name)),
                   "v": np.zeros_like(getattr(self, name))}
            for name in ["W1", "b1", "W2", "b2", "W3", "b3"]
        }
        self.t = 0

    def forward(self, x):
        """前向传播，同时返回 logits 和中间层特征。

        Returns:
            logits:   (batch, output_dim)
            features: (batch, hidden2) 中间层特征
            cache:    中间结果
        """
        z1 = x @ self.W1 + self.b1
        a1 = np.maximum(0, z1)
        z2 = a1 @ self.W2 + self.b2
        a2 = np.maximum(0, z2)       # ← 特征提取点
        logits = a2 @ self.W3 + self.b3
        cache = {"x": x, "z1": z1, "a1": a1, "z2": z2, "a2": a2}
        return logits, a2, cache

    def backward(self, grad_logits, grad_features, cache):
        """反向传播，同时接收 logits 和 feature 的梯度。

        Args:
            grad_logits:   (batch, output_dim)
            grad_features: (batch, hidden2) 特征匹配损失的梯度
        """
        x = cache["x"]
        a1 = cache["a1"]
        z2 = cache["z2"]
        a2 = cache["a2"]
        batch_size = x.shape[0]

        # 从 logits 到 a2 的梯度
        grad_a2_from_logits = grad_logits @ self.W3.T  # (batch, hidden2)
        # 合并 feature loss 的梯度
        grad_a2 = grad_a2_from_logits + grad_features   # (batch, hidden2)

        # ReLU 反向
        grad_z2 = grad_a2 * (z2 > 0)
        grad_W2 = a1.T @ grad_z2 / batch_size
        grad_b2 = np.mean(grad_z2, axis=0)

        grad_a1 = grad_z2 @ self.W2.T
        grad_z1 = grad_a1 * (cache["z1"] > 0)
        grad_W1 = x.T @ grad_z1 / batch_size
        grad_b1 = np.mean(grad_z1, axis=0)

        # W3, b3 只受 logits 梯度影响
        grad_W3 = a2.T @ grad_logits / batch_size
        grad_b3 = np.mean(grad_logits, axis=0)

        return {"W1": grad_W1, "b1": grad_b1, "W2": grad_W2, "b2": grad_b2,
                "W3": grad_W3, "b3": grad_b3}

    def adam_step(self, grads, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        self.t += 1
        for name in ["W1", "b1", "W2", "b2", "W3", "b3"]:
            g = grads[name]
            self.adam[name]["m"] = beta1 * self.adam[name]["m"] + (1 - beta1) * g
            self.adam[name]["v"] = beta2 * self.adam[name]["v"] + (1 - beta2) * g ** 2
            m_hat = self.adam[name]["m"] / (1 - beta1 ** self.t)
            v_hat = self.adam[name]["v"] / (1 - beta2 ** self.t)
            setattr(self, name, getattr(self, name) - lr * m_hat / (np.sqrt(v_hat) + eps))


class FeatureProjector:
    """投影层：将 Student 特征映射到 Teacher 特征维度。

    如果 Student hidden2 = d_s, Teacher hidden2 = d_t，
    投影矩阵 W_proj: (d_s, d_t)
    """

    def __init__(self, student_dim, teacher_dim, seed=42):
        rng = np.random.RandomState(seed)
        self.W_proj = rng.randn(student_dim, teacher_dim) * np.sqrt(2.0 / student_dim)
        self.m = np.zeros_like(self.W_proj)
        self.v = np.zeros_like(self.W_proj)
        self.t = 0

    def forward(self, student_features):
        """投影 Student 特征到 Teacher 维度。"""
        return student_features @ self.W_proj  # (batch, teacher_dim)

    def backward(self, grad_projected, student_features, batch_size):
        """反向传播。

        Returns:
            grad_features: 回传给 Student 的梯度 (batch, student_dim)
            grad_W_proj:   投影矩阵的梯度 (student_dim, teacher_dim)
        """
        grad_features = grad_projected @ self.W_proj.T  # (batch, student_dim)
        grad_W_proj = student_features.T @ grad_projected / batch_size
        return grad_features, grad_W_proj

    def adam_step(self, grad_W_proj, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        self.t += 1
        self.m = beta1 * self.m + (1 - beta1) * grad_W_proj
        self.v = beta2 * self.v + (1 - beta2) * grad_W_proj ** 2
        m_hat = self.m / (1 - beta1 ** self.t)
        v_hat = self.v / (1 - beta2 ** self.t)
        self.W_proj -= lr * m_hat / (np.sqrt(v_hat) + eps)


def feature_distillation_step(student, projector, teacher, x, y,
                               temperature=4.0, alpha=0.5, beta=0.3, lr=1e-3):
    """带特征蒸馏的训练步。

    总损失 = α * soft_loss + β * feature_loss + (1-α-β) * hard_loss

    Args:
        student:    Student 模型
        projector:  特征投影层
        teacher:    Teacher 模型（冻结）
        x:          (batch, input_dim)
        y:          (batch,) 真实标签
        temperature: 蒸馏温度
        alpha:      soft loss 权重
        beta:       feature loss 权重
        lr:         学习率
    Returns:
        metrics: dict
    """
    batch_size = x.shape[0]

    # Teacher 前向（冻结）
    teacher_logits, teacher_features, _ = teacher.forward(x)
    teacher_probs_T = softmax(teacher_logits, T=temperature)

    # Student 前向
    student_logits, student_features, cache = student.forward(x)
    student_probs_T = softmax(student_logits, T=temperature)
    student_probs_1 = softmax(student_logits, T=1.0)

    # 1. Soft loss (KL散度)
    kl = np.sum(teacher_probs_T * (np.log(teacher_probs_T + 1e-12) -
                                    np.log(student_probs_T + 1e-12)), axis=-1)
    soft_loss = temperature ** 2 * np.mean(kl)

    # 2. Feature loss (MSE)
    projected_features = projector.forward(student_features)  # (batch, teacher_dim)
    feature_loss = np.mean((projected_features - teacher_features) ** 2)

    # 3. Hard loss (交叉熵)
    hard_loss = -np.mean(np.log(student_probs_1[np.arange(batch_size), y] + 1e-12))

    # 总损失
    total_loss = alpha * soft_loss + beta * feature_loss + (1 - alpha - beta) * hard_loss

    # ---- 反向传播 ----
    # 对 student_logits 的梯度
    grad_soft = alpha * temperature * (student_probs_T - teacher_probs_T) / batch_size
    one_hot = np.zeros_like(student_probs_1)
    one_hot[np.arange(batch_size), y] = 1
    grad_hard = (1 - alpha - beta) * (student_probs_1 - one_hot) / batch_size
    grad_logits = grad_soft + grad_hard

    # 对 student_features 的梯度（来自 feature loss）
    # feature_loss = mean((proj_features - teacher_features)^2)
    # d(feature_loss)/d(projected_features) = 2 * (projected_features - teacher_features) / batch_size
    grad_projected = beta * 2 * (projected_features - teacher_features) / batch_size
    grad_features, grad_W_proj = projector.backward(
        grad_projected, student_features, batch_size
    )

    # Student 反向传播（合并 logits 和 feature 的梯度）
    grads = student.backward(grad_logits, grad_features, cache)
    student.adam_step(grads, lr=lr)

    # 投影层更新
    projector.adam_step(grad_W_proj, lr=lr)

    # 准确率
    pred = np.argmax(student_logits, axis=-1)
    accuracy = np.mean(pred == y)

    return {
        "total_loss": total_loss,
        "soft_loss": soft_loss,
        "feature_loss": feature_loss,
        "hard_loss": hard_loss,
        "accuracy": accuracy,
    }
```

3. **边缘 case 覆盖**：人工难以构造的稀有场景，用 LLM 批量生成

## 第 490 题：实现 Self-Instruct 数据生成管道

### 知识讲解

**Self-Instruct** 方法的核心流程：

```
1. 种子指令池 (Seed Pool)
   ↓ 从种子中随机采样
2. 指令生成 (Instruction Generation)
   ↓ 用 LLM 生成新的 instruction
3. 响应生成 (Response Generation)
   ↓ 用 LLM 为 instruction 生成 response
4. 过滤 (Filtering)
   ↓ 去重、质量检查
5. 加入指令池 (Add to Pool)
   ↓ 循环 2-5
6. 最终数据集
```

**关键设计**：
- **种子指令**：人工编写的高质量指令，作为生成的起点
- **指令模板**：将种子指令组合成 prompt，引导 LLM 生成新指令
- **过滤器**：
  - 长度过滤：太短或太长的指令
  - 重复过滤：与已有指令相似度过高
  - 格式检查：确保是有效的 instruction
- **迭代扩展**：新生成的合格指令加入种子池，参与下一轮生成

```python
import numpy as np

# ======================== 模拟 LLM 生成器 ========================
class MockLLM:
    """模拟 LLM 的指令和响应生成器。

    实际场景中应调用 GPT-4 / Claude 等模型 API。
    这里用规则 + 随机组合模拟生成过程。
    """

    def __init__(self, seed=42):
        self.rng = np.random.RandomState(seed)

        # 指令模板库
        self.verbs = ["翻译", "总结", "分类", "解释", "比较", "分析",
                      "生成", "改写", "提取", "评估", "推荐", "排序"]
        self.objects = ["以下文本", "这段对话", "这篇文章", "这个问题",
                        "这些数据", "这个概念", "这段代码", "这个场景",
                        "这组关键词", "这个论点"]
        self.conditions = ["用简洁的语言", "分点说明", "给出具体例子",
                           "从多个角度", "考虑边缘情况", "用类比解释",
                           "限定在100字内", "面向初学者", "包含步骤",
                           "引用权威来源"]

        # 响应模板
        self.response_templates = [
            "根据要求，{verb}{object}的结果如下：\n1. 首先分析核心内容\n2. {condition}进行处理\n3. 最终得出结论",
            "这是一个{verb}任务。\n输入：{object}\n处理方式：{condition}\n输出：处理完成",
            "关于{object}的{verb}：\n- 关键点1：理解上下文\n- 关键点2：{condition}\n- 结论：任务完成",
        ]

    def generate_instruction(self, seed_instructions):
        """基于种子指令生成新指令。

        Args:
            seed_instructions: list[str] 种子指令列表
        Returns:
            new_instruction: str 新生成的指令
        """
        # 从种子中采样并组合
        verb = self.rng.choice(self.verbs)
        obj = self.rng.choice(self.objects)
        cond = self.rng.choice(self.conditions)

        # 随机选择生成模式
        mode = self.rng.randint(0, 3)
        if mode == 0:
            # 直接组合
            instruction = f"请{verb}{obj}，{cond}。"
        elif mode == 1:
            # 基于种子指令改写
            seed = self.rng.choice(seed_instructions)
            instruction = f"参考"{seed}"，请{verb}{obj}，{cond}。"
        else:
            # 组合多个操作
            verb2 = self.rng.choice(self.verbs)
            instruction = f"请先{verb}{obj}，然后{verb2}结果，{cond}。"

        return instruction

    def generate_response(self, instruction):
        """为指令生成响应。

        Args:
            instruction: str 指令文本
        Returns:
            response: str 响应文本
        """
        verb = self.rng.choice(self.verbs)
        obj = self.rng.choice(self.objects)
        cond = self.rng.choice(self.conditions)

        template = self.rng.choice(self.response_templates)
        response = template.format(verb=verb, object=obj, condition=cond)
        return response


# ======================== Self-Instruct 管道 ========================
class SelfInstructPipeline:
    """Self-Instruct 数据生成管道。

    流程: 种子 → 生成指令 → 生成响应 → 过滤 → 加入池 → 循环
    """

    def __init__(self, seed_instructions, llm=None, seed=42):
        """
        Args:
            seed_instructions: list[str] 初始种子指令
            llm: MockLLM 实例
            seed: 随机种子
        """
        self.llm = llm if llm else MockLLM(seed=seed)
        self.rng = np.random.RandomState(seed)
        self.instruction_pool = list(seed_instructions)
        self.generated_data = []  # 存储生成的 (instruction, response) 对
        self.rejected = {"too_short": 0, "too_long": 0, "duplicate": 0, "format": 0}

    def _is_valid_instruction(self, instruction, min_len=8, max_len=200):
        """检查指令是否有效。

        Args:
            instruction: 待检查的指令
            min_len: 最小长度
            max_len: 最大长度
        Returns:
            valid: bool 是否有效
            reason: str 如果无效，原因是什么
        """
        # 长度检查
        if len(instruction) < min_len:
            return False, "too_short"
        if len(instruction) > max_len:
            return False, "too_long"

        # 格式检查：必须包含动词（中文）
        has_verb = any(v in instruction for v in self.llm.verbs)
        if not has_verb:
            return False, "format"

        # 重复检查：与已生成数据的相似度
        for existing_inst, _ in self.generated_data:
            sim = self._similarity(instruction, existing_inst)
            if sim > 0.7:  # 相似度阈值
                return False, "duplicate"

        return True, "ok"

    def _similarity(self, text1, text2):
        """计算两段文本的简化相似度（基于字符 Jaccard）。

        Args:
            text1, text2: 两段文本
        Returns:
            similarity: 0~1
        """
        set1 = set(text1)
        set2 = set(text2)
        if len(set1) == 0 or len(set2) == 0:
            return 0.0
        intersection = len(set1 & set2)
        union = len(set1 | set2)
        return intersection / union

    def run(self, target_count=50, num_seeds_per_round=3, max_rounds=100):
        """运行 Self-Instruct 生成管道。

        Args:
            target_count:   目标生成数量
            num_seeds_per_round: 每轮采样几个种子
            max_rounds:     最大轮数（防止无限循环）
        Returns:
            generated_data: list of (instruction, response)
        """
        round_num = 0
        while len(self.generated_data) < target_count and round_num < max_rounds:
            round_num += 1

            # 1. 从指令池中随机采样种子
            pool_size = min(num_seeds_per_round, len(self.instruction_pool))
            sampled_seeds = self.rng.choice(
                self.instruction_pool, size=pool_size, replace=False
            )

            # 2. 生成新指令
            for seed_inst in sampled_seeds:
                if len(self.generated_data) >= target_count:
                    break

                new_instruction = self.llm.generate_instruction(self.instruction_pool)

                # 3. 过滤
                valid, reason = self._is_valid_instruction(new_instruction)
                if not valid:
                    self.rejected[reason] = self.rejected.get(reason, 0) + 1
                    continue

                # 4. 生成响应
                response = self.llm.generate_response(new_instruction)

                # 5. 加入数据集和指令池
                self.generated_data.append((new_instruction, response))
                self.instruction_pool.append(new_instruction)

        return self.generated_data

    def get_stats(self):
        """获取生成统计信息。"""
        total = len(self.generated_data)
        rejected_total = sum(self.rejected.values())
        return {
            "generated": total,
            "rejected": rejected_total,
            "rejection_rate": rejected_total / max(total + rejected_total, 1),
            "pool_size": len(self.instruction_pool),
            "rejection_breakdown": dict(self.rejected),
        }
```

## 第 491 题：实现数据去重（MinHash + Jaccard 相似度）

### 知识讲解

在合成数据生成中，**去重** 是质量控制的关键步骤。直接计算所有文本对之间的 Jaccard 相似度时间复杂度为 O(n²)，对于大数据集不可行。

**MinHash** 是一种近似计算 Jaccard 相似度的技术，通过哈希函数将集合压缩为固定长度的签名（signature），然后只比较签名。

**Jaccard 相似度**：

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

**MinHash 原理**：
1. 对集合中的每个元素应用 k 个哈希函数
2. 对每个哈希函数，取集合中所有元素哈希值的最小值
3. k 个最小值组成签名（长度为 k 的向量）
4. 两个集合的 MinHash 签名在相同位置相等的比例 ≈ Jaccard 相似度

**数学保证**：$\Pr[\min(h(A)) = \min(h(B))] = J(A, B)$

**流程**：
```
文本 → 分词 → token 集合 → MinHash 签名 → 签名比较 → 相似度阈值过滤
```

### 完整代码

```python
import numpy as np
from collections import defaultdict


def tokenize(text, ngram=2):
    """将文本分词为 n-gram 集合。

    Args:
        text:  输入文本
        ngram: n-gram 的 n 值
    Returns:
        tokens: set of n-gram strings
    """
    # 按字符切分（适用于中文）
    chars = list(text.strip())
    if len(chars) < ngram:
        return set(chars) if chars else set()
    # 生成 n-gram
    ngrams = set()
    for i in range(len(chars) - ngram + 1):
        ngrams.add("".join(chars[i:i + ngram]))
    return ngrams


def jaccard_similarity(set_a, set_b):
    """精确计算两个集合的 Jaccard 相似度。

    J = |A ∩ B| / |A ∪ B|
    """
    if len(set_a) == 0 and len(set_b) == 0:
        return 1.0
    intersection = len(set_a & set_b)
    union = len(set_a | set_b)
    return intersection / union if union > 0 else 0.0


class MinHash:
    """MinHash 签名生成器。

    通过 k 个哈希函数将集合压缩为固定长度的签名，
    用于近似计算 Jaccard 相似度。
    """

    def __init__(self, num_hashes=128, seed=42):
        """初始化 MinHash。

        Args:
            num_hashes: 哈希函数数量（签名长度）
            seed: 随机种子
        """
        self.num_hashes = num_hashes
        rng = np.random.RandomState(seed)

        # 生成 k 组哈希函数参数: h(x) = (a * x + b) mod large_prime
        self.large_prime = (1 << 61) - 1  # 梅森素数
        self.a = rng.randint(1, self.large_prime, size=num_hashes)
        self.b = rng.randint(0, self.large_prime, size=num_hashes)

    def _hash_element(self, element, hash_idx):
        """对单个元素应用第 hash_idx 个哈希函数。

        h(x) = (a * x + b) mod p
        """
        # 将字符串转为整数
        x = hash(element) & 0x7FFFFFFFFFFFFFFF  # 确保非负
        return (self.a[hash_idx] * x + self.b[hash_idx]) % self.large_prime

    def compute_signature(self, token_set):
        """计算一个 token 集合的 MinHash 签名。

        Args:
            token_set: set of tokens
        Returns:
            signature: (num_hashes,) numpy 数组，每个元素是对应哈希函数的最小哈希值
        """
        if len(token_set) == 0:
            return np.full(self.num_hashes, np.iinfo(np.uint64).max, dtype=np.uint64)

        signature = np.full(self.num_hashes, np.iinfo(np.uint64).max, dtype=np.uint64)

        for token in token_set:
            for i in range(self.num_hashes):
                h = self._hash_element(token, i)
                if h < signature[i]:
                    signature[i] = h

        return signature

    def estimate_similarity(self, sig_a, sig_b):
        """通过 MinHash 签名估算 Jaccard 相似度。

        估算值 = 签名相同位置的比例

        Args:
            sig_a: (num_hashes,) 签名 A
            sig_b: (num_hashes,) 签名 B
        Returns:
            estimated_similarity: 0~1
        """
        matches = np.sum(sig_a == sig_b)
        return matches / self.num_hashes


class LSHIndex:
    """Locality-Sensitive Hashing 索引，用于快速近似去重。

    将 MinHash 签名分为多个 band，每个 band 哈希到一个桶。
    只有落在同一个桶的候选对才需要比较签名。
    """

    def __init__(self, num_hashes=128, num_bands=32, seed=42):
        """
        Args:
            num_hashes: MinHash 签名长度
            num_bands:  band 数量（每个 band 有 num_hashes/num_bands 行）
        """
        assert num_hashes % num_bands == 0, "num_hashes 必须能被 num_bands 整除"
        self.num_hashes = num_hashes
        self.num_bands = num_bands
        self.rows_per_band = num_hashes // num_bands
        self.minhash = MinHash(num_hashes, seed)
        self.buckets = [defaultdict(list) for _ in range(num_bands)]  # 每个 band 的桶
        self.signatures = []  # 存储所有签名

    def _band_hash(self, signature, band_idx):
        """将一个 band 的签名值哈希为桶 key。"""
        start = band_idx * self.rows_per_band
        end = start + self.rows_per_band
        band = signature[start:end]
        return hash(tuple(band))

    def insert(self, doc_id, token_set):
        """插入一个文档。

        Args:
            doc_id:    文档 ID
            token_set: 文档的 token 集合
        """
        sig = self.minhash.compute_signature(token_set)
        self.signatures.append((doc_id, sig))

        # 将签名分成 band，每个 band 插入对应桶
        for band_idx in range(self.num_bands):
            bucket_key = self._band_hash(sig, band_idx)
            self.buckets[band_idx][bucket_key].append(doc_id)

    def query_candidates(self, token_set):
        """查询可能相似的候选文档。

        Returns:
            candidates: set of doc_id（与查询文档可能相似的文档）
        """
        sig = self.minhash.compute_signature(token_set)
        candidates = set()

        for band_idx in range(self.num_bands):
            bucket_key = self._band_hash(sig, band_idx)
            if bucket_key in self.buckets[band_idx]:
                candidates.update(self.buckets[band_idx][bucket_key])

        return candidates

    def find_duplicates(self, documents, threshold=0.5):
        """找出所有近似重复的文档对。

        Args:
            documents: list of (doc_id, text) 或 (doc_id, token_set)
            threshold:  Jaccard 相似度阈值
        Returns:
            duplicates: list of (doc_id_a, doc_id_b, similarity)
        """
        # 1. 插入所有文档
        doc_tokens = {}
        for doc_id, content in documents:
            if isinstance(content, str):
                tokens = tokenize(content)
            else:
                tokens = content
            doc_tokens[doc_id] = tokens
            self.insert(doc_id, tokens)

        # 2. 对每个文档查询候选，计算精确相似度
        duplicates = []
        seen_pairs = set()

        for doc_id, tokens in doc_tokens.items():
            candidates = self.query_candidates(tokens)

            for cand_id in candidates:
                if cand_id >= doc_id:  # 避免重复比较
                    continue
                pair = (cand_id, doc_id)
                if pair in seen_pairs:
                    continue
                seen_pairs.add(pair)

                # 计算精确 Jaccard 相似度
                sim = jaccard_similarity(tokens, doc_tokens[cand_id])
                if sim >= threshold:
                    duplicates.append((cand_id, doc_id, sim))

        return duplicates
```

## 第 492 题：实现数据质量评分（长度、多样性、格式合规性检查）

### 知识讲解

合成数据的质量直接影响下游模型训练效果。本题实现一个综合的数据质量评分系统，从多个维度评估每条数据：

**评分维度：**

1. **长度评分（Length Score）**：
   - instruction 和 response 都应有合理长度
   - 太短：信息量不足；太长：可能包含噪声
   - 使用钟形函数评分：中等长度得分最高

2. **多样性评分（Diversity Score）**：
   - 衡量该样本与数据集中其他样本的差异程度
   - 用平均 Jaccard 距离衡量：与其他样本越不同，多样性得分越高
   - 避免数据集过于同质化

3. **格式合规性（Format Compliance）**：
   - instruction 是否包含明确的动作词
   - response 是否有实际内容（非空、非重复）
   - instruction 和 response 的比例是否合理

4. **语言质量（Language Quality）**：
   - 标点符号使用
   - 是否包含乱码或特殊字符
   - 句子完整性

**综合评分** = w1 × 长度分 + w2 × 多样性分 + w3 × 格式分 + w4 × 语言质量分

### 完整代码

```python
import numpy as np
import re


# ======================== 质量评分器 ========================
class DataQualityScorer:
    """合成数据质量评分器。

    从多个维度评估数据质量，输出综合评分和分项评分。
    """

    def __init__(self, weights=None):
        """
        Args:
            weights: dict 各维度权重
        """
        self.weights = weights or {
            "length": 0.25,
            "diversity": 0.25,
            "format": 0.25,
            "language": 0.25,
        }

    # ---- 长度评分 ----
    def score_length(self, instruction, response):
        """长度评分：使用钟形函数，中等长度得分最高。

        理想长度区间：
        - instruction: 10~80 字符
        - response: 20~300 字符

        Returns:
            score: 0~1
        """
        def bell_curve(length, ideal_min, ideal_max):
            """钟形评分函数。"""
            if length < ideal_min:
                # 太短：线性惩罚
                return max(0, length / ideal_min)
            elif length > ideal_max:
                # 太长：指数衰减
                excess = length - ideal_max
                return max(0, 1.0 * np.exp(-excess / (ideal_max * 0.5)))
            else:
                return 1.0

        inst_score = bell_curve(len(instruction), 10, 80)
        resp_score = bell_curve(len(response), 20, 300)

        # 响应权重更高（响应质量更关键）
        return 0.4 * inst_score + 0.6 * resp_score

    # ---- 多样性评分 ----
    def score_diversity(self, instruction, response, all_instructions, all_responses):
        """多样性评分：与数据集中其他样本的差异程度。

        使用字符级 Jaccard 距离的平均值。

        Returns:
            score: 0~1，越高表示越独特
        """
        def char_set(text):
            return set(text)

        inst_set = char_set(instruction)
        resp_set = char_set(response)

        # 计算与所有其他样本的平均 Jaccard 距离
        inst_dists = []
        for other_inst in all_instructions:
            if other_inst == instruction:
                continue
            other_set = char_set(other_inst)
            if len(inst_set) == 0 or len(other_set) == 0:
                continue
            jaccard = len(inst_set & other_set) / len(inst_set | other_set)
            inst_dists.append(1 - jaccard)  # 距离 = 1 - 相似度

        resp_dists = []
        for other_resp in all_responses:
            if other_resp == response:
                continue
            other_set = char_set(other_resp)
            if len(resp_set) == 0 or len(other_set) == 0:
                continue
            jaccard = len(resp_set & other_set) / len(resp_set | other_set)
            resp_dists.append(1 - jaccard)

        avg_inst_dist = np.mean(inst_dists) if inst_dists else 0.5
        avg_resp_dist = np.mean(resp_dists) if resp_dists else 0.5

        return 0.4 * avg_inst_dist + 0.6 * avg_resp_dist

    # ---- 格式合规性 ----
    def score_format(self, instruction, response):
        """格式合规性评分。

        检查项：
        - instruction 是否包含动词
        - response 是否非空且有实际内容
        - instruction/response 长度比是否合理
        - response 是否只是简单重复 instruction

        Returns:
            score: 0~1
        """
        score = 0.0
        checks = 0

        # 检查1: instruction 包含动词
        action_verbs = ["翻译", "总结", "分类", "解释", "比较", "生成", "改写",
                        "提取", "评估", "推荐", "排序", "分析", "回答", "编写",
                        "描述", "列举", "计算", "转换", "创建", "设计"]
        has_verb = any(v in instruction for v in action_verbs)
        score += 1.0 if has_verb else 0.0
        checks += 1

        # 检查2: response 非空且有足够内容
        resp_valid = len(response.strip()) >= 10
        score += 1.0 if resp_valid else 0.0
        checks += 1

        # 检查3: instruction/response 长度比合理 (response 应比 instruction 更长或相当)
        if len(instruction) > 0:
            ratio = len(response) / len(instruction)
            ratio_ok = 0.3 < ratio < 20.0  # 响应不应太短也不应异常长
            score += 1.0 if ratio_ok else 0.5
            checks += 1

        # 检查4: response 不是 instruction 的简单重复
        if instruction.strip() in response.strip() or response.strip() in instruction.strip():
            score += 0.0  # 重复扣分
        else:
            score += 1.0
        checks += 1

        # 检查5: response 有结构化内容（分点、步骤等）
        has_structure = any(p in response for p in ["\n", "1.", "2.", "-", "•", "步骤", "首先"])
        score += 0.5 if has_structure else 1.0  # 没有结构也可以，但有结构加分
        checks += 1

        return score / checks

    # ---- 语言质量 ----
    def score_language(self, instruction, response):
        """语言质量评分。

        检查项：
        - 标点符号使用
        - 无乱码/异常字符
        - 句子完整性

        Returns:
            score: 0~1
        """
        score = 0.0
        checks = 0

        combined = instruction + " " + response

        # 检查1: 包含中文标点
        cn_puncts = ["。", "，", "！", "？", "；", "：", "、"]
        has_punct = any(p in combined for p in cn_puncts)
        score += 1.0 if has_punct else 0.3
        checks += 1

        # 检查2: 无异常字符（连续特殊符号）
        abnormal_pattern = re.compile(r'[^\w\s\u4e00-\u9fff，。！？；：、""''（）【】\-\.]{5,}')
        has_abnormal = bool(abnormal_pattern.search(combined))
        score += 0.0 if has_abnormal else 1.0
        checks += 1

        # 检查3: 中文字符占比合理
        cn_chars = sum(1 for c in combined if '\u4e00' <= c <= '\u9fff')
        total_chars = len(combined.strip())
        if total_chars > 0:
            cn_ratio = cn_chars / total_chars
            # 中文数据集，中文占比应 > 30%
            score += min(1.0, cn_ratio * 2)  # 50% 中文 → 满分
        else:
            score += 0.0
        checks += 1

        # 检查4: 无连续重复字符（如 "啊啊啊啊啊啊"）
        repeat_pattern = re.compile(r'(.)\1{5,}')
        has_repeat = bool(repeat_pattern.search(combined))
        score += 0.0 if has_repeat else 1.0
        checks += 1

        # 检查5: response 包含换行或句号（句子完整性信号）
        has_sentence_end = any(p in response for p in ["。", "！", "？", "\n"])
        score += 1.0 if has_sentence_end else 0.5
        checks += 1

        return score / checks

    # ---- 综合评分 ----
    def score(self, instruction, response, all_instructions=None, all_responses=None):
        """综合质量评分。

        Args:
            instruction: 指令文本
            response:    响应文本
            all_instructions: 数据集中所有指令（用于多样性计算）
            all_responses:    数据集中所有响应
        Returns:
            result: dict 包含综合分和各维度分
        """
        if all_instructions is None:
            all_instructions = [instruction]
        if all_responses is None:
            all_responses = [response]

        length_score = self.score_length(instruction, response)
        diversity_score = self.score_diversity(instruction, response,
                                                 all_instructions, all_responses)
        format_score = self.score_format(instruction, response)
        language_score = self.score_language(instruction, response)

        total = (self.weights["length"] * length_score +
                 self.weights["diversity"] * diversity_score +
                 self.weights["format"] * format_score +
                 self.weights["language"] * language_score)

        return {
            "total": total,
            "length": length_score,
            "diversity": diversity_score,
            "format": format_score,
            "language": language_score,
            "instruction": instruction,
            "response": response,
        }

    def score_dataset(self, dataset):
        """对整个数据集评分并生成报告。

        Args:
            dataset: list of (instruction, response)
        Returns:
            results: list of score dict
            summary: dict 数据集级统计
        """
        all_instructions = [inst for inst, _ in dataset]
        all_responses = [resp for _, resp in dataset]

        results = []
        for inst, resp in dataset:
            result = self.score(inst, resp, all_instructions, all_responses)
            results.append(result)

        # 数据集级统计
        summary = {
            "count": len(results),
            "avg_total": np.mean([r["total"] for r in results]),
            "avg_length": np.mean([r["length"] for r in results]),
            "avg_diversity": np.mean([r["diversity"] for r in results]),
            "avg_format": np.mean([r["format"] for r in results]),
            "avg_language": np.mean([r["language"] for r in results]),
            "min_total": min(r["total"] for r in results),
            "max_total": max(r["total"] for r in results),
            "low_quality_count": sum(1 for r in results if r["total"] < 0.4),
            "high_quality_count": sum(1 for r in results if r["total"] >= 0.7),
        }

        return results, summary
```

## 知识总览

**评测框架** 是 LLM 应用开发中最关键的基础设施之一。好的评测系统能帮助你：
1. 量化模型能力的变化（版本迭代、参数调整）
2. 定位模型的弱点（哪些场景/类型表现差）

**评测维度（以 RAG 系统为例）：**

- 批量运行测试用例
- 统计聚合（均值、方差、置信区间）
- 可视化报告（分数分布、失败分析、趋势图）

## 第 493 题：实现 RAGAS Faithfulness 指标

### 知识讲解

**Faithfulness（忠实度）** 衡量答案是否忠于检索到的上下文，即模型是否"编造了"上下文中不存在的信息。

**RAGAS 的计算方法：**

1. 从答案中提取声明（claims）：将答案分解为独立的陈述句
2. 对每个声明，检查它是否可以从上下文中推导出来
3. Faithfulness = 能从上下文推导出的声明数 / 总声明数

```
答案: "北京是中国的首都，人口约2200万。"
上下文: "北京是中华人民共和国的首都，常住人口约2150万人。"

声明1: "北京是中国的首都" → 上下文支持 ✓
声明2: "人口约2200万" → 上下文说2150万，不精确一致 ✗

Faithfulness = 1/2 = 0.5
```

**简化实现**：本题用基于关键词重叠的简化版来模拟 LLM 判断过程。

### 完整代码

```python
import numpy as np
import re


def extract_claims(text):
    """从文本中提取声明（句子级别）。

    简化实现：按标点符号分割成句子，过滤空句子。

    Args:
        text: 答案文本
    Returns:
        claims: list of str
    """
    # 按中文标点和换行分割
    sentences = re.split(r'[。！？；\n，]+', text)
    # 过滤和清理
    claims = [s.strip() for s in sentences if len(s.strip()) > 2]
    return claims


def check_claim_faithful(claim, context, similarity_threshold=0.3):
    """检查一个声明是否忠实于上下文。

    简化实现：基于字符级 n-gram 重叠率来判断。
    实际 RAGAS 会调用 LLM 进行判断。

    Args:
        claim: 待检查的声明
        context: 上下文文本
        similarity_threshold: 重叠率阈值
    Returns:
        is_faithful: bool
        score: float 重叠率 (0~1)
    """
    def char_bigrams(text):
        """生成字符 bigram 集合。"""
        return set(text[i:i+2] for i in range(len(text) - 1)) if len(text) >= 2 else {text}

    claim_ngrams = char_bigrams(claim)
    context_ngrams = char_bigrams(context)

    if len(claim_ngrams) == 0:
        return True, 1.0

    overlap = len(claim_ngrams & context_ngrams)
    score = overlap / len(claim_ngrams)

    return score >= similarity_threshold, score


def compute_faithfulness(answer, contexts):
    """计算 Faithfulness 指标。

    Args:
        answer: 模型生成的答案
        contexts: list of str 检索到的上下文列表
    Returns:
        faithfulness: 0~1
        details: dict 详细信息
    """
    # 合并所有上下文
    full_context = "\n".join(contexts)

    # 提取答案中的声明
    claims = extract_claims(answer)

    if len(claims) == 0:
        return 1.0, {"claims": [], "faithful_count": 0, "total_claims": 0}

    # 检查每个声明
    claim_results = []
    faithful_count = 0

    for claim in claims:
        is_faithful, overlap_score = check_claim_faithful(claim, full_context)
        claim_results.append({
            "claim": claim,
            "is_faithful": is_faithful,
            "overlap_score": overlap_score,
        })
        if is_faithful:
            faithful_count += 1

    faithfulness = faithful_count / len(claims)

    details = {
        "claims": claim_results,
        "faithful_count": faithful_count,
        "total_claims": len(claims),
        "faithfulness": faithfulness,
    }

    return faithfulness, details


def batch_faithfulness(test_cases):
    """批量计算 Faithfulness 指标。

    Args:
        test_cases: list of dict，每个包含 question、answer、contexts
    Returns:
        results: list of dict
        summary: dict 聚合统计
    """
    results = []
    for tc in test_cases:
        faith, details = compute_faithfulness(tc["answer"], tc["contexts"])
        results.append({
            "question": tc["question"],
            "faithfulness": faith,
            "details": details,
        })

    scores = [r["faithfulness"] for r in results]
    summary = {
        "mean": np.mean(scores),
        "std": np.std(scores),
        "min": np.min(scores),
        "max": np.max(scores),
        "median": np.median(scores),
        "count": len(scores),
        "perfect_count": sum(1 for s in scores if s == 1.0),
        "zero_count": sum(1 for s in scores if s == 0.0),
    }

    return results, summary
```

## 第 494 题：实现 RAGAS Answer Relevancy 指标

### 知识讲解

**Answer Relevancy（答案相关性）** 衡量答案是否真正回答了用户提出的问题。即使答案本身是正确的，如果它没有回答问题，相关性也很低。

**RAGAS 的反向方法：**

1. 从答案反向生成问题（answer → questions）
2. 计算反向生成的问题与原始问题之间的相似度
3. Answer Relevancy = 反向问题与原始问题的平均相似度

**直觉**：如果答案确实回答了原始问题，那么从答案生成的问题应该与原始问题相似。如果答案跑题了，生成的问题自然与原问题无关。

**本题简化实现**：
- 不用 LLM 反向生成问题，而是直接从答案中提取关键词
- 计算答案关键词与原始问题的关键词的重叠度
- 同时检查答案是否包含问题中要求的特定信息类型

### 完整代码

```python
import numpy as np
import re


def extract_keywords(text):
    """提取文本关键词（简化版）。

    使用 n-gram + 停用词过滤。

    Args:
        text: 输入文本
    Returns:
        keywords: set of str
    """
    # 停用词
    stop_words = set(["的", "了", "是", "在", "和", "与", "有", "这", "那", "个",
                      "一个", "什么", "怎么", "如何", "为什么", "多少", "哪", "哪些",
                      "请", "给", "帮", "我", "你", "他", "它", "们", "吧", "呢",
                      "吗", "啊", "哦", "嗯", "也", "都", "还", "就", "会", "能",
                      "可以", "要", "把", "被", "对", "从", "到", "中", "上", "下",
                      "the", "a", "an", "is", "are", "was", "were", "in", "on",
                      "at", "to", "of", "and", "or", "for", "with", "this", "that"])

    # 按非字母数字字符分割
    tokens = re.split(r'[^\w\u4e00-\u9fff]+', text.lower())

    # 过滤
    keywords = set()
    for token in tokens:
        if len(token) >= 2 and token not in stop_words:
            keywords.add(token)

    # 添加 bigram
    chars = list(text)
    for i in range(len(chars) - 1):
        bigram = chars[i] + chars[i + 1]
        if len(bigram) >= 2 and bigram not in stop_words:
            keywords.add(bigram)

    return keywords


def compute_keyword_overlap(keywords_a, keywords_b):
    """计算两组关键词的重叠率。

    使用 F1 风格的调和平均。

    Args:
        keywords_a: set of keywords
        keywords_b: set of keywords
    Returns:
        precision: A 中有多少在 B 中
        recall: B 中有多少在 A 中
        f1: 调和平均
    """
    if len(keywords_a) == 0 or len(keywords_b) == 0:
        return 0.0, 0.0, 0.0

    intersection = keywords_a & keywords_b
    precision = len(intersection) / len(keywords_a)
    recall = len(intersection) / len(keywords_b)

    if precision + recall == 0:
        f1 = 0.0
    else:
        f1 = 2 * precision * recall / (precision + recall)

    return precision, recall, f1


def compute_answer_relevancy(question, answer, contexts=None):
    """计算答案相关性指标。

    方法：
    1. 关键词重叠法：答案是否包含问题的关键词
    2. 信息覆盖法：答案是否回答了问题的"是什么/为什么/怎么"
    3. 上下文相关法：答案是否与检索上下文相关（可选）

    Args:
        question: 原始问题
        answer:   模型答案
        contexts: 检索到的上下文（可选）
    Returns:
        relevancy: 0~1
        details: dict 详细评分
    """
    # ---- 方法1: 关键词重叠 ----
    q_keywords = extract_keywords(question)
    a_keywords = extract_keywords(answer)
    precision, recall, f1 = compute_keyword_overlap(q_keywords, a_keywords)

    # ---- 方法2: 问题类型覆盖检查 ----
    # 检查答案是否回应了问题类型
    question_type_score = 0.0
    question_types = {
        "what": (["是什么", "什么是", "什么叫", "指的是"], "定义"),
        "how": (["如何", "怎么", "怎样", "步骤"], "方法"),
        "why": (["为什么", "原因", "因为", "所以"], "原因"),
        "compare": (["比较", "区别", "不同", "对比", "优缺"], "对比"),
    }

    # 检测问题类型
    q_type = "unknown"
    for qtype, (patterns, _) in question_types.items():
        if any(p in question for p in patterns):
            q_type = qtype
            break

    if q_type != "unknown":
        # 检查答案中是否包含对应类型的信息
        patterns, _ = question_types[q_type]
        has_type_signal = any(p in answer for p in patterns)
        question_type_score = 1.0 if has_type_signal else 0.3

    # ---- 方法3: 上下文相关性（可选）----
    context_score = 0.5  # 默认值
    if contexts:
        full_context = "\n".join(contexts)
        ctx_keywords = extract_keywords(full_context)
        _, _, context_f1 = compute_keyword_overlap(a_keywords, ctx_keywords)
        context_score = min(1.0, context_f1 * 1.5)  # 适当放大

    # ---- 综合评分 ----
    relevancy = 0.4 * f1 + 0.3 * question_type_score + 0.3 * context_score

    details = {
        "keyword_f1": f1,
        "keyword_precision": precision,
        "keyword_recall": recall,
        "question_type": q_type,
        "question_type_score": question_type_score,
        "context_score": context_score,
        "question_keywords": list(q_keywords)[:10],
        "answer_keywords": list(a_keywords)[:10],
    }

    return relevancy, details


def batch_answer_relevancy(test_cases):
    """批量计算 Answer Relevancy。

    Args:
        test_cases: list of dict {question, answer, contexts}
    Returns:
        results: list of dict
        summary: dict 聚合统计
    """
    results = []
    for tc in test_cases:
        relevancy, details = compute_answer_relevancy(
            tc["question"], tc["answer"], tc.get("contexts")
        )
        results.append({
            "question": tc["question"],
            "relevancy": relevancy,
            "details": details,
        })

    scores = [r["relevancy"] for r in results]
    summary = {
        "mean": np.mean(scores),
        "std": np.std(scores),
        "min": np.min(scores),
        "max": np.max(scores),
        "median": np.median(scores),
        "count": len(scores),
    }

    return results, summary
```

## 第 495 题：实现 LLM-as-a-Judge 评测器（多维度打分 + 加权汇总）

### 知识讲解

**LLM-as-a-Judge** 是一种用强模型评测弱模型输出的方法。核心流程：

```
1. 设计评分标准 (Rubric)
   ↓
2. 构造评测 Prompt（包含问题、答案、标准）
   ↓
3. LLM 输出多维度评分
   ↓
4. 加权汇总为综合分
```

**评分维度设计（示例）**：

| 维度 | 权重 | 说明 | 评分范围 |
|------|------|------|---------|
| 准确性 (Accuracy) | 0.3 | 答案中信息的正确程度 | 1-5 |
| 相关性 (Relevance) | 0.25 | 是否回答了问题 | 1-5 |
| 完整性 (Completeness) | 0.2 | 是否覆盖关键信息 | 1-5 |
| 清晰度 (Clarity) | 0.15 | 表达是否清楚 | 1-5 |
| 安全性 (Safety) | 0.1 | 是否包含有害内容 | 1-5 |

**加权综合分** = Σ (维度分 × 权重)

**评测可靠性**：
- **自一致性**：同一答案多次评测是否稳定
- **位置偏差**：多答案比较时，是否倾向选第一个
- **冗长偏差**：是否倾向给更长的答案更高分
- 解决方案：多次评测取平均、打乱顺序、长度归一化

```python
import numpy as np
import re


# ======================== 评分标准 ========================
class Rubric:
    """评分标准定义器。

    定义评测的维度、权重和每个分值的描述。
    """

    def __init__(self):
        self.dimensions = []

    def add_dimension(self, name, weight, description, level_descriptions=None):
        """添加一个评分维度。

        Args:
            name: 维度名称
            weight: 权重 (0~1)
            description: 维度描述
            level_descriptions: dict {score: description} 每个分值的描述
        """
        self.dimensions.append({
            "name": name,
            "weight": weight,
            "description": description,
            "level_descriptions": level_descriptions or {},
        })

    def validate(self):
        """验证评分标准的有效性。"""
        total_weight = sum(d["weight"] for d in self.dimensions)
        assert abs(total_weight - 1.0) < 1e-6, f"权重之和应为1.0，实际为{total_weight}"
        return True

    def to_prompt(self):
        """生成评分 prompt 模板。"""
        lines = ["请根据以下标准评测给定答案：\n"]
        for d in self.dimensions:
            lines.append(f"### {d['name']} (权重: {d['weight']:.0%})")
            lines.append(f"说明: {d['description']}")
            if d["level_descriptions"]:
                lines.append("评分标准:")
                for score, desc in sorted(d["level_descriptions"].items(),
                                          key=lambda x: int(x[0])):
                    lines.append(f"  {score}分: {desc}")
            lines.append("")
        return "\n".join(lines)


# ======================== 模拟评测 LLM ========================
class MockJudgeLLM:
    """模拟 LLM 评测器。

    基于关键词匹配和统计特征给出评分，
    模拟真实 LLM-as-a-Judge 的行为。
    """

    def __init__(self, seed=42):
        self.rng = np.random.RandomState(seed)

    def judge(self, question, answer, reference_answer=None, dimension=None):
        """对单个维度打分。

        Args:
            question: 问题
            answer: 待评测答案
            reference_answer: 参考答案（如果有）
            dimension: 维度名称
        Returns:
            score: 1~5 的整数
            reasoning: str 评分理由
        """
        base_score = 3.0  # 基础分

        if dimension == "准确性":
            if reference_answer:
                # 与参考答案的关键词重叠率
                ref_words = set(reference_answer)
                ans_words = set(answer)
                overlap = len(ref_words & ans_words) / max(len(ref_words), 1)
                base_score = 1 + overlap * 4
            else:
                # 无参考答案时，检查答案长度和信息密度
                base_score = min(4.0, 2.0 + len(answer) / 100)

        elif dimension == "相关性":
            q_words = set(question)
            a_words = set(answer)
            overlap = len(q_words & a_words) / max(len(q_words), 1)
            base_score = 1 + overlap * 4

        elif dimension == "完整性":
            # 答案长度与参考答案的比例
            if reference_answer:
                len_ratio = len(answer) / max(len(reference_answer), 1)
                base_score = min(5.0, 1 + len_ratio * 3)
            else:
                base_score = min(5.0, 1 + len(answer) / 50)

        elif dimension == "清晰度":
            # 检查结构化元素
            has_structure = sum(1 for p in ["\n", "1.", "2.", "-", "•"] if p in answer)
            base_score = min(5.0, 2 + has_structure * 0.5)

        elif dimension == "安全性":
            # 检查是否有害词
            harmful_patterns = ["暴力", "歧视", "色情", "违法"]
            has_harmful = any(p in answer for p in harmful_patterns)
            base_score = 1.0 if has_harmful else 5.0

        # 添加随机噪声（模拟 LLM 评分的不确定性）
        noise = self.rng.randn() * 0.3
        final_score = np.clip(np.round(base_score + noise), 1, 5)

        # 生成理由
        reasoning = self._generate_reasoning(dimension, int(final_score), answer)

        return int(final_score), reasoning

    def _generate_reasoning(self, dimension, score, answer):
        """生成评分理由。"""
        reasons = {
            "准确性": {
                5: "答案中的信息与参考答案高度一致",
                4: "答案基本准确，个别细节可能有偏差",
                3: "答案部分准确，存在明显错误信息",
                2: "答案存在较多不准确之处",
                1: "答案信息与事实严重不符",
            },
            "相关性": {
                5: "答案完全针对问题作答",
                4: "答案基本相关，少量跑题内容",
                3: "答案部分相关，有明显的答非所问",
                2: "答案与问题关系不大",
                1: "答案完全偏离问题",
            },
            "完整性": {
                5: "答案全面覆盖了所有关键信息",
                4: "答案覆盖了大部分关键信息",
                3: "答案覆盖了部分关键信息",
                2: "答案信息严重不足",
                1: "答案几乎没有提供有用信息",
            },
            "清晰度": {
                5: "答案结构清晰，表达流畅",
                4: "答案基本清晰，偶有混乱",
                3: "答案组织一般，部分难以理解",
                2: "答案表达混乱",
                1: "答案完全无法理解",
            },
            "安全性": {
                5: "答案安全，无任何有害内容",
                4: "答案安全，个别表述可更谨慎",
                3: "答案存在轻微风险",
                2: "答案存在明显风险",
                1: "答案包含有害内容",
            },
        }
        dim_reasons = reasons.get(dimension, {})
        return dim_reasons.get(score, f"评分: {score}")


# ======================== LLM-as-a-Judge 评测器 ========================
class LLMJudge:
    """LLM-as-a-Judge 评测器。

    使用多个维度评测答案，加权汇总为综合分。
    """

    def __init__(self, rubric, judge_llm=None, num_judgments=3):
        """
        Args:
            rubric: Rubric 实例
            judge_llm: 评测用 LLM
            num_judgments: 每个维度重复评测次数（取中位数）
        """
        self.rubric = rubric
        self.judge_llm = judge_llm or MockJudgeLLM()
        self.num_judgments = num_judgments

    def evaluate_single(self, question, answer, reference_answer=None):
        """评测单个答案。

        Args:
            question: 问题
            answer: 待评测答案
            reference_answer: 参考答案（可选）
        Returns:
            result: dict 包含各维度评分和综合分
        """
        dimension_scores = {}
        dimension_reasons = {}

        for dim in self.rubric.dimensions:
            name = dim["name"]
            weight = dim["weight"]

            # 多次评测取中位数
            scores = []
            for _ in range(self.num_judgments):
                score, reasoning = self.judge_llm.judge(
                    question, answer, reference_answer, name
                )
                scores.append(score)

            # 取中位数作为最终评分
            final_score = int(np.median(scores))
            dimension_scores[name] = final_score
            dimension_reasons[name] = reasoning

        # 加权综合分 (1~5)
        weighted_score = sum(
            dim["weight"] * dimension_scores[dim["name"]]
            for dim in self.rubric.dimensions
        )

        # 归一化到 0~1
        normalized_score = weighted_score / 5.0

        return {
            "question": question,
            "answer": answer,
            "dimension_scores": dimension_scores,
            "dimension_reasons": dimension_reasons,
            "weighted_score": weighted_score,
            "normalized_score": normalized_score,
        }

    def evaluate_batch(self, test_cases):
        """批量评测。

        Args:
            test_cases: list of dict {question, answer, reference_answer}
        Returns:
            results: list of evaluation result
            summary: dict 聚合统计
        """
        results = []
        for tc in test_cases:
            result = self.evaluate_single(
                tc["question"], tc["answer"], tc.get("reference_answer")
            )
            results.append(result)

        # 聚合统计
        all_normalized = [r["normalized_score"] for r in results]
        dim_names = [d["name"] for d in self.rubric.dimensions]

        summary = {
            "total_cases": len(results),
            "mean_score": np.mean(all_normalized),
            "std_score": np.std(all_normalized),
            "dimension_means": {},
            "dimension_stds": {},
        }

        for dim_name in dim_names:
            dim_scores = [r["dimension_scores"][dim_name] / 5.0 for r in results]
            summary["dimension_means"][dim_name] = np.mean(dim_scores)
            summary["dimension_stds"][dim_name] = np.std(dim_scores)

        return results, summary
```

## 第 496 题：实现批量评测管道（多测试用例 → 并行运行 → 生成报告）

### 知识讲解

**批量评测管道** 是将评测框架投入实际使用的关键。它负责：

```
1. 加载测试集（test suite）
   ↓
2. 运行待评测系统（如 RAG pipeline、LLM API）
   ↓
3. 收集输出（answers）
   ↓
4. 计算多维指标（Faithfulness, Relevancy, LLM-as-Judge）
   ↓
5. 聚合统计（均值、方差、置信区间）
   ↓
6. 生成报告（文本报告 + 可视化）
   ↓
7. 回归检测（与基线版本对比）
```

**关键设计**：
- **测试用例结构**：{question, expected_answer, contexts, metadata}
- **指标组合**：可以同时计算多个指标（Faithfulness + Relevancy + Judge Score）
- **并行运行**：多线程/多进程加速
- **报告格式**：结构化输出，支持对比分析
- **回归检测**：新版本 vs 基线版本的统计显著性检验

import numpy as np
import time
import json


# ======================== 测试套件 ========================
class TestSuite:
    """测试套件：管理评测用例。"""

    def __init__(self, name="default"):
        self.name = name
        self.cases = []

    def add_case(self, question, expected_answer=None, contexts=None,
                 metadata=None, category=None):
        """添加测试用例。"""
        self.cases.append({
            "id": len(self.cases),
            "question": question,
            "expected_answer": expected_answer,
            "contexts": contexts or [],
            "metadata": metadata or {},
            "category": category or "general",
        })

    def load_from_jsonl(self, filepath):
        """从 JSONL 文件加载测试用例。"""
        with open(filepath, "r", encoding="utf-8") as f:
            for line in f:
                data = json.loads(line.strip())
                self.add_case(
                    question=data["question"],
                    expected_answer=data.get("expected_answer"),
                    contexts=data.get("contexts", []),
                    metadata=data.get("metadata", {}),
                    category=data.get("category", "general"),
                )

    def get_by_category(self, category):
        """获取某类别的所有用例。"""
        return [c for c in self.cases if c["category"] == category]

    @property
    def categories(self):
        """所有类别。"""
        return sorted(set(c["category"] for c in self.cases))

    def __len__(self):
        return len(self.cases)


# ======================== 评测指标集合 ========================
def compute_all_metrics(question, answer, expected_answer=None, contexts=None):
    """计算所有评测指标。

    Args:
        question: 问题
        answer: 模型答案
        expected_answer: 参考答案
        contexts: 检索到的上下文
    Returns:
        metrics: dict 各指标值
    """
    metrics = {}

    # 1. Faithfulness (答案是否忠于上下文)
    if contexts:
        from collections import Counter
        full_context = "\n".join(contexts)
        ans_chars = set(answer)
        ctx_chars = set(full_context)
        if len(ans_chars) > 0:
            faithfulness = len(ans_chars & ctx_chars) / len(ans_chars)
        else:
            faithfulness = 0.0
        metrics["faithfulness"] = min(1.0, faithfulness * 1.2)

    # 2. Answer Relevancy (答案与问题的相关性)
    q_chars = set(question)
    a_chars = set(answer)
    if len(q_chars) > 0 and len(a_chars) > 0:
        overlap = len(q_chars & a_chars) / len(q_chars)
        metrics["relevancy"] = min(1.0, overlap * 1.5)
    else:
        metrics["relevancy"] = 0.0

    # 3. LLM-as-Judge Score (简化版多维度评分)
    judge_scores = {}

    # 准确性
    if expected_answer:
        ref_chars = set(expected_answer)
        ans_chars = set(answer)
        overlap = len(ref_chars & ans_chars) / max(len(ref_chars), 1)
        judge_scores["accuracy"] = min(1.0, overlap * 1.2)
    else:
        judge_scores["accuracy"] = min(1.0, len(answer) / 100)

    # 完整性
    if expected_answer:
        len_ratio = len(answer) / max(len(expected_answer), 1)
        judge_scores["completeness"] = min(1.0, len_ratio * 0.8)
    else:
        judge_scores["completeness"] = min(1.0, len(answer) / 80)

    # 清晰度
    structure_count = sum(1 for p in ["\n", "1.", "-", "•", "："] if p in answer)
    judge_scores["clarity"] = min(1.0, 0.3 + structure_count * 0.15)

    # Judge 综合分
    weights = {"accuracy": 0.4, "completeness": 0.35, "clarity": 0.25}
    judge_total = sum(w * judge_scores[k] for k, w in weights.items())
    metrics["judge_score"] = judge_total
    metrics["judge_detail"] = judge_scores

    # 4. 综合分
    metric_weights = {
        "faithfulness": 0.25 if contexts else 0.0,
        "relevancy": 0.25,
        "judge_score": 0.50 if not contexts else 0.50,
    }
    if contexts:
        metrics["overall"] = (0.25 * metrics.get("faithfulness", 0) +
                              0.25 * metrics["relevancy"] +
                              0.50 * metrics["judge_score"])
    else:
        metrics["overall"] = (0.0 * metrics.get("faithfulness", 0) +
                              0.25 * metrics["relevancy"] +
                              0.50 * metrics["judge_score"])

    return metrics

class MockEvalSystem:
    """模拟待评测的 AI 系统。"""

    def __init__(self, name="v1", quality=0.7, seed=42):
        self.name = name
        self.quality = quality
        self.rng = np.random.RandomState(seed)

    def predict(self, question, contexts=None):
        """生成答案。"""
        # 根据 quality 参数控制答案质量
        if contexts:
            context = contexts[0]
            answer_len = int(len(context) * self.quality * self.rng.uniform(0.5, 1.5))
            answer = context[:max(answer_len, 10)]
        else:
            answer_len = int(50 * self.quality * self.rng.uniform(0.5, 1.5))
            answer = f"关于{question[:10]}的回答。" + "这是生成的内容。" * max(answer_len // 20, 1)

        # 低质量时添加噪声
        if self.quality < 0.5:
            answer = answer[:len(answer) // 2]

        return answer


# ======================== 评测管道 ========================
class EvaluationPipeline:
    """批量评测管道。

    流程: 加载测试集 → 运行系统 → 计算指标 → 聚合统计 → 生成报告
    """

    def __init__(self, test_suite, system=None):
        self.test_suite = test_suite
        self.system = system
        self.results = []
        self.report = None

    def run(self, verbose=True):
        """运行评测。"""
        if verbose:
            print(f"开始评测: {self.system.name}")
            print(f"测试集: {self.test_suite.name} ({len(self.test_suite)} 条)")
            print("-" * 50)

        self.results = []
        start_time = time.time()

        for i, case in enumerate(self.test_suite.cases):
            # 运行系统
            answer = self.system.predict(case["question"], case.get("contexts"))

            # 计算指标
            metrics = compute_all_metrics(
                question=case["question"],
                answer=answer,
                expected_answer=case.get("expected_answer"),
                contexts=case.get("contexts"),
            )

            result = {
                "id": case["id"],
                "question": case["question"],
                "category": case["category"],
                "answer": answer,
                "expected_answer": case.get("expected_answer"),
                "metrics": metrics,
            }
            self.results.append(result)

            if verbose and (i % 3 == 0 or i == len(self.test_suite) - 1):
                print(f"  [{i+1}/{len(self.test_suite)}] "
                      f"overall={metrics['overall']:.3f} | {case['question'][:30]}...")

        elapsed = time.time() - start_time
        if verbose:
            print(f"\n评测完成: {len(self.results)} 条, 耗时 {elapsed:.2f}s")

        return self.results

    def compute_summary(self):
        """计算聚合统计。"""
        if not self.results:
            return {}

        # 全局统计
        all_metrics = {}
        metric_names = ["faithfulness", "relevancy", "judge_score", "overall"]
        for name in metric_names:
            values = [r["metrics"][name] for r in self.results if name in r["metrics"]]
            if values:
                all_metrics[name] = {
                    "mean": np.mean(values),
                    "std": np.std(values),
                    "min": np.min(values),
                    "max": np.max(values),
                    "median": np.median(values),
                }

        # 分类别统计
        category_stats = {}
        categories = set(r["category"] for r in self.results)
        for cat in sorted(categories):
            cat_results = [r for r in self.results if r["category"] == cat]
            cat_overalls = [r["metrics"]["overall"] for r in cat_results]
            category_stats[cat] = {
                "count": len(cat_results),
                "mean": np.mean(cat_overalls),
                "std": np.std(cat_overalls),
            }

        # 失败案例分析
        threshold = 0.3
        failures = [r for r in self.results if r["metrics"]["overall"] < threshold]
        failure_analysis = {
            "count": len(failures),
            "rate": len(failures) / len(self.results),
            "by_category": {},
        }
        for cat in categories:
            cat_failures = [r for r in failures if r["category"] == cat]
            failure_analysis["by_category"][cat] = len(cat_failures)

        summary = {
            "system": self.system.name if self.system else "unknown",
            "total_cases": len(self.results),
            "overall_metrics": all_metrics,
            "category_stats": category_stats,
            "failure_analysis": failure_analysis,
        }

        return summary

    def compare_with_baseline(self, baseline_results, alpha=0.05):
        """与基线版本对比。

        Args:
            baseline_results: 基线版本的 results
            alpha: 显著性水平
        Returns:
            comparison: dict 对比结果
        """
        new_scores = np.array([r["metrics"]["overall"] for r in self.results])
        base_scores = np.array([r["metrics"]["overall"] for r in baseline_results])

        # 均值差
        mean_diff = np.mean(new_scores) - np.mean(base_scores)

        # 配对 t 检验（简化版）
        n = min(len(new_scores), len(base_scores))
        if n > 1:
            paired_diff = new_scores[:n] - base_scores[:n]
            t_stat = np.mean(paired_diff) / (np.std(paired_diff) / np.sqrt(n) + 1e-12)
            # 近似 p-value（双侧）
            # 简化：用经验阈值
            significant = abs(t_stat) > 2.0  # 近似 p < 0.05
        else:
            t_stat = 0.0
            significant = False

        # 逐维度对比
        dim_comparison = {}
        for dim in ["faithfulness", "relevancy", "judge_score"]:
            new_vals = np.array([r["metrics"][dim] for r in self.results])
            base_vals = np.array([r["metrics"][dim] for r in baseline_results])
            dim_comparison[dim] = {
                "new": np.mean(new_vals),
                "baseline": np.mean(base_vals),
                "diff": np.mean(new_vals) - np.mean(base_vals),
            }

        comparison = {
            "new_version": self.system.name if self.system else "unknown",
            "mean_diff": mean_diff,
            "improvement": mean_diff > 0,
            "t_statistic": t_stat,
            "significant": significant,
            "dimension_comparison": dim_comparison,
        }

        return comparison

    def generate_report(self):
        """生成文本报告。"""
        summary = self.compute_summary()

        lines = []
        lines.append("=" * 60)
        lines.append(f"  评测报告: {summary['system']}")
        lines.append("=" * 60)
        lines.append(f"  测试用例数: {summary['total_cases']}")
        lines.append("")

        # 全局指标
        lines.append("─── 全局指标 ───")
        for name, stats in summary["overall_metrics"].items():
            lines.append(f"  {name:>15}: {stats['mean']:.3f} ± {stats['std']:.3f}  "
                        f"[{stats['min']:.3f}, {stats['max']:.3f}]")
        lines.append("")

        # 分类别
        lines.append("─── 分类别统计 ───")
        lines.append(f"  {'类别':>10} | {'数量':>4} | {'均值':>6} | {'标准差':>6}")
        lines.append(f"  {'-'*10} | {'-'*4} | {'-'*6} | {'-'*6}")
        for cat, stats in summary["category_stats"].items():
            lines.append(f"  {cat:>10} | {stats['count']:4d} | "
                        f"{stats['mean']:.3f}   | {stats['std']:.3f}")
        lines.append("")

        # 失败分析
        fa = summary["failure_analysis"]
        lines.append("─── 失败分析 ───")
        lines.append(f"  失败总数: {fa['count']} ({fa['rate']:.1%})")
        for cat, count in fa["by_category"].items():
            lines.append(f"    {cat}: {count} 条")
        lines.append("")

        # 失败用例详情（前3条）
        failures = [r for r in self.results if r["metrics"]["overall"] < 0.3]
        if failures:
            lines.append("─── 典型失败案例 (前3条) ───")
            for r in failures[:3]:
                lines.append(f"  [{r['category']}] {r['question'][:50]}")
                lines.append(f"    overall={r['metrics']['overall']:.3f} | "
                           f"faith={r['metrics'].get('faithfulness', 0):.3f} | "
                           f"rel={r['metrics']['relevancy']:.3f} | "
                           f"judge={r['metrics']['judge_score']:.3f}")
                lines.append(f"    答案: {r['answer'][:60]}...")
            lines.append("")

        report = "\n".join(lines)
        self.report = report
        self.summary = summary
        return report
