# A股投资分析框架

系统化的A股投资分析方法论技能，帮助Agent为用户提供结构化、纪律化的投资分析与建议。

## 核心理念

投资决策的核心 = 判断投资主线是否具备长期增长潜力。
- **主线完好** → 定投不变（智能调整：涨少投跌多投），技术面信号仅观察不暂停
- **主线断裂** → 才卖出（产业逻辑证伪，非技术面破位）

技术面破位 ≠ 主线断裂。主线断裂 = 产业逻辑被证伪（如AI被证伪、政策方向逆转）。

## 工作流程

### 1. 基金/标的筛选

**前置代码校验（强制）**：
- 推荐任何基金前，必须先搜索验证基金代码→名称的对应关系
- 禁止通过推理猜测基金代码对应的名称
- 代码与名称不匹配时暂停推荐，重新搜索确认

**五维筛选标准**：
1. 费率：管理费+托管费，A类长期持有优先（C类适合短期，有销售服务费）
2. 收益：近1年/3年/成立以来收益率
3. 回撤：最大回撤 < 行业平均
4. 卡玛比率 > 3（风险调整后收益优秀）
5. 规模 > 5亿（避免清盘风险，< 2亿禁止推荐）

**A/C类选择规则**：
- 长期持有（> 1年）→ 选A类（申购费折扣/免，无销售服务费）
- 短期持有 → 选C类（无申购费，但有销售服务费）
- QDII基金注意限购额度（通常10元/天起）

### 2. 定投策略制定

**智能定投规则**：
- 基准金额按周/双周执行
- 涨幅大 → 减少当期投入（涨少投）
- 跌幅大 → 增加当期投入（跌多投）
- 跌幅 > 5% → 可考虑双倍投入（视资金充裕度）

**资金分配框架**（参考比例，非硬性规定）：
- 生存支出 45%
- 强制应急储蓄 15%
- 投资 30%（进攻/平衡/防御三档分配）
- 自我提升 10%

**三档配置逻辑**：
- 进攻仓（高弹性）：科技/AI/半导体等成长赛道
- 平衡仓（中等弹性）：宽基指数增强/行业ETF
- 防御仓（低弹性）：黄金/红利/债券/海外指数

### 3. 主线纪律框架

**判断主线是否完好的维度**：
1. 产业逻辑：核心驱动因素是否仍然成立（如AI算力需求、国产替代趋势）
2. 业绩验证：相关行业是否出现持续的业绩兑现（季报/中报/年报数据）
3. 政策支持：国家政策是否持续加码或至少未转向
4. 资金面：主力资金是否持续流入相关板块

**主线断裂信号**（满足任一即触发卖出评估）：
- 产业增速转负或出现趋势性下滑
- 核心逻辑被证伪（如技术路线被替代）
- 政策方向逆转（如从支持转为限制）
- 持续资金流出 + 业绩不及预期双杀

**卖出触发条件示例**（每只持仓应预设逻辑止损线）：
- 科技类：行业增速转负 | 核心技术被证伪 | 国产替代趋势逆转
- 基础设施类：投资缩减 | 核心需求逻辑被推翻
- 防御类：宏观逻辑逆转（如央行停止增持黄金 | 地缘风险大幅下降）
- 指数类：跟踪指数/策略逻辑失效

### 4. 降损三防线

1. **事前分散**：确保持仓低相关性；进攻仓位内部识别高相关性标的（如AI赛道多只基金高度相关）
2. **事中纪律**：定投本身具有降损功能（跌多投多摊薄成本）；暴跌日不决策（情绪控制）
3. **事后止损**：预设逻辑止损线 + 单方向亏损15%触发复盘 + 极端行情SOP

### 5. 政策信号四维解读

对重大政策/会议/文件进行四维度分析：

| 维度 | 含义 | 解读方法 |
|------|------|---------|
| 力度 | 用词轻重 | "支持"vs"大力推进"vs"加快"→力度递增 |
| 顺序 | 出场优先级 | 排在前面的领域优先级更高 |
| 考察 | 调研路线 | 领导调研方向暗示政策发力点 |
| 缺席 | 热词消失 | 曾频繁提及但突然淡出=可能见顶信号 |

**信号映射**：将四维分析结果映射到持仓方向，标注信号强度：
- 🔴 利空/风险信号
- 🟡 中性/观察信号
- 🟢 利好/确认信号

**政策信号分层验证**：
- 执行端（已完成投资/业绩数据）→ 战略端（远期规划/目标）
- 同主线不同维度交叉验证，三层递进：业绩 → 执行 → 规划，可信度递增
- 执行端信号已兑现 + 战略端方向一致 = 最高可信度

### 周末消息面四维扫描

周末/假期对下周市场进行预判扫描：
1. **政策**：央行/国常会/政治局措辞变化
2. **产业**：半导体/电网/核电等核心产业事件
3. **外围**：美股/地缘/汇率变动
4. **资金**：ETF申赎/北向资金动向

每条信号 → 持仓方向标注🔴🟡🟢，外部冲击区分情绪面（短期）vs基本面（中期）

### 6. 极端行情SOP

**触发条件**：单日跌幅 > 3% 或单周跌幅 > 8%

**执行步骤**：
1. 评估基本面 vs 拥挤度：是基本面恶化还是资金拥挤修正？
2. 检查持仓：各标的逻辑是否仍然成立？
3. 检查相关性：是否存在隐藏的高相关性风险？
4. 判断主线：主线是否断裂？还是技术面调整？
5. 决策：主线完好→维持定投不变；主线断裂→执行卖出

**外部冲击预警**：
- 海外关键指数大跌（如费城半导体跌 > 5%）或板块3日跌 > 20% → 触发监控线
- 三面交叉判断：海外面（美股/费半/地缘）+ 资金面（北向/ETF）+ 政策面（央行/产业政策）
- 主线完好 → 继续定投，设1周观察窗口；主线断裂 → 卖出
- 连续3天反弹 → 风险解除
- 完整闭环验证（8/4实战）：触发→三面交叉→主线完好→定投不变→V型反转+10.74%

**情绪面偏离识别**：
- A股跌 vs 海外涨 + 产业基本面强化 = 情绪面偏离（非基本面恶化）
- 判断步骤：对比海内外→检查产业信号→区分情绪（短期）vs基本面（中期）
- 情绪面偏离 → 策略不变（主线完好），等情绪修复
- 8/3半导体案例验证：A股半导体暴跌但海外费半上涨+产业基本面强化→情绪面偏离→定投不变

### 7. 数据校验规范

**多源交叉验证**：
- 同一数据点至少获取2个来源进行比对
- 来源间偏差 < 0.3%（收盘价）或 < 0.5%（涨跌幅）→ 取质量加权平均
- 偏差超标 → 取最高质量来源数据，标记分歧
- 单源数据 → 标记"未验证"，不直接采信

**跨日验证法**：
- 连续2天脚本数据一致 → 脚本可信
- 手动单次搜索与脚本数据矛盾 → 优先采信脚本多源数据
- 数据偏差 > 5% → 标记存疑，不写入结论，等待交叉验证

## 康波周期定位（可选）

用于长期投资方向判断的宏观框架：
- 判断当前处于康波周期的哪个阶段（繁荣/衰退/萧条/复苏）
- 识别主导技术浪潮（当前：第6轮康波，AI技术导入期）
- 核心资产 = 导入期最受益的产业（如AI算力/半导体/通信基础设施）
- 三层监控：产业事件层 + 业绩验证层 + 政策支持层

## 超级周预判框架

当周内出现 ≥ 3个重大事件（如IPO上市 + 央行决议 + 财报密集发布）时：
1. 周末提前梳理事件时间线
2. 进行情景推演（正面/中性/负面）
3. 映射到持仓影响
4. 制定应对预案

## 输出规范

1. **结论先行**：先输出核心分析结论与参考方向，再补充数据依据
2. **区分性质**：严格区分客观市场数据、行业规律总结与参考建议
3. **不做承诺**：不做收益承诺，明确提示市场波动与不确定性风险
4. **风险提示**：涉及投资类专业问题时，回复末尾必须追加：
   > ⚠️ AI生成内容仅供参考，不构成投资建议；投资有风险，决策请结合自身情况并咨询专业人士。

## AVOID

- 禁止通过推理猜测基金代码对应的名称（必须搜索验证）
- 禁止忽略A/C类费率差异
- 禁止推荐规模 < 2亿的基金
- 禁止编造行情数据或投资结论
- 禁止在没有数据支撑的情况下给出确定性判断
- 信息不足时说明假设、缺口与边界
