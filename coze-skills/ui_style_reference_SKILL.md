# UI/UX设计风格参考

84种UI设计风格标准词汇表，源自GitHub 95k star项目ui-ux-pro-max-skill。在生成图片、PPT、网页或任何视觉产物时，引用标准风格名称可显著提升产出质量。

## 使用方法

1. 根据任务类型（通用界面/落地页/数据看板/移动端）确定风格大类
2. 从对应清单中选择1-2种匹配的风格
3. 在image_gen的prompt中直接使用**风格标准英文名**（如"Glassmorphism glass effect"）
4. 可组合多种风格（如"Bento Grid layout + Glassmorphism cards"）

## 风格快速选型决策树

```
界面类型？
├── 企业/SaaS/工具 → Minimalism, Flat Design, Bento Grids, Neumorphism
├── 消费级/社交 → Glassmorphism, Claymorphism, Aurora UI, Soft UI
├── 创意/艺术 → Brutalism, Memphis, Vaporwave, Y2K, Psychedelic
├── 科技/AI → Cyberpunk, Holographic, Dark Mode, Tech Noir
├── 游戏/娱乐 → Pixel Art, Retro Futurism, Voxel, HUD/Glassmorphism
├── 金融/数据 → Material Design, Bento Grids, Clean Corporate, Data-Centric
├── 移动端 → iOS Native, Liquid Glass, Bottom Sheet, Card-based
└── 落地页 → Hero-focused, Gradient Mesh, 3D Illustrations, Asymmetric
```

## 49种通用UI风格

## 8种落地页专用风格

1. **Hero-focused** — 大标题+CTA居中，简洁有力
2. **Product Showcase** — 3D产品渲染+特性说明
3. **Storytelling** — 纵向叙事滚动，章节式
4. **Social Proof** — 用户评价+数据墙+Logo矩阵
5. **Interactive Demo** — 内嵌可交互产品演示
6. **Video Background** — 全屏视频背景+文字叠加
7. **Asymmetric Split** — 左右非对称分割，图文各半
8. **Conversion-focused** — 表单前置，漏斗式布局

## 10种数据看板风格

1. **Dark Dashboard** — 深色背景+亮色数据，适合监控大屏
2. **Light Clean** — 白底+卡片+少量强调色，SaaS主流
3. **Bento Dashboard** — Bento网格卡片布局，Apple风
4. **Dense Data** — 高密度表格+多面板，金融交易
5. **Spatial Analytics** — 3D/空间感数据可视化
6. **Minimal Metrics** — 大数字+极简图表，KPI导向
7. **Real-time HUD** — 实时刷新、扫描线、科技感
8. **Color-coded** — 语义色编码（红黄绿）+热力图
9. **Narrative Dashboard** — 数据故事线，自上而下解读
10. **Mobile-first BI** — 大卡片+滑动手势，移动优先

## 17种移动端专用风格

1. **iOS Native** — SF字体、毛玻璃、底部Tab
2. **Material You** — Material 3、动态配色、圆角
3. **Card-based** — 卡片流、滑动操作
4. **Bottom Sheet** — 底部弹出面板、手势关闭
5. **Swipe-first** — 左右滑动为主交互（Tinder风）
6. **Full-screen Feed** — 全屏沉浸信息流（抖音风）
7. **Floating Action** — 悬浮按钮+展开菜单
8. **Onboarding-first** — 多屏引导、渐变背景
9. **Chat-first** — 对话式主界面、气泡消息
10. **Widget-centric** — 小组件为主、个性化桌面
11. **Gesture-nav** — 全面屏手势、无按钮
12. **Pull-to-refresh** — 下拉刷新动效
13. **Skeleton Loading** — 骨架屏加载占位
14. **Dark Mode Mobile** — 移动端暗色主题
15. **Biometric UI** — 指纹/面容识别动效
16. **AR Overlay** — 相机叠加AR信息
17. **Watch/Wearable** — 圆形/方形小屏、Glanceable

## 在图片生成中引用风格

使用image_gen生成UI/界面图时，在prompt中加入：

```
[场景描述], using [StyleName] style: [该风格的1-2个视觉特征关键词],
[配色描述], [排版/布局描述], high fidelity UI design
```

示例：
- "一个投资组合看板页面，using Bento Grids style: modular rounded cards with subtle shadows, dark navy background with emerald and gold accents, data visualization charts, high fidelity UI design"
- "一个AI助手对话界面，using Glassmorphism style: frosted glass translucent cards with background blur, soft purple and blue gradient background, high fidelity UI design"

## 在PPT制作中引用风格

使用create-ppt技能制作PPT时，在视觉风格描述中引用：
- 商务/金融主题：Minimalism + Swiss Design + Monochrome
- 科技/AI主题：Dark Mode + Bento Grids + Futuristic
- 创意/营销主题：Aurora UI + Gradient Mesh + 3D Illustrations
- 教育/培训：Soft UI + Flat Design + Playful
